No. 01
Micro-level AI Feedback Features and Student Responses in Consecutive LLM Tutoring Interactions
cs.HC 2026-07-13
本研究旨在探討AI輔助回饋中的微觀特徵，如何影響學生在連續LLM輔導互動中的困惑與理解。過去研究多集中於會話或任務層面的回饋效果，但本研究深入分析了具體闡述、情感語言和回饋長度等微觀特徵。研究方法是透過分析自然輔導情境中的用戶-AI互動數據，追蹤學生在一次互動後立即產生的反應。結果發現，這些微觀特徵與學生後續的學習狀態（如困惑或理解）存在顯著關聯。這項發現對於優化AI輔導系統的回饋策略，提升學習效果具有重要實踐意義，有助於設計更具適應性和有效性的教育AI。
AI回饋微觀特徵如何影響學生學習？
深度點評
  • 本研究將AI回饋分析從宏觀層面推進到微觀層面，具體探討了「具體闡述」等語言特徵對學習的影響，方法創新。
  • 相較於傳統的學習分析，本研究更聚焦於即時、連續的互動數據，提供了更細緻的因果關係洞察，而非僅是相關性。
  • 研究結果可直接應用於AI輔導系統的回饋模組設計，提升其智能化和個性化程度，對教育心理學與人機互動領域有潛在影響。
研究貢獻
  • 首次在連續LLM輔導互動中，系統性評估微觀AI回饋特徵對學生反應的影響。
  • 識別出具體闡述、情感語言和回饋長度等關鍵特徵與學生困惑/理解的關聯。
  • 為設計更有效、更具適應性的AI輔導回饋策略提供了實證基礎。
研究限制
  • 研究數據來自特定自然輔導情境，結果的普適性可能受限於領域和學生群體。
  • 未深入探討不同學習者特徵（如先備知識、學習風格）如何調節回饋效果。

cs.HC 2026-07-13

強制穿戴感測系統下，使用者如何適應？
深度點評
  • 本研究採用質性方法深入探討了使用者在高風險AI系統中的行為適應機制，提供了獨特的視角和豐富的實證資料。
  • 提出了「感測器素養」這一新概念，超越了傳統的數位素養，更聚焦於使用者對感測數據判斷邏輯的理解與應對。
  • 對AI系統的透明度、可解釋性以及使用者賦權等倫理議題提供了深刻的社會心理學洞察，對HCI和AI倫理領域有重要影響。
研究貢獻
  • 首次對強制性穿戴式感測系統中的使用者行為適應進行質性研究。
  • 提出了「感測器素養」概念，描述使用者在高風險AI環境中發展的風險導向知識。
  • 揭示了使用者透過行為探測和適應來應對AI黑箱判斷的策略。
研究限制
  • 研究對象來自特定文化和制度背景，結果的普適性可能需要進一步驗證。

如何透過遊戲提升開發者隱私意識？

研究貢獻

CogniConsole: Externalizing Inference-Time Control as a Formal Abstraction for Reliable LLM Interactions
cs.AIcs.HC
核心問題
如何提升LLM系統的推論時可靠性與可控性？
方法亮點
本研究提出了CogniConsole架構，將推論時控制外部化為結構化介面，結合程式化協調與有界限的提示式推理。透過「可控性導向探針」進行評估，證明了其在提升LLM可靠性方面的有效性。

將LLM控制權交還用戶，是提升可靠性與信任的關鍵一步。

An Emergent Mirage: Is Emergent Misalignment and Realignment Indeed a Robust Phenomenon?
cs.AI
核心問題
LLM的湧現性錯位與重新對齊現象是否具備穩健性？
方法亮點

Prompt × 心理學 No.01
CogniConsole: Externalizing Inference-Time Control as a Formal Abstraction for Reliable LLM Interactions
cs.CL
Prompt 技術
有界限的提示式推理 (Bounded Prompt-based Reasoning)：此技術將LLM的推理過程限制在預設的結構化介面和程式化協調中，而非完全開放式的提示。它結合了程式邏輯與提示指令，確保LLM在特定框架內進行推理，以提高可靠性。
心理學概念
認知負荷 (Cognitive Load) 與控制感 (Sense of Control)：透過外部化控制和結構化介面，CogniConsole旨在降低用戶在與LLM互動時的認知負荷，因為用戶無需在複雜的提示中摸索。同時，提供明確的控制點能增強用戶的控制感，這在心理學上與信任、滿意度和效率密切相關。
應用場景
當前應用於需要高可靠性的LLM系統，如企業級客服、自動化報告生成或決策支援系統。未來潛力在於將LLM整合到更多關鍵任務應用中，例如醫療診斷輔助或金融風險評估，透過精確控制推理過程來確保結果的準確性和可解釋性。對心理學實務的啟發是，設計人機互動介面時，應考慮如何透過結構化控制來管理用戶的認知資源，並提升其對AI系統的信任與接受度。
精準提示與程式協調，讓LLM不再是黑箱，而是可控工具。

Prompt 技術
角色提示 (Persona Prompting) 與多代理辯論 (Multi-Agent Debate)：透過為每個LLM代理分配明確的「專家角色」（如檢察官、辯護律師、法官），並設計結構化的辯論流程。每個代理根據其角色和提示進行推理和發言，最終透過聚合方法得出結論。
心理學概念
群體決策 (Group Decision-Making) 與認知多樣性 (Cognitive Diversity)：此技術模擬了人類在複雜問題解決中利用不同視角和專業知識進行協商的過程。為代理分配不同角色，引入了「認知多樣性」，有助於減少單一模型可能存在的偏見或盲點，提升決策的全面性和穩健性，這與社會心理學中的群體智慧理論相符。
應用場景
當前應用於法律文本蘊涵、合同審查和法律諮詢等領域，提升法律推理的準確性。未來潛力在於將此多代理辯論框架推廣到其他需要複雜判斷和多方協商的領域，如政策制定、科學研究或商業策略分析。對心理學實務的啟發是，AI系統可以作為人類群體決策的輔助工具，透過模擬不同視角來幫助人類發現潛在問題、評估風險，甚至在心理諮詢中模擬不同觀點以幫助個案釐清思緒。
AI代理化身法律專家，辯論出更精準的判決。

Prompt × 心理學 No.03
ARCANA: A Reflective Multi-Agent Program Synthesis Framework for ARC-AGI-2 Reasoning
cs.CL
Prompt 技術
反射式精煉 (Reflective Refinement) 與迭代提示 (Iterative Prompting)：ARCANA框架分解任務為感知、假設生成、符號執行和反射式精煉。其中，反射代理會根據失敗案例生成回饋，並將這些回饋作為新的提示，引導其他代理進行下一輪的程序合成，形成一個自我修正的迭代循環。
心理學概念
元認知 (Metacognition) 與問題解決 (Problem Solving)：反射式精煉機制高度模擬了人類的元認知能力，即對自身思維過程的監控和調整。當AI代理「反思」其失敗並從中學習時，它展現了類似人類的錯誤分析和策略調整能力，這對於複雜問題解決至關重要。這種迭代修正的過程也反映了人類試錯學習的心理機制。
應用場景
當前應用於解決ARC AGI 2這類需要複雜推理和程序合成的任務，展示了AI在通用人工智慧領域的潛力。未來潛力在於將這種反射式多代理框架應用於軟體工程、科學發現或機器人規劃等需要高度自主性和適應性的領域。對心理學實務的啟發是，AI可以作為認知訓練的工具，透過模擬複雜問題解決過程，幫助人類理解和提升自身的元認知能力，例如在教育中提供更精準的錯誤分析和學習策略建議。
AI自我反思，迭代精進，邁向通用智慧的關鍵一步。
