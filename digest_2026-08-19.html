cs.HCcs.CY 2026-08-19
隨著健身數據在Strava和Instagram等社交平台上的分享日益普及，這種視覺化呈現方式成為一個新興的研究領域。本研究旨在深入理解健身數據分享的過程、設計考量以及視覺化在其中的作用。研究採用建構主義紮根理論方法，對18位健身數據分享者進行了半結構式訪談並分析數據。分析結果揭示了健身數據分享的三個獨特特徵，包括其作為社交資本、自我表達工具以及社群連結的媒介。這些發現不僅豐富了人機互動與社交媒體研究，也為未來設計更具吸引力和支持性的健身應用提供了實證基礎。研究結果對於理解數位時代的自我呈現與社交互動模式具有重要意義。
健身數據分享在社交媒體上呈現出哪些獨特的人機互動與社會心理學特徵？
深度點評
  • 本研究採用紮根理論，透過深度訪談揭示了健身數據分享背後的複雜動機與社會心理機制，其方法論嚴謹且具備高度的探索性。
  • 相較於傳統的數據隱私或技術可用性研究，本文更側重於數據分享的社會文化意義與個人體驗，填補了該領域的空白。
  • 研究結果對於設計更符合用戶心理需求的社交健身平台、理解數位時代的自我呈現與社群建構具有重要啟示。
研究貢獻
  • 首次系統性地探索了健身數據分享在社交媒體上的獨特特徵。
  • 揭示了健身數據作為社交資本、自我表達與社群連結媒介的多重作用。
  • 為未來社交健身應用設計提供了以用戶為中心的實證指導。
研究限制

如何透過協作反思方法，讓對話式代理更精確地理解用戶在決策對話中的思考覆蓋範圍？
深度點評
  • 本研究提出協作反思方法，旨在解決對話式代理在理解用戶決策過程中「為什麼」的問題，超越了僅基於行為模式的傳統方法，具有創新性。

  • 該研究對於提升決策支援系統的智慧化程度、增強用戶信任與滿意度具有重要潛在影響。
研究貢獻
  • 提出了一種以人為中心的協作反思方法，用於理解用戶在決策對話中的思考覆蓋範圍。
  • 解決了傳統對話策略可能因誤判用戶意圖而導致不當互動的問題。

研究限制

如何在為認知障礙老年人設計生成式AI系統時，平衡其安全性與用戶自主性？

Procedural Collapse: A Structural Account of Disengagement in LLM-Assisted Writing
cs.HCcs.CYcs.CL 2026-08-19
當學生使用大型語言模型進行寫作時，對於其脫離學習的普遍解釋是傾向性的：他們過度依賴，而解決方法是鷹架式地支持自我調節。本研究認為需要一個結構性的解釋，為支持適當的AI輔助寫作設計干預措施提供替代基礎。當前的LLM寫作介面會導致「程序性崩潰」：將迭代、自定進度的寫作過程替換為單一輸出，從而將寫作者的任務從生成轉變為全面的評估。由於這種結構性轉變，學生在寫作過程中失去了參與感，導致學習效果下降。本研究旨在透過分析這種程序性崩潰，為設計更具教育效益的AI寫作工具提供新的視角。
LLM輔助寫作如何導致「程序性崩潰」，進而影響學生的寫作參與度和學習效果？
深度點評
  • 本研究提出了「程序性崩潰」這一創新概念，從結構性角度解釋了LLM輔助寫作中學生脫離學習的現象，挑戰了傳統的傾向性解釋。
  • 相較於僅關注學生個人行為的研究，本文更深入分析了AI工具介面設計對認知過程的影響，為教育心理學與人機互動領域提供了新的理論框架。
  • 研究結果對於設計更符合學習規律、促進學生深度參與的AI寫作工具具有重要指導意義，有助於避免AI在教育中的潛在負面影響。
研究貢獻
  • 引入了「程序性崩潰」概念，從結構性角度解釋LLM輔助寫作中的學習脫離現象。
  • 指出當前LLM寫作介面將生成任務轉變為評估任務，導致寫作者參與度下降。
  • 為設計促進學生深度參與和學習的AI寫作工具提供了新的設計基礎。
研究限制
  • 研究主要基於理論分析和觀察，缺乏大規模的實證數據支持。
  • 「程序性崩潰」的具體測量方法和量化指標仍需進一步開發。

No. 05
Margin-Regularized Structured Semantic Alignment for Brain-Language Correspondence
cs.AIcs.CLq-bio.NC 2026-08-19
隨著大型語言模型的快速發展，腦-語言解碼取得了顯著進展。然而，目前仍不清楚解碼內容是否真正反映了神經表徵，還是主要由語言模型本身重建。這種模糊性限制了解釋性，並阻礙了對內在腦-語言對應關係的深入研究。為了解決這一挑戰，本研究提出了MD-SigLIP框架。這是一個邊際正則化結構化語義對齊框架，旨在直接將腦部嵌入與文本嵌入在共享的語義空間中進行對齊。透過這種方法，研究旨在更清晰地揭示大腦活動與語言意義之間的直接關聯，從而提升腦-語言解碼的解釋性和準確性。
如何在腦-語言解碼中，更清晰地辨別解碼內容是神經表徵還是語言模型重建，並提升解釋性？
深度點評
  • MD-SigLIP框架透過邊際正則化和結構化語義對齊，直接在共享空間中對齊腦部與文本嵌入，有效提升了腦-語言解碼的解釋性，是方法上的重要創新。
  • 相較於傳統的腦-語言解碼方法，本研究更著重於區分神經表徵與模型重建，為理解大腦如何處理語言提供了更精確的工具。
  • 該研究對於神經科學、認知科學以及腦機介面技術的發展具有深遠影響，有助於揭示語言處理的底層機制。
研究貢獻
  • 提出了MD-SigLIP框架，用於邊際正則化結構化語義對齊，以提升腦-語言解碼的解釋性。
  • 解決了當前腦-語言解碼中，內容來源（神經表徵或模型重建）模糊不清的問題。
  • 為深入研究內在腦-語言對應關係提供了新的技術途徑。
研究限制
  • 框架的有效性可能高度依賴於腦部嵌入和文本嵌入的品質。
  • 實驗數據的規模和多樣性可能限制了模型的泛化能力。

04 / Prompt Engineering × 心理學 精選 TOP 3 PROMPT ENG × PSYCHOLOGY
Prompt × 心理學 No.01
The Price of Thinking: Reasoning Effort as a Model-Specific API Contract
cs.AIcs.CL
Prompt 技術
顯式推理努力提示 (Explicit Reasoning Effort Prompting)：透過在API請求中明確指定「高努力」(high effort) 等參數，引導模型投入更多計算資源進行深度推理，而非僅提供快速但可能膚淺的回答。
心理學概念
認知負荷 (Cognitive Load) 與 決策疲勞 (Decision Fatigue)：當模型被要求進行高努力推理時，其內部處理資源會被更大量地消耗，類似於人類在執行複雜認知任務時的認知負荷。這也暗示了模型在不同「努力」水平下的表現差異，可能與人類在不同認知資源投入下的決策品質變化相似。
應用場景
當前，此技術主要應用於需要高精度和複雜邏輯推理的場景，如數學問題求解、法律文件分析或科學研究輔助。未來，它有望應用於需要AI進行深度診斷、策略規劃或創造性問題解決的心理學相關任務。例如，在心理諮詢輔助中，可以要求AI以「高努力」模式分析個案資料，提供更全面、深入的評估與干預建議，避免因「低努力」而產生的誤判。這也啟發心理學研究者思考如何透過提示工程，更精確地引導AI模擬人類的深度思考過程。
讓AI「多想一點」，不只花錢，更買到深度。

Prompt × 心理學 No.02
DiSCO: Defending text-to-image generation through distribution-guided contrastive prompt optimization
cs.AIcs.CV
Prompt 技術
分佈引導對比提示優化 (Distribution-guided Contrastive Prompt Optimization)：透過優化提示詞，使其在潛在空間中遠離有害內容的分佈，同時接近安全內容的分佈，從而引導文生圖模型生成符合安全規範的圖像。這是一種黑盒防禦策略，無需修改模型內部權重。
心理學概念
偏見 (Bias) 與 感知安全 (Perceived Safety)：模型在生成圖像時可能內化訓練數據中的偏見，導致生成有害內容。此技術旨在透過提示工程來「糾正」這種偏見，使其輸出更符合人類對「安全」內容的感知與期待。這也涉及了人類對圖像內容的道德判斷與接受度。
應用場景
當前，該技術主要應用於防止文生圖模型生成暴力、色情或其他不適宜內容，尤其是在社交媒體、教育內容創作或兒童應用中。未來，它有望擴展到更廣泛的內容審核與倫理AI設計領域，例如防止AI生成帶有刻板印象或歧視性的圖像。在心理學實務中，這可以確保AI生成的視覺輔助材料（如心理治療中的圖像聯想）是安全、無害且符合倫理規範的，避免對用戶造成潛在的心理衝擊或負面影響。
讓AI學會「察言觀色」，生成內容更安全、更合乎倫理。

Prompt × 心理學 No.03
Towards Safer RAG: Only Agents Capable of System 2 Thinking may Access Untrusted Documents
cs.AIcs.CL
Prompt 技術
RAG與認知系統分層 (RAG with Cognitive System Layering)：結合檢索增強生成（RAG）與類似人類「系統2思維」的認知控制機制。具體而言，只有被設計為能進行深度、批判性思考的代理（模擬系統2）才被允許訪問未經信任的文件，以防範知識中毒攻擊。
心理學概念
雙重歷程理論 (Dual Process Theory)，特別是 系統1與系統2思維 (System 1 and System 2 Thinking)：系統1是快速、直覺、自動的思考，系統2是緩慢、審慎、分析性的思考。本研究將AI代理分為類似這兩種思維模式，並將對「不可信」資訊的處理權限賦予「系統2」代理，以模擬人類的批判性思考和風險評估。
應用場景
當前，此技術主要應用於提升RAG系統在處理潛在惡意或不實資訊時的安全性，尤其是在資訊檢索、問答系統和內容生成領域。未來，它有望應用於需要AI進行高度風險評估和決策的場景，如金融分析、醫療診斷輔助或法律諮詢。在心理學實務中，這可以確保AI在提供心理健康資訊或輔導建議時，能批判性地篩選外部資訊，避免傳播錯誤或有害的內容，從而保護用戶的心理健康。這也為AI的「認知控制」研究提供了新的方向。
讓AI學會「三思而後行」，面對假資訊不再輕信。
