No. 01
Incongruence-Aware Evaluation of Multimodal Speech Emotion Recognition in Audio Large Language Models
cs.AIcs.CLcs.HC 2026-10-XX
語音互動式大型語言模型（LLMs）處理說話者的內容與表達方式，但文本與語音通道常不一致。本研究探討這種不一致性是否會降低語音情感識別的性能。我們將文本和音訊映射到共享的「效價-喚醒-主導性」（VAD）空間，並利用兩成分高斯混合模型將兩者距離轉換為連續、無閾值的不一致性分數。該分數已透過人類判斷驗證其有效性。我們在表演、對話和自發性語音數據集上評估了三個音訊處理模型，結果顯示考慮不一致性對於多模態情感識別至關重要。這項研究為開發更具情境感知能力的AI系統提供了重要見解，尤其在心理健康輔助和客戶服務等領域。
文本與語音通道之間的不一致性，如何影響音訊大型語言模型的多模態語音情感識別性能？
深度點評
  • 本研究創新性地提出了「不一致性分數」來量化多模態情感表達中文本與語音之間的分歧，並透過高斯混合模型實現了連續且無閾值的評估，這比傳統的二元判斷更為精細。
  • 過去研究多專注於單一模態或假設模態一致，本研究則正視了現實世界中模態不一致的普遍性，並將其納入評估框架，提升了情感識別的實用性與魯棒性。
  • 此研究對於開發更具情境感知能力、能處理複雜人類情感表達的AI系統具有重要意義，尤其在心理健康輔助、客戶服務等領域，能更準確地理解用戶真實情感。
研究貢獻
  • 提出並驗證了基於 VAD 空間的連續、無閾值「不一致性分數」。
  • 首次在音訊大型語言模型中，以不一致性感知的方式評估多模態語音情感識別。
  • 證明了考慮文本與語音不一致性對於提高情感識別準確性的重要性。
研究限制
  • VAD 空間的映射可能無法完全捕捉所有情感細微差異。
  • 研究可能未充分探討不同語言或文化背景下情感表達不一致性的影響。

cs.AIcs.CYcs.HC 2026-10-XX

ChatGPT作為廣泛使用的LLM產品，其能力如何被濫用於監控相關任務，並帶來哪些潛在風險？

研究貢獻
  • 透過案例研究展示了 ChatGPT 協助執行監控任務的潛在風險。
  • 提出了一個包含七個監控風險類別的分類法。
  • 強調了廣泛可用的 LLM 產品在監控領域的倫理挑戰。
研究限制

No. 03
The First Few Tokens Matter: Understanding Chain-of-Thought Controllability
cs.AIcs.CL 2026-10-XX
思維鏈（Chain-of-Thought, CoT）監控是監督日益強大代理的一種有前景的方法。其成功部分歸因於當前模型在控制其推理軌跡中口頭表達內容的能力似乎有限。本研究調查了這種限制的來源，並將其與開頭思考標籤後前幾個 token 的熵崩潰（entropy collapse）聯繫起來。我們利用這一機制，透過對初始 token 的兩種推論時干預：預填充（prefilling），即使單個 token 也能顯著增加控制力，來恢復 CoT 的可控性。這項研究為理解和控制LLM的推理過程提供了新的理論和實踐基礎。
思維鏈（CoT）推理的可控性限制源於何處，以及如何透過干預初始 token 來恢復其可控性？
深度點評
  • 本研究首次將 CoT 可控性問題與「初始 token 熵崩潰」現象聯繫起來，揭示了 CoT 生成過程中的一個深層機制，為理解和控制 LLM 推理提供了新的視角。
  • 提出的「預填充」等推論時干預方法，以極低的成本（甚至單個 token）顯著提升了 CoT 的可控性，這比修改模型架構或重新訓練更具實用價值。
  • 此研究對於開發更透明、更可解釋、更可信賴的AI代理具有重要意義，尤其在需要人類監督和干預的關鍵決策場景中，能有效提升人機協作的效率與安全性。
研究貢獻
  • 識別出 CoT 可控性限制源於初始 token 的熵崩潰。
  • 提出並驗證了透過推論時干預（如預填充）恢復 CoT 可控性的方法。
  • 為理解和控制 LLM 的推理過程提供了新的理論和實踐基礎。
研究限制
  • 研究可能未充分探討不同 CoT 提示策略對熵崩潰的影響。
  • 「可控性」的定義和衡量可能仍有進一步細化的空間。

No. 04
Beyond Plausible Prediction: Safety Sufficiency in Web World Models
cs.AIcs.HC 2026-10-XX
網路世界模型日益被用於預測代理行動的後果，然而，一個看似合理的預測未來，不一定能支持正確的安全決策。本研究對十個凍結開源模型的3,000個預測進行了人類評估，發現86.1%的預測在語義上被判斷為合理。然而，多個模型在授權行為上表現出高度不對稱性，結合了低誤報安全執行率與對「需澄清詢問」（ASK）案例的低召回率，並強烈偏好「阻擋」（BLOCK）操作。這促使我們提出「安全充分性」（safety sufficiency）的概念，即預測性資訊是否足以支持正確的安全決策，超越了單純的合理性判斷。這對開發更安全、更值得信賴的AI代理系統具有重要指導意義。
網路世界模型在預測代理行動後果時，其「合理性」是否足以確保「安全決策的充分性」？
深度點評
  • 本研究透過引入「安全充分性」這一新穎概念，挑戰了僅以「預測合理性」評估AI系統安全性的傳統觀點，強調了決策支持的實際效用。
  • 透過大規模人類評估，揭示了現有模型在安全決策中存在的偏見（如過度偏好BLOCK），這與傳統的準確性指標不同，更貼近人類對風險的感知。
  • 此研究對開發更安全、更值得信賴的AI代理系統具有重要指導意義，特別是在高風險決策場景中，應將安全充分性納入評估標準。
研究貢獻
  • 提出「安全充分性」概念，作為評估AI系統安全決策能力的新指標。
  • 透過人類評估揭示了現有網路世界模型在安全授權行為上的不對稱性與偏好。
  • 強調了預測合理性與實際安全決策充分性之間的差距。
研究限制
  • 人類評估的規模雖大，但仍可能受評估者主觀性影響。
  • 研究未深入探討造成模型安全決策偏見的根本原因。

No. 05
DiRAFT: Privacy-Aware Financial Transcript Synthesis from Aggregate Discourse Priors
cs.CLcs.CY 2026-10-XX
使用客戶對話來訓練和評估金融語言模型會引發保密性問題，因為即使直接識別資訊被遮蔽，非公開的金融事實仍可能殘留。合成轉錄本提供了一種替代數據源，但其語篇保真度（discourse fidelity）和殘留保密風險需要評估。本研究引入了 DiRAFT（Discourse Realization from Aggregate First-order Transitions），該方法提取金融概念圖並記錄概念首次引入的順序。它匯集了相鄰的概念轉換，以生成具有高語篇保真度且隱私保護的合成金融對話。這項研究為金融科技領域的AI應用提供了重要的隱私保護解決方案。
如何在保護客戶隱私的前提下，生成高語篇保真度的合成金融轉錄本，以訓練和評估金融語言模型？
深度點評
  • DiRAFT 透過提取金融概念圖和記錄概念引入順序，創新性地從聚合語篇先驗中合成轉錄本，有效解決了傳統數據匿名化後仍可能洩露敏感資訊的問題。
  • 相較於簡單的數據匿名化或隨機生成，DiRAFT 更注重語篇的連貫性和金融事實的邏輯性，顯著提升了合成數據的實用價值和保真度。
  • 此研究為金融科技領域的AI應用提供了重要的隱私保護解決方案，有助於在合規前提下加速金融語言模型的開發與部署，同時也對其他敏感領域的數據合成具有啟發意義。
研究貢獻
  • 提出 DiRAFT 方法，用於生成隱私保護且高語篇保真度的合成金融轉錄本。
  • 創新性地利用金融概念圖和概念引入順序來捕捉語篇結構。
  • 為金融語言模型的訓練和評估提供了安全的替代數據源。
研究限制
  • 概念圖的構建可能需要領域專家知識，且難以自動化。
  • 合成數據的語篇保真度仍需持續與真實數據進行嚴格比較。

Prompt × 心理學 No.01
The First Few Tokens Matter: Understanding Chain-of-Thought Controllability
cs.CL
Prompt 技術
Chain-of-Thought (CoT) prompting。透過在提示中加入「讓我們一步一步思考」等指令，引導LLM生成中間推理步驟，以提高複雜任務的解決能力。本研究進一步探討了CoT生成過程中的可控性。
心理學概念
認知控制（Cognitive Control）與元認知（Metacognition）。CoT技術旨在讓LLM模擬人類的逐步推理過程，這與人類在解決問題時的認知控制能力（如注意力分配、抑制干擾）和元認知能力（對自身思維過程的監控與調節）密切相關。本研究探討如何透過干預初始token來「控制」LLM的CoT，正是對其認知控制機制的探索。
應用場景
在教育領域，可利用可控的CoT生成更具指導性的學習路徑或解題步驟，幫助學生理解複雜概念。在心理諮詢輔助中，AI能提供更透明的推理過程，解釋其建議的邏輯，增強用戶信任。在決策支援系統中，可控CoT能確保AI的推理符合特定倫理或安全規範，減少偏見。未來潛力在於開發能自我反思、自我修正的AI代理，提升其在複雜情境下的適應性與可靠性。

Prompt × 心理學 No.02
Does Recursive Knowledge Construction Help Agents Verify Consensus Claims in Science?
cs.AI
Prompt 技術
遞歸式知識建構（Recursive Knowledge Construction），這是一種代理行為（Agentic Behavior）的體現，類似於多步驟提示或自我反思（Self-reflection）的提示策略。代理透過檢索證據、建構中間狀態並判斷資訊是否足夠，來迭代地完善其知識。
心理學概念
認知推理（Cognitive Reasoning）與知識表徵（Knowledge Representation）。此技術模擬了人類在面對複雜問題時，如何逐步收集資訊、整合知識並進行判斷的認知過程。代理的「判斷器」決定何時停止遞歸，這與人類在決策時的「滿意度原則」（satisficing）或「認知負荷」（cognitive load）管理有關。
應用場景
在科學研究輔助中，AI代理能更有效地綜合多篇論文資訊，驗證科學主張的共識程度，加速文獻回顧與知識發現。在教育領域，可設計AI導師引導學生進行深度探究式學習，逐步建構對複雜主題的理解。在臨床診斷中，AI能遞歸地收集患者資訊，並判斷何時已獲得足夠證據以支持診斷。未來潛力在於開發能自主學習、自我修正的知識型AI系統，減少人類在資訊過載下的認知負擔。
AI學會「科學思考」，知識建構不再是盲人摸象！

More Rules, Longer Lists? Benchmarking Self-Evolving Agents on a Hidden-Rule Curriculum
cs.AI
Prompt 技術
自我演化代理（Self-Evolving Agents）與基於回饋的狀態重寫（Rewriting Persistent State from Feedback）。這可以被視為一種強化學習（Reinforcement Learning）或迭代優化（Iterative Refinement）的提示策略，代理根據環境回饋調整其內部規則或狀態，以適應新的隱藏規則。
心理學概念
學習與適應（Learning and Adaptation）及規則學習（Rule Learning）。本研究探討代理如何從經驗中學習並歸納出隱藏規則，這與人類的歸納推理、概念形成和認知靈活性密切相關。代理能否避免僅將新規則作為例外處理，而是真正整合到其知識體系中，反映了其認知效率與泛化能力。
應用場景
在自適應學習系統中，AI代理能根據學生的學習行為和表現，動態調整教學策略或內容，以適應學生的隱藏學習模式。在行為科學中，可用於設計能從用戶行為中學習並優化激勵機制的AI系統，以促進習慣養成。在人機互動中，能開發出更具適應性、能理解用戶隱藏偏好的智能助手。未來潛力在於創造能持續學習、自我改進的AI系統，使其在動態環境中保持高效。
AI不只會學規則，還要學會「舉一反三」，不再是死記硬背！
