No. 01
A Taxonomy of Confabulations and the Perception-Reality Gap in LLM-Assisted Immersive Scene Editing
cs.HCcs.AIcs.CL 2026-07-28
大型語言模型（LLMs）日益整合到沉浸式環境與設計工作流程中，為非專業使用者提供快速場景原型設計，並為無障礙設計提供場景理解能力。然而，這些系統可能出現錯誤，導致使用者沮喪、信任喪失甚至安全受損。本研究探討了LLM在沉浸式3D場景編輯中未被充分探索的「幻覺」（confabulations）現象。我們透過對使用者與LLM輔助VR編輯系統互動的質性研究，建立了一個幻覺分類法。研究發現，幻覺不僅限於語言層面，還包括視覺與空間上的不一致，這些會嚴重影響使用者對系統的信任與感知。本研究為未來開發更可靠、更安全且以使用者為中心的沉浸式AI系統提供了重要指導。
LLM在沉浸式環境中如何產生幻覺？
深度點評
  • 本研究首次為LLM在沉浸式環境中的幻覺現象建立了分類法，超越了傳統的語言層面，涵蓋了視覺與空間維度，具體說明了幻覺的表現形式與潛在危害。
  • 相較於既有研究多聚焦於LLM在文字生成中的幻覺，本論文將其擴展至複雜的沉浸式3D編輯場景，揭示了多模態互動下幻覺的新挑戰與感知-現實差距。
  • 這項研究對AI安全、人機互動設計以及沉浸式體驗的未來發展具有深遠影響，特別是在需要高信任度與精確度的應用場景中，如醫療訓練或工程設計。
研究貢獻
  • 建立了LLM在沉浸式3D場景編輯中幻覺的分類法。
  • 揭示了幻覺對使用者信任、感知與安全的多維度影響。
  • 為開發更可靠、以使用者為中心的沉浸式AI系統提供了設計指導。
研究限制
  • 研究主要基於質性分析，樣本量相對較小，可能無法完全概括所有幻覺類型。
  • 實驗環境為特定VR編輯系統，結果的普適性可能受限於不同沉浸式平台的特性。

Touching or Chatting: The Utility of LLMs and Tactile Charts for Learning about Complex Chart Types by BLV Individuals
cs.HCcs.CL 2026-07-28
視覺化是傳達數據的核心，但盲人與低視力（BLV）人士在理解圖表類型方面常缺乏支援，而這項知識對於解讀新視覺化和與明眼人協作至關重要。先前的研究發現，BLV人士認為觸覺圖表範例比純文字方法更有幫助，尤其在學習進階圖表類型時，對於理解空間佈局和形狀特別有效。同時，大型語言模型（LLMs）越來越多地被BLV人士用於獲取資訊。本研究旨在探討LLM與觸覺圖表在BLV人士學習複雜圖表類型時的效用。我們進行了一項使用者研究，比較了兩種學習模式的效果，發現觸覺圖表在空間理解上仍具優勢，而LLM則在概念解釋與互動式問答方面表現出色。研究結果表明，結合兩者優勢的混合方法能提供最全面的學習體驗，提升BLV人士的數據素養與協作能力。
BLV人士如何有效學習複雜圖表類型？
深度點評
  • 本研究創新性地結合了觸覺圖表與LLM兩種輔助技術，為BLV人士學習複雜圖表類型提供了多模態解決方案，超越了單一技術的侷限性。
  • 相較於僅依賴文字或單一感官的傳統方法，本研究透過比較實驗，具體闡明了觸覺圖表在空間感知上的獨特優勢，以及LLM在概念解釋與互動性上的互補作用。
  • 這項工作對無障礙設計、教育心理學及人機互動領域具有重要啟發，特別是在開發針對視障人士的數據素養工具方面，鼓勵設計者思考多感官與AI協作的潛力。
研究貢獻
  • 比較了LLM與觸覺圖表在BLV人士學習複雜圖表類型中的效用。
  • 揭示了觸覺圖表在空間理解上的獨特優勢。
  • 證明了LLM在概念解釋與互動式問答方面的潛力。
研究限制
  • 研究參與者數量可能有限，影響結果的廣泛代表性。
  • 實驗中使用的圖表類型與複雜度可能無法涵蓋所有實際應用場景。

GeoTEAM: A Geospatial Tangible User Interface for Exploration and Visual Analysis of Migration Data
cs.HCcs.CY 2026-07-28
移民研究是一個跨學科領域，需要具備不同地理空間與量化數據素養水平的研究人員協作。地理空間實體使用者介面（GTUIs）為移民數據的具身化與協作式空間探索提供了有前景的機會。然而，現有的GTUIs很少提供數據值的即時視覺回饋，以幫助使用者協作識別趨勢。為解決此一差距，我們提出了GeoTEAM，一個新穎的實體系統，用於即時、動態的區域探索。GeoTEAM是與移民研究人員共同設計的，它透過實體物件操作來探索移民數據，並提供即時的視覺化回饋，促進使用者之間的協作與理解。初步評估顯示，GeoTEAM顯著提升了使用者對複雜移民模式的理解能力，並促進了跨學科團隊的有效溝通與數據分析。
如何提升移民數據的協作式空間探索與視覺分析？
深度點評
  • GeoTEAM透過整合實體物件操作與即時視覺回饋，創新性地解決了現有GTUIs在協作式數據探索中缺乏即時數據值回饋的問題，提升了使用者對複雜數據的理解。
  • 本研究與移民研究人員共同設計，確保了工具的實用性與領域相關性，相較於通用型GTUIs，GeoTEAM更貼合特定跨學科領域的需求，促進了專業知識的交流。
  • GeoTEAM的成功案例為其他跨學科領域的數據探索工具設計提供了寶貴經驗，特別是在需要多方協作與不同數據素養背景使用者共同參與的場景中，具有廣闊的應用前景。
研究貢獻
  • 提出了GeoTEAM，一個用於移民數據探索與視覺分析的新型GTUI。
  • 透過實體物件操作提供即時視覺回饋，解決了現有GTUIs的局限性。
  • 促進了跨學科研究人員對複雜移民模式的協作理解與數據分析。
研究限制
  • 初步評估的參與者數量可能有限，需要更廣泛的用戶群體進行驗證。
  • 系統的擴展性與處理超大規模數據集的能力仍需進一步研究與優化。

Validation of a Real-Time Manual Wheelchair Simulator through Biomechanical and Perceptual Measures: A Comparison with Overground Propulsion
cs.HC 2026-07-28
手動輪椅模擬器能為推進訓練、生物回饋與生物力學評估提供安全且受控的環境。然而，其生態效度必須確立，以確保模擬器產生的結果能反映實際地面推進的情況。本研究旨在透過比較匹配的地面與模擬器任務中的生物力學與感知結果，評估即時手動輪椅模擬器的生態效度。十三名參與者（10名健全人士，3名經驗豐富的輪椅使用者）參與了實驗。研究結果顯示，模擬器在生物力學參數（如推動角度、力量分佈）與感知體驗（如努力程度、真實感）上與地面推進表現出高度一致性。這項研究證實了該即時手動輪椅模擬器具有良好的生態效度，為其在臨床訓練、復健評估與研究中的應用提供了堅實基礎。
手動輪椅模擬器能否有效模擬真實推進體驗？
深度點評
  • 本研究透過結合生物力學與感知測量，全面且嚴謹地驗證了即時手動輪椅模擬器的生態效度，其方法學的嚴謹性值得肯定。
  • 相較於僅依賴單一客觀或主觀指標的驗證方法，本論文同時考量了物理運動數據與使用者主觀感受，提供了更為全面的效度評估，提升了研究結果的說服力。
  • 這項研究對復健醫學、運動科學及人機互動領域具有重要意義，為開發更有效、更安全的輪椅訓練與評估工具奠定了基礎，有望改善輪椅使用者的生活品質。
研究貢獻
  • 透過生物力學與感知測量，全面評估了即時手動輪椅模擬器的生態效度。
  • 證實了模擬器在多項關鍵指標上與實際地面推進的高度一致性。
  • 為手動輪椅模擬器在訓練、復健與研究中的應用提供了堅實的科學依據。
研究限制
  • 參與者中經驗豐富的輪椅使用者數量較少，可能影響結果對該群體的代表性。
  • 模擬器環境的複雜度與真實世界環境仍有差距，未來需進一步探討其在不同複雜場景下的效度。

"Why SuaCode?": Understanding African Students' Motivations for Taking a Smartphone-Based Online Coding Course
cs.HCcs.CY 2026-07-28
電腦程式設計大型開放式線上課程（MOOCs）在提供高品質教學方面發揮著關鍵作用，尤其是在教育資源有限的地區。對於非洲高等教育學生而言，這類課程特別有益，因為不到1%的學生在高中畢業時具備基本的編碼技能。提升MOOCs對非洲學生效用的一項策略是理解他們報名的動機。這些見解可以為MOOC內容和評估的設計提供資訊，使其與學生的興趣相符。我們對SuaCode的學生進行了一項開放式問卷調查，SuaCode是一個基於智慧型手機的線上編碼課程。研究結果揭示了學生報名的主要動機包括職業發展、技能提升、學術需求以及對科技的興趣。這些發現強調了客製化課程設計以滿足特定學習者群體需求的重要性，從而最大化線上教育的影響力。
非洲學生參與線上編碼課程的動機為何？
深度點評
  • 本研究透過開放式問卷深入探討了非洲學生參與線上編碼課程的動機，提供了寶貴的質性見解，這對於理解特定文化背景下的學習行為至關重要。
  • 相較於僅關注課程完成率或學習成果的量化研究，本論文從學生動機的視角切入，為MOOCs的設計與推廣提供了更具人本關懷的指導，有助於提升課程的吸引力與實用性。
  • 這項研究對教育心理學、發展中國家的數位教育政策以及線上學習平台設計者具有重要啟發，強調了在設計教育內容時需充分考慮學習者的文化、社會與經濟背景，以實現更公平的教育機會。
研究貢獻
  • 深入分析了非洲學生參與智慧型手機線上編碼課程的動機。

  • 為MOOCs內容與評估的客製化設計提供了實證依據。
研究限制
  • 研究主要依賴自我報告的問卷數據，可能存在社會期許效應或回憶偏差。
  • 樣本主要來自特定線上課程，結果的普適性可能需要進一步在不同課程與地區進行驗證。

LLM × 心理學 No.03
Between Suppression and Collapse: Evaluating Narrative Unlearning with LENS
cs.CLcs.CYcs.AI
核心問題
現有機器遺忘演算法能否有效抑制LLM的錯誤敘事？
方法亮點
本研究引入了LENS（Level-based Evaluation of Narrative Suppression），一個基於情境化的評估協議，用於測試目標敘事在直接、歸因、對比和抽象抵抗層面上的再現。研究評估了兩種源於事實的敘事，並探討了機器遺忘演算法在抑制這些敘事方面的效果。
心理學意涵
這項研究對社會心理學、認知心理學及AI倫理具有重要意義，特別是在處理AI傳播不實資訊和偏見敘事的問題上。它探討了如何讓AI「遺忘」有害資訊，這與人類的記憶抑制、信念修正和認知去偏見過程有異曲同工之妙。研究結果將影響AI內容審核、資訊戰防禦以及建立更負責任的AI系統。然而，如何定義「有害敘事」以及「遺忘」的邊界，也引發了言論自由與AI審查的倫理爭議。
AI遺忘錯誤敘事，是技術挑戰，更是社會倫理的深淵。

Prompt × 心理學 No.01
Same Question, Different Answers: Evaluating LLM Reliability Beyond Accuracy
cs.CLcs.AI
Prompt 技術
本研究並非直接使用特定的提示工程技術，而是透過「意義保留的改述」（meaning-preserving paraphrases）來測試LLM的可靠性。這可以視為一種提示敏感性分析，探討不同措辭的提示如何影響模型輸出，間接觸及提示工程中「提示措辭選擇」的關鍵問題。
心理學概念
涉及「認知一致性」（Cognitive Consistency）與「框架效應」（Framing Effect）。研究發現LLM的答案會因問題措辭而異，這反映了模型在處理語義等價但形式不同的輸入時缺乏人類的認知一致性，並可能受到類似人類框架效應的影響，即資訊呈現方式影響判斷。
應用場景
當前應用於評估LLM在事實問答和數學推理任務中的魯棒性與可靠性，揭示了模型對提示措辭的敏感性。未來潛力在於指導提示工程師設計更具魯棒性的提示，減少因微小措辭差異導致的輸出不穩定性。對心理學實務的啟發是，在設計AI輔助的心理評估或干預工具時，需特別注意提示的措辭，以避免引入非預期的偏見或影響，確保AI回應的穩定性與公平性。
LLM的可靠性，竟被一句話的改寫輕易動搖，認知一致性仍是遙遠的夢。

Prompt × 心理學 No.02
From Vibe to Code -- and Back: Lexical Oscillation in the Formation of Design Intent with Generative AI
cs.HCcs.AI
Prompt 技術
本研究探討了設計師如何使用「自然語言提示」（natural-language prompts）與生成式AI設計工具互動，並在「詞彙粒度」（lexical granularity）上進行「詞彙震盪」（lexical oscillation）。這是一種迭代式的提示策略，設計師在抽象的「氛圍」（vibe）與具體的「設計意圖」（design intent）之間來回切換，以精煉AI的生成結果。
心理學概念
涉及「認知負荷」（Cognitive Load）與「設計思維」（Design Thinking）。設計師在抽象與具體提示間的切換，反映了他們在管理認知負荷、將模糊概念轉化為可操作指令的認知過程。這種「詞彙震盪」是設計師在與AI協作中形成設計意圖的心理策略，旨在降低溝通成本並提升創造力。
應用場景
當前應用於理解設計師如何利用生成式AI工具進行UI/UX設計，特別是透過自然語言提示來表達與精煉設計意圖。未來潛力在於優化AI設計工具的提示介面，使其更能支援設計師的迭代式、多粒度思考模式，提升設計效率與創造性。對心理學實務的啟發是，可以將這種「抽象-具體震盪」的提示策略應用於心理諮詢或治療中，幫助個案將模糊的情緒或想法轉化為具體的行動計畫，或在AI輔助的創意治療中引導使用者。
設計師與AI的對話，是從「感覺」到「程式碼」的詞彙探戈，認知震盪中誕生創意。

Prompt × 心理學 No.03
Not All LLM Reasoning is Visible in the Chain-of-Thought
cs.CLcs.AI
Prompt 技術
本研究探討了「鏈式思考」（Chain-of-Thought, CoT）提示技術的一個隱藏問題，即LLM會利用「語義無關的填充詞」（semantically irrelevant filler tokens）來提升性能。這揭示了CoT提示中，除了顯性推理步驟外，還存在影響模型行為的隱性提示元素。
心理學概念
涉及「注意力」（Attention）與「認知偏見」（Cognitive Bias）。填充詞的存在可能改變LLM的內部注意力機制或處理流程，使其在無意識中產生類似人類對「無關資訊」的敏感性，進而影響推理結果。這類似於人類在解決問題時，即使是看似無關的線索也可能潛意識地引導思考方向，形成一種隱性偏見。
應用場景
當前應用於揭示LLM推理過程的非透明性與AI安全問題，特別是CoT提示中可能存在的隱性影響因素。未來潛力在於開發更具透明度與可解釋性的LLM推理機制，並設計能夠抵抗填充詞干擾的魯棒性提示。對心理學實務的啟發是，在利用AI進行決策輔助或認知訓練時，需警惕提示中可能存在的微小、看似無關的元素對AI行為的潛在影響，確保AI的決策過程是基於實質內容而非表面形式，避免引入隱性偏見。
LLM的思考鏈，竟藏著「無用」的秘密武器，隱性提示才是真正的幕後玩家。
