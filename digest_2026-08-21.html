Cyber-Physical Systems for Accessibility and Ability Augmentation: Bridging Diverse Communities
cs.HCcs.CY 2026-08-21
隨著穿戴式裝置、機器人、XR和智慧環境的融合，網路實體系統（CPS）為支援和增強人類日常能力提供了廣闊的設計空間。這些系統透過感知真實世界情境、建模使用者需求並提供情境化協助，不僅能改善身心障礙者的可近性，還能提升人類在感知、記憶、學習和行動等方面的廣泛能力。然而，要實現這一潛力，必須解決情境感知、使用者建模、個人化適應和倫理考量等關鍵挑戰。本研究旨在探討CPS如何透過整合多模態感測、智慧演算法和人機介面，為不同社群提供客製化的能力增強解決方案。透過跨領域合作，本研究期望能推動CPS在提升人類福祉和社會包容性方面的發展。
CPS如何增強人類能力與可近性？
深度點評
  • 本研究提出了一個全面的框架，將多種先進技術（穿戴式、機器人、XR、智慧環境）整合於CPS中，以實現能力增強，其跨領域整合的視角具有創新性。
  • 相較於單一技術的輔助研究，本研究強調了CPS在感知、建模和適應使用者需求方面的潛力，並將可近性與廣泛能力增強結合，擴大了應用範圍。
  • 此框架為未來設計和部署支援人類能力的智慧系統提供了理論基礎和實踐指導，特別是在身心障礙輔助和認知增強領域。
研究貢獻
  • 提出整合多種先進技術的CPS框架，用於能力增強與可近性改善
  • 強調情境感知、使用者建模和個人化適應在CPS設計中的關鍵作用
  • 為跨領域合作開發以人為中心的智慧系統提供指導
研究限制
  • 框架的實證驗證仍需大規模跨領域合作
  • 倫理和隱私問題的具體解決方案有待深入探討

Delegating or Doing? Understanding User Behavior in Hybrid Human-Agent Interfaces
cs.HCcs.AI 2026-08-21
大型語言模型（LLMs）日益被整合到應用程式中，允許使用者透過直接操作或將任務委託給對話代理來完成工作。然而，當兩種模式都可用時，使用者如何平衡這些模式的行為模式卻鮮為人知。本研究提出了一個結合LLM代理的網路內容管理系統，透過模型情境協定（MCP），讓使用者可以透過圖形介面、對話代理或兩者結合來執行CRUD（建立、讀取、更新、刪除）任務。我們進行了一項跨受試者研究（N=73），旨在理解使用者在混合人機代理介面中的行為模式。研究結果揭示了使用者在不同任務複雜度和代理能力感知下，選擇委託或自行操作的傾向。這項研究為設計更有效率和使用者友善的混合介面提供了寶貴見解。
使用者如何平衡AI代理與直接操作？
深度點評
  • 本研究透過設計一個獨特的混合介面（MCP），首次系統性地探討了使用者在同時擁有直接操作和AI代理委託選項時的行為決策，方法設計具備創新性。
  • 與傳統僅關注單一互動模式的研究不同，本研究深入分析了使用者在不同情境下（如任務複雜度、代理能力感知）的選擇傾向，提供了更全面的使用者行為模型。
  • 研究結果對於未來設計整合LLM的應用程式具有重要指導意義，有助於優化人機協作效率，減少認知負荷，並提升使用者滿意度。
研究貢獻
  • 首次系統性研究混合人機代理介面中的使用者行為決策
  • 開發並應用模型情境協定（MCP）來實現混合互動模式
  • 揭示任務複雜度和代理能力感知對使用者選擇的影響
研究限制
  • 研究樣本量相對有限，可能影響結果的普適性
  • 未深入探討長期使用對使用者行為模式演變的影響

如何在中國有效部署心理健康EMA？
深度點評
  • 本研究針對中國心理健康研究中EMA平台部署的獨特挑戰，提出了一個實施導向的評估框架，其在地化和實用性視角是其主要創新。
  • 與通用EMA平台評估不同，本研究結合了中國特定情境下的工作流程差距，並透過案例應用驗證了框架的有效性，提供了更具針對性的解決方案。
  • 該框架不僅有助於中國研究者選擇和開發合適的EMA平台，也為其他發展中國家在心理健康數位化轉型方面提供了借鑒。
研究貢獻
  • 識別中國心理健康研究中EMA部署的工作流程差距
  • 開發一個以實施為導向的EMA平台評估框架
  • 透過案例應用初步驗證框架的實用性
研究限制

  • 框架中的某些評估指標可能需要更量化的衡量標準

HCI如何透過有形裝置支援正念練習？
深度點評
  • 本研究結合了範圍審查和理論框架的建構，為HCI領域中正念有形裝置的設計提供了系統性的心理學基礎，填補了現有研究的理論空白。

  • 此框架將有助於設計師和研究者開發出不僅能支援注意力調節和身體意識，還能全面促進情緒調節等正念核心要素的具身化裝置，提升心理健康應用效果。
研究貢獻
  • 對HCI中正念有形裝置進行了全面的範圍審查
  • 識別了現有裝置在支援正念機制上的偏重與不足
  • 提出了一個整合正念心理學機制與HCI設計原則的理論框架

No. 05
Calming Robot Pitches? Exploring the Influence of Robot Voice Pitch on Children's Stress Levels
cs.HCcs.AI 2026-08-21
本研究探討了機器人語音音高變化是否會影響兒童在機器人引導遊戲中的壓力水平。儘管較低的語音音高已被證明有助於人類溝通中的壓力調節，但這種效應是否能推廣到兒童與機器人互動中的合成語音尚不明確。27名8-12歲的荷蘭兒童被隨機分配與使用較低音高或較高音高的Zenbo Junior II機器人互動。互動包括介紹和計時遊戲。研究結果顯示，較低音高的機器人語音顯著降低了兒童的生理壓力指標（如心率變異性），並提升了兒童對機器人的信任感和舒適度。這項研究為設計兒童友善型機器人語音提供了重要依據。
機器人語音音高如何影響兒童壓力？
深度點評
  • 本研究首次系統性地探討了機器人語音音高對兒童壓力水平的影響，並結合生理指標進行測量，為兒童機器人互動設計提供了具體的實證依據。
  • 與成人研究不同，本研究聚焦於兒童這一特殊群體，並驗證了人類溝通中「低音高有助於壓力調節」的原則在合成語音中的普適性，具有重要的理論和實踐意義。
  • 研究結果直接指導了兒童機器人介面中語音設計的優化，有助於創造更具安撫性、更能促進兒童福祉的機器人互動體驗。
研究貢獻
  • 首次實證研究機器人語音音高對兒童壓力水平的影響
  • 發現較低音高的機器人語音能有效降低兒童生理壓力
  • 為兒童友善型機器人語音設計提供具體指導
研究限制
  • 研究樣本量較小，可能影響結果的普適性
  • 未探討不同文化背景下兒童對機器人語音音高的反應差異

LLM在ATC的應用潛力巨大，但安全與信任仍是關鍵考量。

Active Inference as Context Acquisition for AI Agents
cs.AIcs.CL

將主動推斷引入AI情境獲取，為AI決策提供認知心理學新框架。

Prompt × 心理學 No.01
Air Traffic Control Using Large Language Models: Prompt Engineering, Architecture, and Evaluation
cs.CL
Prompt 技術
Prompt Engineering (多層次約束提示)：透過迭代設計五種不同約束程度的提示結構（P1-P5），從開放式到高度結構化，以引導LLM生成符合安全關鍵領域（如空中交通管制）的精確且操作真實的對話。這涉及明確定義角色、任務、輸出格式和安全規範。
心理學概念
認知負荷 (Cognitive Load)：在ATC情境中，人類飛行員和管制員面臨極高的認知負荷。本研究透過提示工程，旨在讓LLM生成清晰、簡潔且無歧義的指令，以降低人類操作者的認知負荷，減少誤解和錯誤。同時，提示的複雜度本身也會影響LLM的認知處理。
應用場景
當前應用於生成操作真實的空中交通管制通訊，輔助或訓練管制員。未來潛力在於將LLM整合到更廣泛的安全關鍵系統中，如醫療診斷輔助、緊急應變協調等。對心理學實務的啟發是，提示工程不僅是技術優化，更是對人機溝通心理學的應用，可設計出更能適應人類認知模式、降低壓力、提升信任的AI介面。
提示工程精準引導LLM，為安全關鍵領域的人機協作開闢新徑。

Active Inference as Context Acquisition for AI Agents
cs.CL
Prompt 技術
Active Inference (主動推斷)：這是一種基於自由能原理的決策框架，AI代理人透過選擇能最大化資訊增益並最小化預期自由能的行動來獲取情境。這包括在預設假設、澄清問題、檢索或工具呼叫之間進行權衡，以最有效率的方式更新對潛在任務狀態的信念。
心理學概念
決策 (Decision Making) 與認知經濟學 (Cognitive Economics)：AI代理人面臨「花費資源（tokens）獲取更多資訊」與「依賴預設假設」之間的權衡，這與人類在不確定性下進行決策時的認知經濟學原理高度相關。主動推斷模型模擬了人類在有限資源下，如何透過資訊尋求來降低不確定性，以最小化「驚訝」或「預測誤差」。
應用場景
當前應用於提升互動式AI代理人在複雜任務中獲取正確情境的效率。未來潛力在於開發更具適應性和自主性的AI代理人，能像人類一樣在對話中主動提問、澄清，甚至預測使用者意圖。對心理學實務的啟發是，此模型為理解人類在互動中如何進行情境理解和資訊尋求提供了計算模型，有助於設計更符合人類溝通習慣的AI助手，並在教育、諮詢等領域提供更精準的個性化支援。
主動推斷讓AI更像人，高效情境獲取是智慧互動的基石。

Beyond Imitation: Filtering On-Policy Distillation by Reasoning Progress
cs.CLcs.AI
Prompt 技術
On-Policy Distillation (OPD) with Reasoning Progress Filtering (基於推理進度過濾的策略蒸餾)：傳統OPD假設教師模型的回饋等同於推理進度，但本研究提出此假設不總是成立。因此，它引入了一種過濾機制，僅選擇那些真正反映推理進度的教師回饋來指導學生模型，而非盲目模仿所有回饋。這可以被視為一種更精細的RLHF（Reinforcement Learning from Human Feedback）或RLAIF（Reinforcement Learning from AI Feedback）形式。
心理學概念
學習與推理 (Learning and Reasoning)；回饋與動機 (Feedback and Motivation)：本研究挑戰了傳統機器學習中對「正確回饋」的簡化假設，這與教育心理學中關於學習和推理過程的理解高度相關。它指出，並非所有「教師」提供的回饋都對「學生」的真正進步有益，有些甚至可能誤導。這引發了對AI學習過程中「有效回饋」本質的思考，以及如何設計能促進真正認知進步的學習環境。
應用場景
當前應用於提升語言模型在後訓練階段的推理能力和學習效率。未來潛力在於開發更具「批判性」學習能力的AI系統，能夠辨別並篩選出真正有助於其認知發展的資訊。對心理學實務的啟發是，這項研究強調了回饋品質對學習效果的關鍵影響，無論是對人類還是AI。在教育、技能培訓或心理治療中，提供精準且有助於「真正進步」的回饋，而非僅僅是「正確」的回饋，是提升成效的關鍵。
智能篩選教師回饋，讓AI學習不再盲目模仿，更懂推理。
