No. 01
Sensus Pond: Exploring Water as Sensing Medium for More-than-Human Observation
cs.HC 2026-08-06
研究動機在於現有互動設計過於以人為中心，忽略了非人類存在的感知與互動。核心問題是如何將水重新定義為一個主動的感知媒介，以捕捉超越人類的痕跡。研究方法提出了一種「無需翻譯的觀察」框架，旨在抵制將非人類存在穩定化、解碼或擬人化的傾向。Sensus Pond是一個具體嵌入物質環境並具場域特性的互動系統，它利用水的物理特性來記錄環境中的細微變化。主要實驗涉及系統的設計與部署，觀察其如何捕捉並呈現非人類的互動痕跡。結果發現Sensus Pond能有效作為一個感知媒介，提供對環境更深層次的理解。實際意義在於為互動設計開闢了新的路徑，鼓勵以生態共生和多物種視角來思考技術與自然的關係。
如何設計超越人類視角的感知互動系統？
深度點評
  • 方法創新：提出「無需翻譯的觀察」框架，挑戰傳統以人為中心的設計範式，透過水作為媒介實現多物種感知，具高度原創性。
  • 比較與進展：相較於現有互動設計多側重於人類使用者體驗，本研究將感知主體擴展至非人類，深化了「多於人類設計」的理論與實踐。
  • 潛在影響：可能啟發環境監測、生態藝術、以及未來人機自然互動介面的設計，推動更具包容性的技術發展。
研究貢獻
  • 引入Sensus Pond系統，將水重新定義為互動感知媒介。
  • 提出「無需翻譯的觀察」方法論框架。
  • 為多於人類設計和生態糾纏理論提供物質實踐案例。
研究限制
  • 系統的長期穩定性與維護成本可能較高。
  • 「無需翻譯」的觀察結果解讀仍需人類參與，可能存在主觀性。

Towards Wearable Opportunistic Crowdsensing for Open-Vocabulary Activity Data Collection Through User-Scheduled Trigger-Action Routines
cs.HC 2026-08-06
收集日常生活中豐富標註的可穿戴活動數據一直困難重重，因為回溯性標註成本高昂且常不精確。現有數據收集應用程式依賴勞力密集型的自我報告策略，且主要將參與者視為眾包標註者。本研究提出Pebbl系統，一個可行性階段的系統，透過機會式眾包感知激勵即時標註。Pebbl允許用戶在智能手機上編寫觸發-動作規則，並在檢測到觸發條件時接收即時提醒以執行有益的動作。這不僅降低了標註的認知負荷，也提高了數據的即時性和準確性。主要實驗評估了Pebbl在不同日常活動中的數據收集效率與用戶體驗。結果顯示Pebbl能有效提升可穿戴活動數據的收集質量與用戶參與度。實際意義在於為行為科學、健康監測和個性化推薦系統提供了更精確、更豐富的數據來源。
如何高效且精確地收集日常可穿戴活動數據？
深度點評
  • 方法創新：結合機會式眾包感知與用戶自定義觸發-動作規則，將數據標註從被動任務轉變為主動參與，有效降低了用戶負擔。
  • 比較與進展：相較於傳統回溯性標註或單純自我報告，Pebbl的即時提醒機制顯著提升了數據的即時性與上下文相關性，提高了數據質量。
  • 潛在影響：對行為科學研究、個性化健康管理、以及智慧生活應用中的數據收集方法具有重要啟發，有助於構建更精準的用戶行為模型。
研究貢獻
  • 提出Pebbl系統，實現可穿戴機會式眾包感知。
  • 引入用戶自定義觸發-動作規則，激勵即時數據標註。
  • 提升了日常活動數據收集的效率與精確性。
研究限制
  • 用戶編寫規則的複雜性可能影響普及率。
  • 觸發條件的準確性仍依賴於底層傳感器技術。

No. 03
Efficient Optimal Mouse Sensor Position Estimation using Simulated Cursor Trajectories
cs.HC 2026-08-06
電腦滑鼠上的最佳感測器位置可以顯著提升指向性能，然而現有的校準方法通常需要耗時重複的指向任務。本研究提出一種新穎的校準方法，旨在大幅減少確定用戶最佳滑鼠感測器位置所需的時間和精力。核心問題是如何在不進行大量重複實體測量的情況下，高效估計最佳感測器位置。研究方法利用雙感測器滑鼠模擬不同感測器位置下的游標軌跡，從而無需重複更換感測器位置進行測量。透過分析模擬軌跡的直線度，系統能夠推斷出最符合用戶操作習慣的最佳感測器位置。主要實驗驗證了該模擬方法的準確性與效率。結果顯示本方法能顯著縮短校準時間，同時保持高精確度。實際意義在於提升了滑鼠的人機工程學設計，改善了用戶體驗，特別是對需要精確操作的專業人士。
如何高效且精確地校準滑鼠最佳感測器位置？
深度點評
  • 方法創新：引入模擬游標軌跡來估計最佳感測器位置，避免了傳統方法中耗時的物理重複測量，極大地提高了校準效率。
  • 比較與進展：相較於依賴用戶重複執行指向任務的校準方式，本方法透過數據模擬實現了非侵入式且更快速的優化，是人機互動領域的一大進步。
  • 潛在影響：對滑鼠設計、遊戲外設、以及需要高精度輸入設備的專業領域（如CAD設計、手術模擬）具有重要應用價值，能顯著提升用戶操作效率與舒適度。
研究貢獻
  • 提出基於模擬游標軌跡的滑鼠感測器位置估計方法。
  • 利用雙感測器滑鼠實現不同感測器位置的軌跡模擬。
  • 大幅減少了最佳感測器位置校準所需的時間和精力。
研究限制
  • 模擬的準確性可能受限於用戶的真實操作習慣與模型匹配度。
  • 雙感測器滑鼠的普及性與成本可能是一個考量。

How Usable Are Geospatial Foundation Models? A Systematic Evaluation of 89 Models
cs.HCcs.AI 2026-08-06
地理空間基礎模型（GeoFMs）為環境監測帶來了變革性的潛力，然而生態學家對其採用程度卻不一。大多數評估都以模型為中心，側重於架構和基準準確性，卻忽略了這些系統對目標受眾（生態學家）的可用性。為彌補這一差距，本研究首先對生態學和保育科學家進行了專家啟發式調查，以識別當前GeoFM開發重點與其需求之間的錯位。核心問題是如何系統性地評估GeoFMs的可用性，以促進其在生態學領域的實際應用。研究方法基於調查結果，並結合可用性工程原則，對89個GeoFMs進行了系統性評估。主要實驗包括用戶測試、介面分析和功能評估。結果發現GeoFMs在可用性方面存在顯著差距，特別是在介面直觀性、數據整合和結果解釋方面。實際意義在於為GeoFM的未來開發提供了以用戶為中心的指導，確保技術能真正服務於環境科學家的實際需求。
地理空間基礎模型對生態學家而言可用性如何？
深度點評
  • 方法創新：從用戶可用性角度而非單純模型性能角度評估GeoFMs，透過專家啟發式調查識別真實需求，為AI模型評估提供了新範式。
  • 比較與進展：打破了傳統AI模型評估的技術中心主義，將人機互動和認知負荷納入考量，推動了AI在特定領域的實際落地與應用。
  • 潛在影響：將直接影響GeoFM的設計與開發方向，促使開發者更關注終端用戶的需求，加速AI技術在環境科學等專業領域的普及與有效應用。
研究貢獻
  • 首次對GeoFMs進行系統性可用性評估，涵蓋89個模型。
  • 透過專家調查識別了GeoFM開發與生態學家需求之間的錯位。
  • 為GeoFM的未來開發提供了以用戶為中心的設計指導。
研究限制
  • 可用性評估的結果可能受限於參與調查的專家群體代表性。
  • 評估標準的權重分配可能存在主觀性。

No. 05
ISEE: Interactive Semantic Enrichment for Database Fields
cs.AIcs.HC 2026-08-06
基於大型語言模型（LLM）的代理在數據相關任務中日益普及，包括數據理解、探索和檢索。然而，它們的性能嚴重依賴於數據語義的清晰度和完整性。在實踐中，許多字段描述模糊或不完整，因為許多基本上下文（例如自定義字段的含義）源於用戶的領域知識，很少公開記錄。核心問題是如何彌補LLM代理在處理不完整或模糊數據語義時的性能差距。本研究提出ISEE系統，一個用於數據庫字段的互動式語義豐富工具。ISEE透過結合LLM的能力與用戶的領域知識，實現對數據語義的動態補充和澄清。主要實驗評估了ISEE在實體連結等下游任務中的表現。結果發現ISEE能顯著提升LLM代理在處理語義不完整數據時的任務性能。實際意義在於提高了數據代理的實用性，降低了數據準備的門檻，並促進了人機協作在數據管理中的應用。
如何提升LLM代理處理模糊數據語義的性能？
深度點評
  • 方法創新：透過互動式語義豐富機制，將人類領域知識與LLM能力結合，動態解決數據語義模糊問題，而非僅依賴預訓練知識。
  • 比較與進展：相較於傳統LLM代理在數據理解任務中對清晰語義的強依賴，ISEE提供了一種在實踐中彌補語義鴻溝的有效策略，提升了代理的魯棒性。
  • 潛在影響：對數據管理、商業智能、以及任何需要LLM代理理解複雜領域數據的應用場景都具有重要意義，能加速數據驅動決策的效率。
研究貢獻
  • 提出ISEE系統，實現數據庫字段的互動式語義豐富。
  • 有效結合LLM與人類領域知識，解決數據語義不完整問題。
  • 提升LLM代理在下游數據任務中的性能。
研究限制
  • 互動過程可能增加用戶的認知負荷。
  • 系統的擴展性可能受限於特定領域知識的獲取。

Evaluating OpenAI's Privacy Filter: Cross-Lingual, Cross-Domain PII Detection Across 42 Benchmarks
cs.AIcs.CL
核心問題
OpenAI的隱私過濾器在多語言、多領域的個人身份資訊（PII）檢測表現如何？
方法亮點
首次對OpenAI的隱私過濾器（OPF）進行獨立、系統性評估，該過濾器是一個1.5B參數的雙向PII檢測器。研究在22種語言和5個領域的42個合成基準上進行零樣本測試，並與Presidio和XLM-RoBERTa等模型進行比較，同時也將GPT-4o納入評估。
心理學意涵
本研究對AI系統的隱私保護能力進行了關鍵評估，直接關係到用戶信任和數據倫理。在心理學上，這影響了用戶對AI系統的感知隱私風險，進而影響其使用意願和行為。高效率的PII檢測有助於減少數據洩露帶來的心理壓力與社會危害。然而，不同語言和領域的表現差異也提示了AI系統在普適性方面的挑戰，可能導致特定群體或情境下的隱私保護不足，引發公平性問題。
隱私保護任重道遠，AI過濾器仍需跨語言、跨領域的精進。

JudgeArena: A Unified Framework for Reproducible LLM-Judge Evaluation
cs.AIcs.CL
核心問題
如何建立一個統一且可重現的框架來評估作為評審的LLM？
方法亮點
提出JudgeArena，一個開源框架，旨在統一主流的LLM評審基準（如AlpacaEval, Arena-Hard, MT-Bench）。該框架允許研究者靈活配置基準、評審模型、提示詞和推理後端，以系統性地研究這些設計選擇如何影響模型質量評估的結論。
心理學意涵
LLM作為評審的範式日益普及，其判斷的可靠性直接影響AI模型的發展方向。從心理學角度看，這涉及「判斷與決策」的認知過程，LLM評審可能存在類似人類的偏見（如錨定效應、光環效應），或因提示詞設計而產生系統性偏差。本研究提供了一個工具來探討這些潛在偏差，有助於理解AI評審的「認知機制」，並設計更公平、客觀的評估方法。這對AI倫理、信任構建及心理測量學的AI應用具有重要意義。
統一評審框架，揭示LLM判斷的黑箱，為AI評估注入客觀性。

LLM × 心理學 No.03
Speculative Correction: Draft-then-Refine Decoding for Diffusion Language Models
cs.AIcs.CL
核心問題
擴散語言模型如何透過「先起草後精修」的解碼策略提升生成文本質量？
方法亮點
研究一種簡單即插即用的推理模式：首先生成一個完整的草稿，然後使用雙向擴散對完整響應進行精修。使用LLaDA2.1-Flash和LLaDA2.1-Mini評估了兩種配置，其中Flash-Flash配置測試了同一個模型是否能改進其自身的塊自回歸輸出。

AI寫作模擬人類思維，草稿精修提升文本品質與認知共鳴。

04 / Prompt Engineering × 心理學 精選 TOP 3 PROMPT ENG × PSYCHOLOGY
Prompt × 心理學 No.01
JudgeArena: A Unified Framework for Reproducible LLM-Judge Evaluation
cs.AIcs.CL
Prompt 技術
Prompt Engineering for Evaluation (PEfE)：該框架允許研究者靈活設計和調整用於LLM評審的提示詞，以系統性地研究不同提示詞如何影響LLM對模型輸出的判斷和排名。這包括定義評審標準、提供上下文、以及指定輸出格式等。
心理學概念
判斷偏見 (Judgment Bias) 與 認知負荷 (Cognitive Load)：不同的提示詞設計會引導LLM評審的「注意力」和「推理路徑」，可能引入或減輕特定的判斷偏見。同時，清晰、結構化的提示詞可以降低LLM的「認知負荷」，使其更有效地執行評審任務，減少錯誤。
應用場景
在AI模型開發中，LLM評審已成為重要的評估工具。本研究的框架能幫助開發者優化提示詞，減少評審偏見，確保評估結果的公平性和可靠性。在心理學實務中，這啟發我們思考如何設計更有效的提問或指令，以引導人類或AI在複雜情境下做出更客觀、減少偏見的判斷。例如，在心理諮詢中，如何透過提問引導來訪者進行自我反思，或在教育領域設計提示來促進批判性思維。
提示詞是LLM評審的羅盤，精準導航方能避免偏見之海。

BAP-SQL: Budget-Aware Observation Planning for Agentic Text-to-SQL
cs.AIcs.CL
Prompt 技術
Agentic Prompting (代理式提示) 與 Constraint-based Prompting (基於約束的提示)：BAP-SQL系統中的代理不只是消耗觀察結果，其行動決定了下一步的輸入。這意味著代理需要透過提示詞來規劃其觀察行為，例如估計查詢風險、重寫SQL，並將硬性限制委託給獨立運行時保護。提示詞用於指導代理在預算限制下進行高效的決策和行動規劃。
心理學概念
資源分配 (Resource Allocation) 與 決策制定 (Decision-Making)：代理在執行Text-to-SQL任務時，需要像人類一樣在有限的「預算」（上下文和數據庫工作量）下，決定如何分配資源來獲取最有用的信息。這涉及對潛在風險的評估和權衡，以避免不必要的消耗。這與人類在認知任務中面臨時間或精力限制時的決策過程相似。
應用場景
在智能助理、數據分析自動化等領域，代理需要高效地與數據庫互動。本研究的技術能讓代理在執行複雜查詢時，更智能地規劃步驟，避免資源浪費。對心理學實務而言，這啟發我們思考如何設計AI工具來輔助人類進行資源管理和決策，例如在時間管理應用中，AI如何根據用戶的認知負荷和任務重要性，提供最佳的行動建議，或在臨床決策支持系統中，AI如何幫助醫生在有限信息下做出最佳診斷。
代理智能規劃，預算意識提升決策效率，數據查詢不再盲目。

Prompt × 心理學 No.03
VeriTrace: Human-Like Temporal Exploration Completes Agentic Action Space
cs.AIcs.CL
Prompt 技術
Hypothesis-Driven Prompting (假設驅動提示) 與 Multi-Agent Orchestration (多代理協調)：VeriTrace系統中的Inspector代理能夠像人類一樣進行假設驅動的根本原因分析，這需要透過精心設計的提示詞來引導代理生成假設、規劃探索路徑、並解釋觀察結果。多代理系統則需要提示詞來提示詞來協調不同代理（如生成代理、檢查代理）之間的溝通與任務分配。
心理學概念
問題解決 (Problem-Solving) 與 注意力 (Attention)：現有系統在Verilog RTL生成和調試中面臨瓶頸，部分原因在於其調試行動空間不完整，限制了代理的「注意力」範圍。VeriTrace透過賦予代理類似人類的「時間探索」能力，擴展了其問題解決的策略。這與人類在複雜系統中進行故障排除時，如何選擇性地關注信息、形成假設並測試的認知過程高度相關。
應用場景
在軟硬體開發、系統故障診斷等需要複雜推理和調試的領域，本研究的代理系統能顯著提升自動化調試的效率和準確性。對心理學實務而言，這啟發我們設計AI輔助工具來提升人類的問題解決能力，例如在教育領域，AI如何透過引導式提示幫助學生系統性地分析問題、形成假設並驗證；或在心理治療中，AI如何輔助治療師分析來訪者的行為模式，提供更精準的干預建議。
代理像人一樣探索，假設驅動突破調試瓶頸，問題解決更上一層樓。
