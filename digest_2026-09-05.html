Structure and Implementation of New Practical English Textbooks Driven by Artificial Intelligence
cs.AIcs.HC 2026-09-05
傳統的應用英語教材形式固定，難以適應學習者的個別需求，而人工智慧的發展為教材帶來了革新機會。本研究旨在探討由AI驅動的新型實用英語教材的結構與應用，以提供更具診斷性、推薦性和回饋性的學習系統。研究提出了一個五層架構：知識映射、學習者畫像、任務生成、回饋協調及教師端治理，旨在實現教材的智慧化與個人化。為驗證其有效性，研究團隊在186名非英語專業大學生中進行了為期八週的原型測試。結果顯示，AI驅動的教材能有效提升學習體驗與成效，為未來語言學習材料的發展提供了實證基礎。這項研究為教育科技的創新應用提供了具體範例，並強調了AI在促進個人化學習中的潛力。
如何設計並實施AI驅動的個人化英語教材？
深度點評
  • 本研究提出的五層架構，將知識映射、學習者畫像、任務生成、回饋協調與教師治理整合，為AI教材的設計提供了全面且系統化的方法，超越了單純的內容生成。
  • 相較於現有AI輔助學習系統多專注於單一功能，本研究強調了教材作為一個整體適應性學習系統的實施，並透過原型測試驗證了其在真實教學環境中的可行性。
  • 這項工作對教育心理學領域的影響深遠，特別是在自適應學習、認知負荷管理和學習動機激發方面，為未來AI在語言教育中的應用奠定了基礎。
研究貢獻
  • 提出AI驅動實用英語教材的五層架構
  • 設計並實施了教材原型系統
  • 在大學生群體中進行了為期八週的實證測試
研究限制
  • 研究對象僅限於非英語專業大學生，推廣性有待進一步驗證
  • 未深入探討教師在AI教材協作中的具體角色與挑戰

Do GUI Agents Know When Not to Act? Enabling Conflict-Aware Termination for Multimodal GUI Agents
cs.AIcs.HC 2026-09-05
圖形使用者介面（GUI）代理在執行自然語言指令方面日益普及，然而使用者可能因無心錯誤發出不可行的指令。一個可靠的代理不僅應知如何行動，更應知何時不行動，以避免執行錯誤或不安全的行為。本研究引入了CONFLICTGUI基準測試，旨在探討代理在指令內部衝突和指令與GUI上下文衝突情境下的衝突感知終止能力。透過對多模態GUI代理的評估，研究發現現有代理存在嚴重的執行偏向過度服從問題，即使在不可行任務上表現良好，也常會錯誤地執行衝突指令。這項工作強調了代理在理解使用者意圖和環境限制方面的不足，並為未來設計更安全、更可靠的GUI代理提供了關鍵方向。
GUI代理如何判斷何時不應執行衝突指令？
深度點評
  • 本研究提出的CONFLICTGUI基準測試，創新性地將代理的「不行動」能力納入評估範疇，彌補了現有評估多專注於執行成功率的不足，對代理可靠性研究具有重要意義。
  • 與傳統代理設計僅追求任務完成度不同，本研究從認知心理學角度探討了代理的「判斷力」與「自我限制」能力，揭示了過度服從的潛在風險。
  • 這項工作對人機互動領域的影響是，它促使設計者重新思考AI代理的倫理與安全邊界，特別是在高風險應用中，代理的衝突感知終止能力將成為使用者信任的關鍵。
研究貢獻
  • 引入CONFLICTGUI基準測試以評估代理的衝突感知終止能力
  • 揭示了現有GUI代理在處理衝突指令時的過度服從問題
  • 為設計更可靠、更安全的GUI代理提供了研究方向
研究限制
  • 研究主要集中在特定類型的GUI衝突，未能涵蓋所有潛在的不可行指令情境
  • 提出的解決方案仍處於概念驗證階段，實際部署仍需進一步研究

No. 03
Beyond "Made with AI": Visualizing Provenance Density to Mitigate the Transparency Penalty
cs.HCcs.CYcs.AI 2026-09-05
隨著生成式AI使得精美文本的生產成本極低，使用者已無法單憑流暢度判斷內容的真實性，這導致了「流暢度陷阱」：使用者可能信任流暢的幻覺內容，卻又在得知內容由AI生成後，即使內容準確也傾向於打折。現有的「AI生成」標籤僅揭示作者身份，卻未能展示內容的證據支持。本研究提出「來源密度」（Provenance Density）這一證據視覺化介面，透過顯示文本中已驗證聲明的密度來緩解透明度懲罰。在一項包含81名參與者的使用者研究中，理想化的來源密度介面顯著提升了使用者對AI生成內容的信任度，並有效降低了因AI揭露而產生的負面偏見。這項研究為提升AI內容的透明度和使用者信任提供了創新解決方案。
如何透過視覺化緩解AI內容的「透明度懲罰」？
深度點評
  • 本研究提出的「來源密度」視覺化方法，超越了傳統二元標籤的局限，透過量化證據密度來提升資訊透明度，為AI內容的信任建立提供了更細緻的技術創新。
  • 相較於僅告知「AI生成」可能引發的負面偏見，本研究從認知心理學角度出發，透過提供具體證據支持，有效緩解了「流暢度陷阱」和「透明度懲罰」，展現了對人類信任機制的深刻理解。
  • 這項工作對社會心理學和人機互動領域具有重要影響，特別是在打擊假資訊、建立AI內容公信力方面，為未來AI系統的設計提供了寶貴的實踐指導和倫理考量。
研究貢獻
  • 提出「流暢度陷阱」和「透明度懲罰」概念
  • 設計「來源密度」證據視覺化介面
  • 透過使用者研究驗證了其在提升信任和緩解偏見方面的有效性
研究限制
  • 使用者研究中的「來源密度」介面是理想化的，實際部署可能面臨技術挑戰
  • 研究未深入探討不同文化背景下使用者對「來源密度」的感知差異

Auditing Contextual Bias in Human Ball-Strike Calls Using KBO's Automated Umpiring Transition
cs.CYcs.AI 2026-09-05
長期以來，關於人類裁判在棒球比賽中球-好球判罰存在情境偏見的說法一直備受爭議。本研究利用韓國職棒（KBO）引入自動好球帶系統（ABS）的機會，對這些說法進行了審計。研究使用KBO從2021年至2026賽季的逐球數據，建立模型來預測接近好球帶邊緣的未揮擊球被判為好球的機率，並以2022-2023賽季作為人類裁判的基準線，以2024年及以後的ABS賽季作為診斷基準。研究發現，人類裁判在計數壓力下存在明顯偏見，例如在0-0計數時，判罰好球的機率相對較低。這項研究不僅提供了人類決策偏見的實證證據，也展示了AI系統在揭示和糾正人類行為偏差方面的潛力。
KBO裁判在球-好球判罰中是否存在情境偏見？
深度點評
  • 本研究利用KBO引入ABS系統作為自然實驗，提供了一個獨特的機會來量化和審計人類裁判的決策偏見，其方法學創新性在於利用AI系統作為客觀基準。
  • 相較於以往多依賴觀察或問卷調查來推斷偏見，本研究透過大規模數據分析，精確識別並量化了人類裁判在不同情境（如計數壓力）下的判罰偏差，提升了研究的實證嚴謹性。
  • 這項工作對行為科學和社會心理學領域具有重要影響，特別是在理解壓力、情境因素對人類決策的影響方面，並為體育、法律等領域引入AI輔助決策提供了有力支持。
研究貢獻
  • 利用KBO的ABS系統作為基準審計人類裁判偏見
  • 透過逐球數據建模分析人類裁判的判罰機率
  • 發現人類裁判在計數壓力下存在顯著的判罰偏見
研究限制
  • 研究僅限於棒球比賽的球-好球判罰，結果的普適性有待其他領域驗證
  • 模型可能無法完全捕捉所有影響人類裁判決策的複雜情境因素

From Misconceptions to Evidence: What Science Teachers Make Visible When Co-Designing Agentic Learning Apps
cs.HCcs.AI 2026-09-05
科學教育者日益接觸到能生成內容的AI工具，然而學科教學的本質在於引導學習者建構模型、診斷迷思概念、解釋證據並保留專業判斷。本研究旨在探討科學教師如何將這些認知工作轉化為代理式學習應用程式的具體規範。研究透過共同設計（co-design）的方式，觀察教師在設計過程中如何將其專業知識和教學策略融入AI應用。這項工作不僅探討了AI在教育領域的潛力，也強調了教師在AI工具開發中的關鍵作用，特別是在確保AI工具能有效支援學生從迷思概念轉向基於證據的理解。研究結果對教師專業學習和科學學習的轉型具有重要啟示。
教師如何將專業知識轉化為AI學習應用的設計規範？
深度點評
  • 本研究透過共同設計方法，深入探討了教師在AI學習應用開發中的主動角色，這超越了將教師視為AI工具被動使用者的傳統觀點，強調了人機協作的深度與複雜性。
  • 相較於多數AI教育研究專注於技術本身，本研究從教育心理學和認知科學角度，聚焦於教師如何將診斷迷思概念、解釋證據等高階認知教學策略融入AI設計，展現了對教學本質的深刻理解。
  • 這項工作對教育科技領域的影響是，它為未來AI學習工具的設計提供了以教師為中心的視角，強調了AI應作為輔助工具，而非取代教師的專業判斷，有助於促進更有效和倫理的AI教育應用。
研究貢獻
  • 探討科學教師在共同設計代理式學習應用程式中的角色
  • 分析教師如何將專業知識和教學策略轉化為AI應用規範
  • 為教師專業學習和AI教育工具開發提供實踐指導
研究限制
  • 研究對象僅限於科學教師，結果的普適性有待其他學科驗證
  • 共同設計過程的複雜性可能導致結果難以完全量化和推廣

LLM × 心理學 No.01
Caught in the Story: Narrative Captivity in Multi-turn LLMs Conversation
cs.CLcs.AIcs.CY
核心問題
敘事如何影響LLM在多輪道德諮詢中的判斷？
方法亮點
研究透過多輪對話情境，讓大型語言模型（LLMs）在沒有明確反對意見的情況下，僅透過敘事來影響其道德判斷。實驗設計模擬了現實世界中尋求建議的過程，而非單純的單輪判斷或壓力反駁，以評估敘事對模型判斷的潛在轉變。
心理學意涵
這項研究揭示了大型語言模型在處理道德諮詢時，可能受到「敘事俘虜」的影響，即單純的敘事內容就能潛移默化地改變其判斷。這對心理學理論而言，挑戰了傳統上認為理性決策應基於客觀事實的觀點，並強調了敘事在認知和說服中的強大作用。在實務應用上，這意味著AI在提供心理健康支持或道德建議時，其輸出可能無意中被使用者敘事中的情感或偏見所引導，從而產生不客觀的建議。這也引發了重要的倫理議題，例如AI在多大程度上應被允許受人類情感敘事影響，以及如何設計AI以抵抗潛在的操縱或偏見，確保其建議的公正性與客觀性。
當AI被故事俘虜，其道德羅盤是否還能指引正確方向？

LLM × 心理學 No.02
Bounded Personas Match Retrieval on Classification but Not Regression for a Frozen Agent
cs.AIcs.CL
核心問題
有界人格（Bounded Personas）在何種任務上能與檢索策略匹敵？
方法亮點
本研究比較了兩種個性化語言代理策略：檢索（Retrieval）和蒸餾（Distillation）。檢索策略將使用者相關歷史項目拉入提示，而蒸餾策略則將歷史壓縮成緊湊的自然語言人格。研究在分類和回歸任務上評估了這些策略，以探討有界人格在不同任務類型下的表現，特別是其在準確性與計算成本之間的權衡。
心理學意涵
這項研究深入探討了AI代理「人格化」的有效性及其對行為的影響，對社會心理學中關於身份、角色和人際互動的理論提供了新的視角。透過將使用者歷史壓縮成「有界人格」，AI能夠以更一致且可解釋的方式回應，這在心理諮詢、教育輔導等需要長期互動的應用中具有巨大潛力。然而，研究也指出這種人格化在某些任務（如回歸）上可能犧牲準確性，這提示我們在設計AI人格時需權衡其解釋性與效能。此外，AI人格的設計也引發了倫理問題，例如人格的真實性、對使用者心理的影響以及潛在的操縱風險，需要謹慎考量。
人格化AI，效率與精準的雙刃劍，需在任務類型中尋求平衡。

LLM × 心理學 No.03
DuplexSpeechBench-IFEval: Evaluating Implicit Instruction Following in Full-Duplex Voice Agents
cs.AIcs.HCcs.CL
核心問題
如何評估全雙工語音代理的隱式指令遵循能力？
方法亮點
本研究引入了DuplexSpeechBench-IFEval (DSB-IFEval) 基準測試，用於評估全雙工語音代理在實時語音互動中遵循隱式指令的能力。該基準測試包含1,038個測試案例，旨在測試代理如何根據角色或人設推斷適當的對話行為，例如何時傾聽、何時打斷、何時接話或讓話，而非僅依賴明確的轉向管理指令。
心理學意涵
這項研究對於理解和改進人機語音互動中的「社會智能」至關重要，直接關聯到社會心理學和認知心理學中關於溝通、角色扮演和非語言線索的理論。全雙工語音代理若能有效遵循隱式指令，將極大提升使用者體驗，使其感覺與AI的互動更自然、更像人類。這在心理健康支持、教育輔導或客服等需要高度共情和流暢對話的應用場景中具有巨大潛力。然而，代理對隱式指令的誤解也可能導致溝通障礙或不適，甚至引發使用者對AI意圖的誤判，因此，確保AI能準確理解人類語境和社會規範，是未來發展中必須解決的倫理與技術挑戰。
語音代理的隱式理解，是人機對話從「聽懂」到「心領神會」的關鍵一步。

Prompt × 心理學 No.03
Where Does Harness-Optimization Value Live? Localized Gains and the Budget-Splitting Trap in Self-Evolving LLM Agents
cs.AIcs.CL
Prompt 技術
分槽式提示優化（Slotted Prompt Optimization）：本研究將大型語言模型（LLM）代理的「線束」（harness，即圍繞模型的文本支架，包括人設、策略、格式規則和控制啟發式）分解為四個可獨立演化的槽位：角色（role）、任務策略（task-strategy）、工具/格式規則（tool/format-rules）和反思/控制（reflection/control）。這種方法允許對提示的不同部分進行局部優化，而非將其視為一個扁平的字符串。
心理學概念
認知架構（Cognitive Architecture）與人格（Persona）：論文中的「線束」和「角色」槽位直接關聯到AI代理的認知架構和其所扮演的人格。透過優化這些提示元素，研究旨在提升AI代理的決策效率和行為一致性，這與人類在不同情境下調整其角色和策略以優化表現的心理過程相似。
應用場景
當前，這種分槽式提示優化方法已用於提升LLM代理在複雜任務中的表現，例如自動化程式碼生成或複雜問題解決。未來，它有望應用於設計更具適應性和情境感知能力的AI代理，例如在心理健康輔導中，AI可以根據不同的諮詢階段或使用者情緒，動態調整其「角色」和「策略」提示，以提供更精準和共情的回應。這對心理學實務的啟發是，透過精細化AI的「人格」和「行為策略」提示，我們可以更有效地引導AI在特定心理情境下發揮作用，同時也需警惕過度優化可能導致的行為僵化或倫理風險。
拆解AI的「人格」提示，精準優化其行為，讓智能更具彈性。
