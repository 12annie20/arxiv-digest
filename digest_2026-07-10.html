AgentLens: Production-Assessed Trajectory Reviews for Coding Agent Evaluation
cs.AI 2026-07-10
傳統的程式碼代理人基準測試多半只關注任務是否通過，忽略了使用者與代理人互動的完整過程。本研究提出了AgentLens，一個以生產評估為基礎的基準測試，旨在全面評估程式碼代理人的運行軌跡。AgentLens結合了形式驗證與大型語言模型撰寫的軌跡評論，並進行了並排比較。透過這種方式，它能評估代理人如何遵循指令、使用工具、自我驗證、從錯誤中恢復以及與使用者溝通。這項研究強調了從單一結果評估轉向全面軌跡評估的重要性，為開發更實用、更符合人類體驗的代理人提供了新視角。
如何全面評估程式碼代理人的互動軌跡與效能？
深度點評
  • 方法創新：AgentLens結合了形式驗證與LLM生成的軌跡評論，提供了一種更細緻、更貼近真實使用者體驗的評估方法，超越了傳統的二元通過/失敗判斷。
  • 與既有研究比較：相較於現有僅關注最終結果的基準測試，AgentLens更深入地分析了代理人的決策過程、錯誤恢復能力及與使用者的互動品質，填補了評估維度上的空白。
  • 潛在影響：這項研究將推動代理人AI的評估標準從單純的技術指標轉向以使用者為中心的體驗指標，有助於開發出更可靠、更人性化的AI代理人。
研究貢獻
  • 提出AgentLens基準測試，用於全面評估程式碼代理人的運行軌跡。
  • 結合形式驗證與LLM撰寫的軌跡評論，提供多維度評估。
  • 強調代理人與使用者互動過程的重要性，而非僅限於最終結果。
研究限制
  • LLM撰寫評論的客觀性與一致性可能受模型本身偏見影響。
  • 評估過程的複雜性可能增加資源消耗與實施難度。

知識工作者每天在不同應用程式間切換數千次，這種「數位碎片化」現象導致他們將近十分之一的工作時間耗費在應用程式轉換上。然而，這種碎片化是否反映了員工的個人特質、工作環境或當天狀態，仍是一個未解之謎。本研究分析了來自八個組織、1,017名員工的1.03億個應用程式事件，這些事件以秒為單位記錄。研究發現，日常的數位碎片化程度與員工的認知負荷和工作滿意度之間存在顯著關聯。此外，生成式AI工具的使用模式也對碎片化程度產生影響，為理解數位工作環境下的行為模式提供了寶貴見解。
數位碎片化與生成式AI使用如何影響知識工作者的工作行為與體驗？
深度點評
  • 方法創新：透過分析大規模、高頻率的真實應用程式使用數據，本研究提供了對數位碎片化現象的量化洞察，超越了傳統的問卷調查或小規模實驗。
  • 與既有研究比較：將數位碎片化與生成式AI使用結合分析，揭示了新興AI工具對工作流程和認知負荷的影響，為人機互動領域提供了前瞻性視角。
  • 潛在影響：研究結果對企業優化工作流程、設計更高效的數位工具以及提升員工福祉具有直接指導意義，有助於緩解數位化帶來的負面影響。
研究貢獻
  • 首次大規模量化分析知識工作者的數位碎片化行為。
  • 揭示數位碎片化與認知負荷、工作滿意度之間的關聯。
  • 探討生成式AI使用對數位碎片化模式的影響。
研究限制
  • 數據來源主要為知識工作者，結果可能不完全適用於其他職業群體。
  • 研究僅觀察到相關性，未能完全建立因果關係。

哪種物件選擇技術最適合低視力人群在AR環境中使用？
深度點評
  • 方法創新：本研究針對低視力人群這一特定群體，系統性地比較了AR中三種主流物件選擇技術，填補了該領域的實證空白。

  • 潛在影響：研究結果將直接指導無障礙AR介面的設計，提升低視力人群使用AR技術的便利性和效率，促進數位包容。
研究貢獻
  • 首次比較低視力人群在AR中不同物件選擇技術的表現。
  • 評估頭部、凝視和手指選擇技術在準確性、速度和使用者體驗方面的差異。
  • 為設計無障礙AR介面提供了實證依據。
研究限制

如何透過跨感官設計創造更具恢復性的虛擬實境環境？
深度點評
  • 方法創新：本研究超越了傳統單一感官或簡單疊加感官的設計，提出「跨感官」協同作用的理念，為VR環境的沉浸感和療癒效果提供了更深層次的理解。
  • 與既有研究比較：相較於僅關注視覺或將多感官視為獨立元素的設計，本研究強調感官間的整合與交互作用，更符合人類感知的整體性。
  • 潛在影響：這項研究將推動VR在心理健康、壓力管理和環境設計領域的應用，為創造更有效、更個人化的數位療癒體驗奠定基礎。
研究貢獻
  • 提出一種新的跨感官設計方法，用於創造恢復性虛擬環境。
  • 探索視覺、聽覺和嗅覺等感官如何協同作用以增強療癒效果。
  • 為VR在心理健康和壓力管理領域的應用提供了實證支持。
研究限制
  • 感官交互作用的機制仍需更深入的神經科學研究來闡明。
  • 個體對不同感官刺激的反應存在差異，設計的普適性可能受限。

LLM如何賦能代理人基模型以預測人類決策並適應實時變化？

LLM × 心理學 No.02
LLMs Silently Correct African American English: Auditing and Mitigating Dialect Bias via Activation Steering
cs.AIcs.CL
核心問題
大型語言模型是否系統性地將非裔美國英語「糾正」為標準美國英語，以及如何審計和緩解這種偏見？
方法亮點
研究發現六個主流LLM（14B至70B）在非裔美國英語（AAE）語境下，系統性地偏好標準美國英語（SAE）的續寫，實質上改寫了AAE。為審計和緩解此偏見，研究引入了條件方言群體不變性（cDGI）框架，並透過激活引導（Activation Steering）技術來調整模型行為，以減少這種方言偏見。
心理學意涵
本研究揭示了LLM中潛在的語言偏見，這對社會心理學和語言心理學具有重要啟示。它表明AI系統可能無意中強化社會刻板印象和語言歧視，影響特定群體的數位體驗和自我表達。這種「無聲糾正」可能導致使用者對AI產生不信任感，甚至影響其身份認同。研究提出的緩解方法，為設計更具文化敏感性和公平性的AI提供了方向，有助於減少數位鴻溝和促進語言多樣性。
LLM無聲的語言「糾正」揭示深層文化偏見，急需AI倫理與公平性介入。

LLM × 心理學 No.03
MILES: Modular Instruction Memory with Learnable Selection for Self-Improving LLM Reasoning
cs.AI
核心問題
如何讓LLM在處理連續問題時，透過可學習的模組化指令記憶來自我改進推理能力？
方法亮點
本文提出MILES（Modular Instruction Memory with Learnable Selection），一個模組化指令記憶系統，旨在讓LLM在處理連續問題時累積可重複使用的經驗。與現有方法不同，MILES不儲存完整的解決方案模板，而是透過可學習的選擇策略來優化最終答案的正確性，從而實現自我改進的推理。
心理學意涵
這項研究對認知心理學中的學習與記憶理論有重要啟發。它模擬了人類在解決問題時，如何從過往經驗中提取相關知識並應用於新情境。MILES的「可學習選擇」機制類似於人類的元認知能力，即知道何時以及如何運用所學知識。這有助於我們理解AI如何發展出更複雜的認知策略，並為設計能像人類一樣從經驗中持續學習和改進的AI系統提供了新的視角。
模組化記憶讓LLM學會「舉一反三」，推理能力更上一層樓。

Prompt × 心理學 No.01
When Does In-Context Search Help? A Sampling-Complexity Theory of Reflection-Driven Reasoning
cs.AIcs.CL
Prompt 技術
In-Context Search (ICS) / Reflection-Driven Reasoning。模型在生成解決方案後，會迭代地進行批判和修改，透過自我反思提供回饋，更新後驗分佈，以提高成功機率。
心理學概念
反思性推理 (Reflective Reasoning) 與認知負荷 (Cognitive Load)。ICS模擬了人類在解決複雜問題時的試錯與反思過程，透過迭代修正來優化決策。這有助於降低單次推理的認知負荷，並在多次嘗試中逐步逼近最佳解。
應用場景
