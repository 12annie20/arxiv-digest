"I Felt Very Seen, But Still Very Alone": Longitudinal Trajectories of General-Purpose LLM Use for Socioemotional Support
cs.HCcs.CL
隨著ChatGPT、Claude和Gemini等通用聊天機器人日益普及，人們開始將其用於心理健康和情感支持。本研究透過一項多階段的長期質性研究，追蹤了18位美國成年人從2025年4月至12月使用LLM尋求社會情感支持的歷程。研究結合了初步訪談、為期四週的日記研究、焦點小組和離職訪談等多種方法。結果發現，社會情感用途通常是從實用性用途中逐漸演變而來，尤其是在其他支持形式不可用時。參與者圍繞聊天機器人使用建立了例行程序和界限，但這些會因模型更新而受到干擾。儘管LLM提供了被看見的感覺，但無法完全取代人類連結，使用者仍感到孤獨。這項研究為理解AI在心理健康支持中的複雜角色提供了深入見解，並對未來設計提出建議。
人們如何長期使用通用LLM尋求社會情感支持，其體驗與影響為何？
深度點評
  • 本研究採用了嚴謹的多階段長期質性研究設計，結合多種數據收集方法，深入捕捉了使用者與LLM互動的動態歷程，彌補了過往研究多為橫斷面分析的局限。
  • 相較於僅關注LLM效能的技術導向研究，本研究更側重於使用者主觀體驗和情感層面，揭示了LLM在提供支持時「被看見但仍孤獨」的複雜心理狀態，為人機情感互動理論提供了新視角。
  • 研究結果對心理健康領域的AI應用設計具有重要啟示，強調了在開發AI支持工具時，需平衡其便利性與人類連結的不可替代性，並考慮模型更新對使用者習慣的影響。
研究貢獻
  • 首次對通用LLM用於社會情感支持進行長期質性研究，揭示了使用模式的演變。
  • 提出了「被看見但仍孤獨」的核心使用者體驗，深入剖析了AI情感支持的雙面性。
  • 為AI心理健康應用設計提供了基於使用者經驗的實證建議，強調了人機協作的重要性。
研究限制
  • 研究樣本量相對較小（18位美國成年人），可能限制了結果的普遍性，尤其是在不同文化背景下。
  • 質性研究的結果解釋可能受研究者主觀性影響，且難以量化AI支持的具體效果。

Synthetic TLX: Forecasting Human Workload Using Agent Simulation
cs.AIcs.HC
評估技術介導任務中的人類工作負載對於預防因不良技術設計導致的任務失敗至關重要。傳統上，工作負載是透過NASA任務負載指數（TLX）在人類完成任務後進行回溯性評估。本研究提出了一個新穎的範式：Synthetic TLX，旨在利用代理模擬在人類嘗試任務之前預測工作負載。這種前瞻性的工作負載估計方法，有望開啟新的互動機會和評估方法。為了驗證其可行性，研究人員進行了一系列實驗，比較了Synthetic TLX與傳統TLX評估結果的一致性。結果顯示，代理模擬能夠有效預測人類的工作負載，為設計更符合人體工學的技術系統提供了潛力。這項研究為人機互動設計和認知心理學領域帶來了新的工具和視角。
如何利用代理模擬在人類執行任務前預測其工作負載？
深度點評
  • 本研究的核心創新在於將傳統上依賴人類回溯報告的NASA TLX評估，轉化為基於AI代理模擬的預測模型，這在方法論上是前瞻性的，能大幅提升工作負載評估的效率和時效性。
  • 相較於現有的人機互動評估方法，Synthetic TLX提供了一種在設計階段就能預測潛在認知負荷的工具，有助於在早期迭代中發現並修正設計缺陷，而非等到實際部署後才進行補救。
  • 這項技術的潛在影響巨大，不僅能應用於軟體介面設計，還能擴展到自動駕駛、航空控制等高風險領域，透過預測操作員的工作負載來提升系統安全性和效率。
研究貢獻
  • 提出了Synthetic TLX範式，實現了人類工作負載的前瞻性預測。
  • 開發了基於代理模擬的工作負載估計方法，並驗證了其可行性。
  • 為技術設計和人機互動領域提供了新的評估工具和優化策略。
研究限制
  • 代理模擬的準確性高度依賴於其對人類認知過程和行為的建模精確度，可能無法完全捕捉所有複雜的人類反應。
  • 目前的研究可能僅限於特定類型的任務，其在廣泛任務場景下的泛化能力仍需進一步驗證。

"People can change, and patterns can be broken": Contextualizing Tradeoffs in Automated Decision-Making Systems
cs.CYcs.AI
自動化決策系統（ADM）在抵押貸款、監獄判決、健康保險和招聘等高風險領域的部署日益增多。在這些領域設計負責任的ADM系統，需要確保隱私保護、跨人口群體的公平性以及對抗性操縱的穩健性。然而，優先考慮其中一個目標往往會以犧牲另一個為代價，這使得在部署時必須權衡取捨。這些權衡明確或隱含地影響著人們的生活、安全和福祉。本研究透過深入分析和案例研究，探討了ADM系統中這些不可避免的權衡，並強調了在設計和部署過程中，應如何考慮「人會改變，模式會被打破」這一核心原則。研究呼籲設計者和政策制定者，在面對這些複雜的倫理困境時，需採取更具情境意識和以人為本的方法。
如何在自動化決策系統中權衡隱私、公平與穩健性，並考慮人類變化的可能性？
深度點評
  • 本研究超越了單純的技術優化，深入探討了ADM系統在社會倫理層面的複雜權衡，特別是其對個人生活和社會公平的深遠影響，這在AI倫理研究中具有高度的現實意義和前瞻性。
  • 論文提出的「人會改變，模式會被打破」的觀點，挑戰了基於歷史數據進行決策的ADM系統的固有假設，強調了動態性和個體差異，這與傳統的靜態模型分析形成了鮮明對比。
  • 這項研究對政策制定者、AI開發者和社會科學家都具有重要啟示，它不僅指出了ADM系統的技術局限，更呼籲在設計和部署時融入更深層次的社會和心理學考量，以避免加劇現有不平等或產生新的社會問題。
研究貢獻
  • 系統性地闡述了ADM系統中隱私、公平和穩健性之間的內在權衡。
  • 引入了「人會改變，模式會被打破」的視角，強調了ADM系統設計中動態和個體差異的重要性。
  • 為高風險領域的ADM系統設計和政策制定提供了倫理框架和情境化考量。
研究限制
  • 論文可能更多地停留在概念和框架層面，缺乏具體的技術解決方案來量化或緩解這些權衡。
  • 「人會改變」的複雜性難以在現有數據驅動的ADM系統中有效建模，這是一個巨大的技術挑戰。

Mindspeller Neuroprofiling. How task performance, EEG, and association evidence support O*NET-based role guidance
cs.AIcs.HC
Mindspeller透過三種來源生成神經檔案（Neuroprofile）：理性自我報告、基於聯想的語義定位，以及認知任務期間記錄的表現和腦電圖（EEG）數據。其中，任務表現和EEG數據是唯一用於創建職業證據的來源。只有當參與者的任務表現支持預期構念且相應的EEG數據通過所需的質量和證據檢查後，結果才能進入角色匹配。目前的試點研究使用了四個EEG電極、十二個評分任務、23個O*NET能力指標，以及一個整合的評估框架。這項研究旨在探索如何將神經生理數據與行為表現相結合，為個人提供更精準的職業指導，超越傳統的自我報告問卷。它為職業心理學和人機介面領域開闢了新的研究方向。
如何結合任務表現、EEG和聯想證據來支持基於O*NET的職業指導？
深度點評
  • 本研究將神經生理學（EEG）數據與認知任務表現相結合，為職業指導提供客觀證據，這在傳統上依賴自我報告的職業心理學領域是方法學上的重大創新，提升了評估的客觀性和精準度。
  • 相較於僅基於問卷或行為觀察的職業評估，Mindspeller的Neuroprofiling方法透過多模態數據融合，能夠更全面地捕捉個體的認知能力和潛在傾向，為個人化職業匹配提供了更深層次的洞察。
  • 這項技術的潛在影響是巨大的，它不僅能幫助個人做出更明智的職業選擇，也能為企業在人才招聘和發展方面提供科學依據，甚至可能影響教育體系對學生潛能的早期識別和培養。
研究貢獻
  • 提出了結合自我報告、聯想證據、任務表現和EEG數據的多模態神經檔案生成方法。
  • 開發了基於任務表現和EEG數據的職業證據創建流程，並與O*NET能力指標結合。
  • 為職業心理學和人才評估領域提供了更客觀、精準的AI輔助工具。
研究限制
  • 目前的試點研究僅使用了四個EEG電極，可能無法捕捉到大腦活動的所有細微之處，限制了神經證據的全面性。
  • 將EEG數據與複雜的職業能力構念建立可靠的因果或相關性，仍需大量的實證研究和驗證，且存在解釋過度的風險。

Informational Help-Seeking on Reddit Did Not Decline After ChatGPT
cs.CLcs.CYcs.HC
自生成式AI如ChatGPT問世以來，人們是否停止在網路上向他人尋求建議？先前關於ChatGPT對線上求助行為影響的研究，在影響程度和方向上存在分歧，部分原因是缺乏將受影響社群與AI難以替代的類似社群進行同期比較的分析。本研究追蹤了ChatGPT推出前後六個月內，26個Reddit資訊型社群與90個規模相當的興趣型社群的每月發文量。研究發現，資訊型社群的求助發文量並未因ChatGPT的出現而下降，甚至在某些情況下略有增加。這表明，儘管AI提供了便捷的資訊獲取途徑，但人類在特定情境下仍傾向於尋求人際互動和社群支持。這項研究對社會心理學、人機互動和線上社群行為具有重要啟示。
ChatGPT推出後，Reddit上的資訊型求助行為是否有所下降？
深度點評
  • 本研究採用了嚴謹的對照組設計，比較了ChatGPT推出前後資訊型社群與興趣型社群的發文趨勢，有效排除了其他時間因素的干擾，提升了研究結果的內在效度。
  • 相較於許多預測AI將取代人類互動的悲觀論調，本研究提供了實證數據，表明在資訊獲取方面，AI與人類社群可能存在互補而非完全替代的關係，這為理解AI的社會影響提供了更 nuanced 的視角。
  • 這項發現對線上社群管理、AI產品設計以及社會心理學中關於求助行為的理論具有重要意義，提示設計者在開發AI工具時，應考慮其與現有社會支持系統的整合，而非單純的替代。
研究貢獻
  • 首次透過對照組設計，實證分析了ChatGPT對Reddit資訊型求助行為的影響。
  • 發現ChatGPT推出後，線上資訊型求助行為並未下降，挑戰了AI替代人類互動的普遍預期。
  • 為理解AI時代的線上社群動態和人類求助行為提供了新的經驗證據。
研究限制
  • 研究僅限於Reddit平台，其結果可能不完全適用於其他類型的線上社群或求助場景。
  • 發文量作為求助行為的代理指標，可能無法完全捕捉求助的質量或深度，也未能探究使用者在AI與人類之間選擇的具體動機。

Creating an Atomic User Model for Personality-Aware Large Language Model Interaction
cs.AIcs.CLcs.HC
核心問題
如何建立一個原子級使用者模型，使大型語言模型能感知並模仿使用者的個性？
方法亮點
本研究提出了一種「原子級使用者模型」方法，旨在捕捉使用者相對穩定的個性結構，而非僅僅是任務相關的偏好。它首先定義了「個性滲透」（personality seepage）現象，即提示詞的語言表面攜帶的個性指紋。透過分析對話歷史中的語言特徵，系統能夠推斷並儲存使用者的個性特徵，進而使LLM在不同任務中都能保持一致的個性化回應。
心理學意涵

LLM × 心理學 No.02
R2VC: Modular Fact-Checking with Retrieval, Verification, and Confidence Calibration
cs.AIcs.CL
核心問題
如何透過模組化架構提升大型語言模型的事實核查能力、診斷失敗原因並校準置信度？
方法亮點
R2VC（Retrieve, Reason, Verify, Calibrate）是一個模組化的事實核查架構，它將證據檢索、推理、驗證和不確定性估計分開處理。該系統結合了維基百科上的混合稀疏+密集檢索，一個經過監督微調和DPO對齊的生成器，用於產生多樣化的結構化判斷候選。這種模組化設計使得系統能夠提供帶有引用的證據支持，並在無法確定時選擇棄權，從而提高事實核查的透明度和可靠性。
心理學意涵
這項研究對於認知心理學中的推理和決策過程具有啟發性，特別是關於人類如何處理不確定性和評估資訊來源。R2VC的模組化方法可以類比人類在進行事實核查時，分階段進行資訊檢索、評估和判斷的認知過程。在教育心理學中，這種透明且可校準的事實核查系統，有助於培養批判性思維和媒體素養。然而，過度依賴AI進行事實核查可能導致人類批判性思考能力的退化，以及AI系統本身可能存在的偏見傳播問題。

LLM × 心理學 No.03
The Cost of Compression: A Rate-Distortion Limit on Factual Hallucination
cs.AIcs.CL
核心問題
除了資訊覆蓋不足，有限記憶壓縮如何導致大型語言模型的事實性幻覺？
方法亮點
本研究透過一個簡單的覆蓋-壓縮模型來探討事實性幻覺的第二個來源：即使事實已被觀察到，有限的記憶也可能迫使其只能近似儲存。研究考慮了一個非結構化問答任務，其中有N個可能的查詢和K個可能的答案。學習者觀察M個訓練事實，然後將其壓縮到有限的記憶中。這種模型揭示了記憶壓縮與事實性幻覺之間的率失真（rate-distortion）限制關係，即在記憶容量有限的情況下，錯誤是不可避免的。
心理學意涵
這項研究對認知心理學中的記憶理論和資訊處理模型提供了新的視角。它將LLM的幻覺現象與人類記憶的壓縮和失真機制進行類比，暗示了在有限認知資源下，錯誤是資訊處理的內在成本。這有助於我們理解人類在記憶和回憶資訊時可能出現的偏差和錯誤。在教育心理學中，這提醒我們在學習和記憶新知識時，過度壓縮或簡化資訊可能導致理解上的偏差。同時，這也對AI系統的可靠性提出了根本性挑戰，即在追求效率和壓縮時，如何平衡事實的準確性。
幻覺非偶然，記憶壓縮的代價，是AI與人類共同的認知宿命。

Prompt Editing (提示編輯) 與 Replay-Informed Policy Adaptation (回放資訊策略適應)。研究探討了對代理模型提示進行局部編輯如何影響其生成工作流程的整體行為。它利用過去的執行回放數據來指導提示編輯，以預測和管理編輯可能帶來的「漣漪效應」，即局部修改導致的全局行為變化，並解決編輯之間的潛在衝突。
心理學概念
認知負荷 (Cognitive Load) 與決策偏差 (Decision Bias)。在人類決策中，局部修改一個規則可能導致意想不到的後果，這與本研究中提示編輯的「漣漪效應」相似。對於設計者而言，理解這種全局影響有助於降低在調整AI行為時的認知負荷，避免因未能預見的交互作用而產生決策偏差。此外，編輯的「組成敏感性」也反映了人類在複雜系統中調整策略時，不同規則組合可能導致的非線性結果。
應用場景
這項技術當前主要應用於優化自動化代理的工作流程生成，例如在軟體開發中，透過編輯提示來改進程式碼生成代理的行為。未來，它在智能輔助系統中具有巨大潛力，例如在醫療診斷或法律諮詢中，透過精確調整AI的推理提示，使其決策更符合特定情境或倫理規範。對心理學實務的啟發是，理解AI行為調整的複雜性，有助於心理學家在設計人機協作系統時，更有效地引導AI行為，並預防潛在的系統性錯誤或偏見，確保AI輔助決策的可靠性。
提示編輯如蝴蝶效應，局部微調，全局震盪，AI行為管理需深思熟慮。

GAUGE: When Not to Trust LLM-as-a-Judge in User-Simulated Evaluation of Task-Oriented Agents
cs.AIcs.CL
Prompt 技術
LLM-as-a-Judge (LLM作為評審) 與 Persona-driven LLM User-simulators (角色驅動的LLM使用者模擬器)。本研究利用LLM模擬使用者與任務導向代理進行對話，再由另一個LLM充當評審來評分對話轉錄。GAUGE協議旨在評估這種「LLM作為評審」方法的有效性，特別是其在不同代理和基準測試下的可靠性，以判斷何時不應信任其評分。
心理學概念
判斷與決策 (Judgment and Decision-Making) 及偏見 (Bias)。LLM作為評審的行為，可以類比人類評審的判斷過程，但其判斷可能受到提示設計、訓練數據和內在偏見的影響。研究探討了這種自動化評審的「評估有效性」，即其評分是否能真實反映代理的表現，這與心理測量學中對測量工具信度和效度的考量高度相關。理解LLM評審的局限性，有助於避免因錯誤評估而導致的決策偏差。
應用場景
目前，LLM作為評審廣泛應用於任務導向型AI代理的快速迭代和評估，例如聊天機器人或虛擬助手的性能測試。未來，這項技術有望擴展到更廣泛的AI系統評估，例如評估AI在教育、醫療等領域的表現。對心理學實務的啟發是，當我們將AI用於評估人類行為或心理狀態時（例如AI輔助診斷），必須深入理解AI評估機制的內在局限和潛在偏見，確保評估結果的公正性和可靠性。GAUGE提醒我們，即使是AI評審，也需要被「審查」。
LLM評審雖高效，但其判斷力仍需GAUGE嚴格校準，盲目信任恐誤導AI發展。
