RadOnc-Agent: An LLM-Orchestrated Framework for AI Workflows Across the Radiotherapy Care Pathway
cs.AIcs.HC 2026-10-08
儘管人工智慧在個別放射治療任務上有所進展，但這些能力在臨床階段、軟體環境和數據模式之間仍是分散的。本研究旨在解決這種碎片化問題，提出RadOnc-Agent，一個代理式人工智慧框架，將放射治療流程形式化為四個臨床階段。該框架透過對話介面提供26個可調用功能，並由大型語言模型控制器將臨床意圖映射到這些功能。研究展示了RadOnc-Agent如何整合AI能力，實現從治療決策到後續追蹤的縱向放射治療工作流程。這項工作為臨床決策支援和醫療工作流程自動化提供了統一的解決方案，有望提升放射治療的效率與精準度。
如何整合AI能力以優化放射治療的端到端工作流程？
深度點評
  • RadOnc-Agent透過LLM協調多個AI功能，將放射治療流程標準化為可操作的階段，這在整合複雜醫療AI應用方面是個創新。
  • 相較於現有分散的AI工具，本框架提供了一個統一的對話式介面，顯著降低了臨床人員的操作複雜度，提升了易用性。
  • 此框架有望加速AI在臨床放射治療中的實際落地，特別是在決策支援和工作流程自動化方面，具有巨大的潛力。
研究貢獻
  • 提出RadOnc-Agent框架，整合AI能力於放射治療全流程。
  • 透過LLM控制器實現臨床意圖到AI功能的映射。
  • 提供26個可調用功能，支援從決策到追蹤的縱向工作流程。
研究限制
  • 框架的實際臨床驗證和長期效果仍需進一步研究。
  • 對話介面的魯棒性和安全性在真實高風險醫療環境中仍是挑戰。

Tellimation: Making Narrative Gaps Visible in Children's Storytelling with Just-in-Time Animation
cs.HCcs.CY 2026-10-08
儘管插圖場景常用於激發兒童講故事，但有語言困難的兒童常會省略使故事連貫的細節、動作和關係。本研究介紹了Tellimation，一個即時動畫系統，它能將兒童省略或錯誤描述的場景元素動畫化，藉此引起他們對敘事空白的注意，而無需直接指出該說什麼。其設計空間涵蓋八種敘事空白，例如場景中的人物、數量、特徵、動作、地點、時間、關係以及圖片之外的內容（如對話和想法）。研究透過實例展示了Tellimation如何具體化這些空白，幫助兒童提升故事的完整性和連貫性。這項創新工具為語言發展遲緩兒童的敘事能力培養提供了新的輔助方法。
如何透過即時動畫幫助兒童識別並填補故事中的敘事空白？
深度點評
  • Tellimation的創新之處在於它不直接糾正兒童，而是透過視覺化動畫「顯示」敘事空白，這種間接引導方式更符合兒童學習心理。
  • 相較於傳統的口頭提示或文字輔助，即時動畫的視覺化回饋更直觀、更具吸引力，尤其適合有語言困難的兒童。
  • 該系統對八種敘事空白的細緻分類和具體化處理，為兒童敘事能力評估和干預提供了實用的框架。
研究貢獻
  • 提出Tellimation系統，利用即時動畫可視化兒童敘事空白。
  • 定義並具體化八種敘事空白類型。
  • 為有語言困難兒童的敘事能力發展提供創新輔助工具。
研究限制
  • 系統的長期效果和在不同文化背景下的適用性仍需進一步驗證。
  • 動畫生成可能存在技術限制，無法完全捕捉所有細微的敘事意圖。

SPEAR: Five Principles for Interactive Human-Agent Alignment
cs.HCcs.AI 2026-10-08
近期AI對齊研究常將其視為部署前的優化問題，透過收集人類回饋、學習偏好或原則來微調模型。然而，當AI系統作為代理人代表用戶在情境化、長期和社交環境中行動時，這種框架未能充分說明後續情況。本立場文件將人機代理對齊重新定義為一個持續的互動設計問題。我們提出了SPEAR，五個互動對齊的支柱：規範（人們如何表達他們的需求）、可預測性（代理人行為的可理解性）、可解釋性（代理人決策的透明度）、可審計性（代理人行動的追溯性）和可修復性（代理人錯誤的修正能力）。這些原則旨在指導未來人機互動系統的設計，以實現更穩健和以人為中心的AI對齊。
如何將人機代理對齊從部署前優化轉變為持續的互動設計問題？
深度點評
  • SPEAR框架將AI對齊從靜態的「部署前優化」轉變為動態的「持續互動設計」，這是一個重要的範式轉變，更貼近真實世界的人機協作情境。
  • 提出的五個支柱——規範、可預測性、可解釋性、可審計性和可修復性——為設計以人為中心的AI代理提供了全面且具體的操作指南，彌補了現有對齊研究的不足。
  • 這項工作強調了用戶在AI對齊過程中的主動參與和控制權，對於提升AI系統的信任度、接受度和長期可用性具有深遠的理論和實踐意義。
研究貢獻
  • 重新定義人機代理對齊為持續互動設計問題。
  • 提出SPEAR五大互動對齊原則。
  • 為未來人機互動系統設計提供以人為中心的指導框架。
研究限制
  • SPEAR作為一個原則性框架，其具體實施細節和量化評估方法仍需進一步探索。
  • 不同應用場景下，五個原則的權重和優先級可能有所不同，需要靈活調整。

如何建立一個可證偽的量子類模型來解釋沉浸式導航中的線索順序效應？
深度點評
  • QSDD模型將量子力學的形式主義應用於認知決策，提供了一種新穎且可證偽的框架來解釋人類決策中的順序效應，這在認知科學領域是個突破。
  • 該研究明確區分了「量子類」行為與「微觀量子過程」，避免了不必要的物理學爭議，專注於宏觀認知現象的建模，提升了理論的嚴謹性。
  • 模型對線索暴露、中間判斷和路線承諾的數學化描述，為未來設計更符合人類認知模式的沉浸式導航系統和人機量子計算機介面提供了理論基礎。
研究貢獻
  • 提出量子類空間決策動力學（QSDD）模型。
  • 將線索暴露、判斷和承諾形式化為量子操作。
  • 為沉浸式導航中的線索順序效應提供可證偽的解釋。
研究限制
  • QSDD模型的實驗驗證仍需大量數據支持，以證明其預測能力和泛化性。
  • 模型在解釋複雜多變的真實世界決策情境時，可能需要進一步的擴展和細化。

Artifact removal improves electrodermal waveforms but not downstream classification in a virtual-reality balance task
cs.AIcs.HC 2026-10-08
假定更乾淨的信號能支持更好的決策，偽影去除通常在皮膚電活動（EDA）分類之前進行。本研究在虛擬實境（VR）平衡干擾任務中測試了這一假設。一個殘差門控網路在專家校正的EDA基準數據上進行訓練，然後應用於VR記錄。原始和門控信號隨後由五種已發表的時序方法在相同的「留一參與者」評估下進行分類。結果顯示，在基準測試中，門控網路能很好地檢測偽影，但經過偽影去除後的EDA信號，並未顯著提升下游分類任務的準確性。這項發現挑戰了傳統的數據預處理假設，對生理信號分析和VR應用中的情緒或壓力檢測具有重要啟示。
偽影去除是否能有效提升VR平衡任務中皮膚電活動的下游分類性能？
深度點評
  • 本研究挑戰了生理信號處理領域的普遍假設，即「更乾淨的信號必然帶來更好的分類結果」，其發現對於重新思考數據預處理策略具有重要意義。
  • 透過在VR環境中進行實驗，研究增加了結果的生態效度，並為未來在沉浸式環境中利用生理數據進行人機互動設計提供了實證依據。
  • 研究採用了多種已發表的時序分類方法進行比較，增強了結果的可靠性和普適性，顯示了偽影去除在某些情境下可能並非必要。
研究貢獻
  • 在VR平衡任務中測試了EDA偽影去除對分類的影響。
  • 發現偽影去除雖改善波形，但未顯著提升下游分類準確性。
  • 挑戰了生理信號預處理的傳統假設。
研究限制
  • 研究結果可能受限於特定的VR任務和EDA數據類型，不一定能推廣到所有生理信號或應用場景。
  • 所使用的偽影去除方法和分類器可能影響結果，未來可探索更多先進技術。

Prompt × 心理學 No.01
Educating future engineers about LLMs: A scalable workshop
cs.CLcs.HC
Prompt 技術
CoT (Chain-of-Thought) 與 Few-shot Prompting。研究中學生為LLM編寫提示，以解決網格導航任務。針對「非推理」和「推理」LLM，學生需要設計不同複雜度的提示，這暗示了他們可能嘗試透過提供逐步思考的指令（CoT）或少量範例（Few-shot）來引導LLM的行為。
心理學概念

cs.HCcs.AI
Prompt 技術
規範性Prompting (Specification Prompting)。SPEAR框架中的「規範（Specification）」支柱，強調人們如何表達他們的需求和期望給AI代理人。這直接關聯到提示工程，即如何設計清晰、明確且全面的提示，以確保AI代理人能準確理解並執行用戶的意圖，實現人機對齊。

應用場景
當前，SPEAR原則為設計長期、情境化的人機代理系統提供了指導。未來，這些原則將直接影響提示工程的發展，促使設計者開發更具彈性、可解釋性和可修復性的提示機制。對心理學實務而言，它啟發我們在設計AI輔助工具時，應特別關注用戶如何表達需求，以及AI如何回饋其理解，以優化人機互動的心理體驗。例如，在心理健康應用中，如何設計提示讓用戶能安全、有效地表達情緒或困擾，並確保AI的回應是恰當且有益的。
