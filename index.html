限制模組可讀取的資訊量，可能反而能提升系統的計算學習能力。本研究透過一項預先註冊的實驗，使用六十個共享語言模型骨幹的四單元系統，並透過學習到的連續封包進行通訊，以驗證此假設。實驗設計了五種條件，包括證據遮蔽、所有權標記及外來證據替換，並在六個初始化叢集與兩種資料順序下，針對一個新任務世界進行測試。結果顯示，在標記可用的情況下，證據遮蔽顯著提升了模型在未見過的兩操作及三操作任務上的準確性。這項發現證實了證據遮蔽是驅動組合式泛化的關鍵因素，強調了資訊限制在AI學習中的重要性。研究結果對AI系統的設計與訓練具有深遠的啟示，特別是在提升模型的泛化能力方面。
證據遮蔽如何影響語言模型的組合式泛化能力？
深度點評
  • 採用預先註冊的六十個四單元系統進行大規模確認性實驗，設計嚴謹，但實驗環境為合成任務世界，與真實世界複雜度仍有差距。
  • 首次大規模確認證據遮蔽對組合式泛化的驅動作用，超越了單一模型或小規模實驗的發現，為該領域提供了強有力的實證支持。
  • 揭示了限制資訊流動在AI學習中的關鍵作用，可能引導未來AI架構設計朝向更模組化、資訊隔離的方向發展，以提升模型的泛化能力與可解釋性。
研究貢獻

  • 提供了關於AI學習機制的新見解

文字描述能否作為穿戴式AI助理的情節記憶？
深度點評
  • 提出以文字描述作為情節記憶的新穎方法，有效解決了視覺模型在長影片處理上的限制，但文字描述的粒度與細節捕捉能力仍可能受限。
  • 突破了傳統視覺語言模型在長上下文影片記憶上的瓶頸，為穿戴式AI助理的記憶系統設計提供了實用且高效的替代方案。
  • 為開發下一代具備情節記憶能力的穿戴式AI助理奠定基礎，有望提升使用者在日常生活中與AI互動的流暢性與實用性。
研究貢獻
  • 定義了情節記憶影片字幕問答任務
  • 發布了CapMem人類標註基準測試集
  • 證明了文字描述作為情節記憶的可行性
研究限制
  • 字幕生成品質可能影響記憶準確性
  • 未探討多模態記憶融合的潛力

AI輔助是否在寫作與程式設計中留下可檢測的時間指紋？
深度點評
  • 首次將AI輔助的時間指紋概念從寫作擴展到程式設計，並利用鍵盤級別的過程數據進行分析，方法新穎。然而，時間指紋的特徵可能因AI工具、使用者習慣和任務類型而異，泛化性仍需進一步驗證。
  • 突破了傳統AI檢測器僅依賴最終產品的局限，為AI輔助下的學習評估提供了更精確、更具倫理考量的過程導向方法。
  • 為教育心理學和人機互動領域提供了檢測AI過度依賴的新工具，有助於教師評估學生真實學習情況，並指導學生更有效地利用AI工具。
研究貢獻
  • 證明AI輔助在寫作和程式設計中存在時間指紋
  • 擴展了AI過度依賴檢測的應用範圍
  • 分析了多個公開語料庫的過程數據
研究限制

Think Before You Comfort: Reflective Cognitive Alignment for Protocol-Grounded Elderly Stimulation Agents
cs.AIcs.HCcs.CL 2026-09-18
認知刺激療法（CST）為認知障礙老年人提供非藥物支持，但其可擴展性受限於對受訓輔導員的依賴以及資料稀缺，特別是對於粵語等隱私敏感且資源匱乏的語言。儘管大型語言模型（LLMs）在自動陪伴方面展現潛力，但它們常難以平衡同理心參與與認知刺激指南的遵循。本研究提出一個框架，從兩個互補軸線解決這些挑戰。首先，我們開發了一種「反思性認知對齊」機制，使LLM能夠在回應前評估其潛在影響，確保符合CST協議。其次，我們利用多模態合成數據生成技術，為粵語CST創建了豐富的訓練資料。這項研究為開發可擴展、文化適應的AI老年照護工具提供了重要基礎。
如何讓LLM在老年認知刺激中平衡同理心與協議遵循？
深度點評
  • 提出了「反思性認知對齊」機制，使LLM能在生成回應前進行自我評估，有效平衡了同理心與協議遵循，這在AI倫理和行為控制上是重要進展。然而，該機制的複雜性可能增加模型的推理負擔。
  • 突破了LLM在敏感應用中難以同時滿足情感需求和專業規範的挑戰，特別是針對低資源語言和隱私敏感領域，展現了AI在臨床心理學應用上的潛力。
  • 為臨床心理學中的老年認知照護提供了可擴展的AI輔助方案，有望緩解專業輔導員資源不足的問題，並為AI在醫療健康領域的倫理應用樹立了典範。
研究貢獻
  • 提出了「反思性認知對齊」框架
  • 解決了LLM在CST中平衡同理心與協議遵循的挑戰
  • 利用合成數據生成技術解決低資源語言問題
研究限制
  • 反思性對齊機制的計算成本
  • 合成數據的真實性與多樣性仍需驗證

LLM × 心理學 No.01
GraphEcho: Structural Redundancy and Evidence Provenance in LLM Graph Agents
cs.AIcs.CL
核心問題
LLM圖代理是否會將重複證據誤認為額外佐證？
方法亮點
引入GraphEcho基準測試，透過控制路徑數量和證據來源，同時固定證據內容，來評估LLM代理的判斷和主動探索行為。實驗揭示了模型依賴的判斷轉變，且冗餘支持路徑增加了所有評估代理重複走訪的比例。
心理學意涵

LLM也逃不過「三人成虎」的認知陷阱。

Faking Good and Faking Bad in LLMs: Response Distortion Across Dark Triad Personality Traits
cs.AIcs.CL
核心問題
LLM在「裝好」或「裝壞」情境下，如何扭曲黑暗三角人格特質的表達？
方法亮點
評估七個最先進的LLM模型，在就業選拔和法醫評估兩種生態相關情境下，探討其在「裝好」和「裝壞」條件下，馬基維利主義、自戀和精神病態等黑暗三角特質的表達。
心理學意涵

LLM也會「演戲」，人格評估需警惕其社會期望效應。

Prompt × 心理學 No.01
Apply-Mag: One Tool to Support Many Inclusive Design Methods
cs.HCcs.AI
Prompt 技術
Prompt-as-Method (提示即方法)：該工具允許HCI從業者將任何包容性設計方法（如Persona、情境訪談、共情地圖等）以文字提示的形式輸入給LLM，LLM則根據這些提示生成相應的設計洞察、建議或分析。這種方式將複雜的設計流程抽象為可提示的指令，極大降低了實施門檻。
心理學概念
認知負荷 (Cognitive Load) 與 設計思維 (Design Thinking)：將包容性設計方法轉化為提示，能有效降低HCI從業者在執行這些方法時的認知負荷，使他們能更專注於創造性思考而非方法論的繁瑣細節。同時，它也促進了設計思維的普及，讓更多人能應用複雜的設計工具。
應用場景
當前，Apply-Mag已能輔助設計師快速生成不同用戶群體的Persona，或針對特定產品提出無障礙設計建議。未來，它有望成為一個全面的設計協作平台，讓設計師能與AI共同探索更多元的設計方案，並即時獲得跨文化、跨能力用戶群體的反饋。這對心理學實務的啟發是，AI工具可以作為認知輔助，幫助心理諮詢師或教育工作者更高效地應用複雜的心理學理論或干預方法，例如生成針對不同文化背景個案的溝通策略。
將設計方法「提示化」，讓包容性設計不再是高門檻。

Prompt × 心理學 No.02
Think Before You Comfort: Reflective Cognitive Alignment for Protocol-Grounded Elderly Stimulation Agents
cs.AIcs.HCcs.CL
Prompt 技術
Reflective Cognitive Alignment (反思性認知對齊)：這是一種先進的提示工程策略，LLM在生成回應前會先進行內部「反思」，評估其潛在回應是否符合預設的協議（如CST指南）和倫理原則（如同理心）。它可能涉及多階段提示，例如先生成多個候選回應，再透過另一個提示進行自我審查和修正，以確保輸出既具同理心又符合專業規範。
心理學概念
情緒調節 (Emotion Regulation) 與 倫理決策 (Ethical Decision-Making)：該技術旨在讓AI在與老年人互動時，能像人類專業人士一樣，在提供情感支持的同時，不偏離治療協議。這涉及AI對自身「情緒表達」的調節，以及在複雜情境下進行倫理權衡的能力，以避免過度安慰或不當建議。
應用場景
當前，該技術已應用於開發粵語老年認知刺激代理，能提供符合CST指南的對話，同時展現適當的同理心。未來，這種「反思性對齊」的提示策略可推廣到其他需要高度倫理敏感性和專業規範的心理健康應用，如心理諮詢輔助、危機干預對話等。它啟發心理學實務者思考如何設計AI，使其不僅能理解人類情感，更能以負責任、有原則的方式回應，成為可靠的輔助工具。
AI學會「三思而後言」，讓老年照護更安心。

Relation Before Entity: Deferred Commitment in Language Model Factual Recall
cs.CLcs.AI
Prompt 技術
Prompt Families for Causal Diagnostics (因果診斷提示家族)：研究者設計了八種不同的提示家族，這些提示旨在系統性地探測語言模型在事實回憶過程中，關係類型資訊（如「首都」）和實體特定資訊（如「法國」對應「巴黎」）何時在模型內部變得「因果活躍」。這些提示家族透過精確控制輸入變量，來隔離和觀察模型內部不同資訊的激活順序。
心理學概念
記憶與知識表徵 (Memory and Knowledge Representation) 與 認知處理時間 (Cognitive Processing Time)：本研究透過提示工程技術，深入探討了語言模型內部知識回憶的認知機制，特別是關係與實體資訊的處理順序。這與人類認知科學中關於語義記憶和知識提取的研究高度相關，揭示了AI在「思考」過程中，不同類型資訊的激活時間差異。
應用場景
當前，這種提示家族已被用於揭示LLM在事實回憶中「關係先於實體」的穩健時間不對稱性。未來，類似的因果診斷提示技術可以應用於探測LLM在其他認知任務（如推理、決策）中的內部處理流程，幫助研究者更好地理解AI的「心智」。這對心理學實務的啟發是，透過精確設計的提示，我們可以將LLM視為一個可控的認知實驗對象，從而更深入地探討人類認知的計算模型，甚至為認知障礙的診斷與干預提供新的視角。
提示家族揭示LLM「思考」秘密，關係先於實體。
