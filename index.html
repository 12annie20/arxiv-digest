No. 01
MemoryForge: Synthesize Lifelong Memory for Human-Like LLM Agents
cs.AIcs.CL
賦予大型語言模型(LLMs)類人的人格對於角色扮演和使用者模擬等代理應用至關重要。傳統基於提示的方法依賴靜態文本描述，常因缺乏真實生活記憶而導致代理人行為通用化。為解決此問題，本研究引入記憶導向的條件化範式，靈感來自認知心理學，用自傳式記憶庫取代抽象描述。此方法使凍結的LLMs能動態檢索並整合相關記憶，以生成更具情境感知和連貫性的反應。實驗結果顯示，MemoryForge顯著提升了代理人在多種情境下的擬人化程度和行為一致性。這項研究為開發更具深度和真實感的AI代理人提供了新途徑。
如何賦予LLM代理人真實且持久的類人記憶？
深度點評
  • 本研究提出記憶導向的條件化範式，透過自傳式記憶庫而非靜態提示來塑造LLM代理人的人格，這在方法上是將認知心理學的記憶理論直接應用於LLM架構的創新嘗試。
  • 相較於現有依賴描述性提示的方法，MemoryForge能讓凍結的LLM動態檢索並整合記憶，顯著提升了代理人的情境感知和行為連貫性，克服了傳統方法的通用化限制。
  • 這項研究為開發更具深度、真實感和長期一致性的AI代理人奠定基礎，對虛擬伴侶、教育模擬和心理健康輔助等領域具有深遠影響。
研究貢獻
  • 提出記憶導向的條件化範式，以自傳式記憶庫取代靜態文本描述來塑造LLM代理人的人格。
  • 設計並實現了MemoryForge系統，使凍結的LLM能動態檢索和整合記憶，生成情境感知和連貫的反應。
  • 透過實驗證明MemoryForge顯著提升了代理人在多種情境下的擬人化程度和行為一致性。
研究限制
  • 記憶庫的建構和維護成本可能較高，特別是對於需要大量個人化記憶的應用。
  • 記憶檢索的效率和準確性仍可能受限於記憶庫的規模和複雜度，可能導致資訊過載或遺漏。

No. 02
AgentMemBench: A Systematic Benchmark for Evaluating Long-Term Memory Management Strategies in Conversational AI Agents
cs.AIcs.CL
長期記憶一直是對話式AI代理人的關鍵瓶頸，因其有限的上下文窗口難以在數千輪對話中保持連貫的記憶。本研究提出AgentMemBench，一個統一且可重現的基準測試平台，用於評估五種記憶管理策略：上下文窗口內處理(ICW)、外部鍵值存儲(EKV)、基於圖的事件記憶(GEM)、基於壓縮的摘要(CBS)和網路增強記憶(WAM)。所有策略都在三個涵蓋長期多會話對話的公開數據集上進行評估。研究結果揭示了不同策略在記憶召回、連貫性和效率方面的優缺點，為未來對話式AI代理人的記憶系統設計提供了實證指導。
如何系統性評估對話式AI代理人的長期記憶管理策略？
深度點評
  • AgentMemBench提供了一個標準化的框架來比較不同的記憶管理策略，這對於理解和改進對話式AI代理人的長期記憶能力至關重要，填補了該領域缺乏統一基準的空白。
  • 該基準測試涵蓋了從簡單的上下文窗口到複雜的圖形記憶和網路增強記憶等多種策略，並在多個真實世界數據集上進行評估，其全面性超越了許多單一策略或單一數據集的評估。
  • 這項工作不僅為研究人員提供了評估工具，也為開發者選擇最適合其應用場景的記憶策略提供了寶貴的實證依據，有助於推動更智能、更連貫的對話系統發展。
研究貢獻
  • 提出AgentMemBench，一個統一且可重現的基準測試平台，用於評估對話式AI代理人的長期記憶管理策略。
  • 系統性地評估了五種主流記憶管理策略（ICW, EKV, GEM, CBS, WAM）在長期多會話對話中的表現。
  • 提供了關於不同記憶策略在記憶召回、連貫性和效率方面的實證分析和比較。
研究限制
  • 基準測試的數據集雖然涵蓋多會話，但可能仍無法完全捕捉所有真實世界對話的複雜性和多樣性。
  • 評估指標主要集中在記憶召回和連貫性，可能未充分考慮記憶管理對代理人推理能力或情感理解的影響。

No. 03
ReVoicer: Conversational Voice Annotation for Human-Centered, LLM-Assisted Peer Review
cs.HCcs.CLcs.AI
本研究提出ReVoicer，一個原型系統，旨在透過對話式語音註釋來輔助同行評審員。評審員在閱讀論文時可高亮段落並口述（或輸入）思考過程中的評論。大型語言模型(LLM)隨後利用周圍文本作為上下文來清理評論，根據評論類型進行標記，並將其錨定到相關段落。評審員完成閱讀後，ReVoicer會根據特定場地的評審標準檢查累積的筆記，報告覆蓋範圍的不足，並僅從評審員自己的評論中起草一份評審報告。這項系統旨在提升同行評審的效率和品質，同時保持以人為中心的評審過程。
如何透過對話式語音註釋和LLM輔助提升同行評審效率與品質？
深度點評
  • ReVoicer將語音輸入與LLM的語境理解能力結合，創造了一種直觀且高效的評論方式，這在人機互動設計上是將自然語言處理技術深度融入專業工作流程的創新。
  • 相較於傳統的文本輸入或手動註釋，ReVoicer透過LLM自動清理、標記和錨定評論，顯著減少了評審員的認知負荷，並能根據評審標準自動檢查，提升了評審的全面性和客觀性。
  • 這項研究不僅為同行評審流程帶來了效率提升，也為其他需要深度文本理解和人機協作的專業領域（如法律審閱、醫學診斷）提供了潛在的應用範式。
研究貢獻
  • 提出ReVoicer系統，一個支援對話式語音註釋的LLM輔助同行評審原型。
  • 設計了LLM清理、標記和錨定評論的流程，利用上下文提升評論質量。
  • 實現了根據評審標準檢查筆記並自動起草評審報告的功能，提升評審效率和全面性。
研究限制
  • 語音識別的準確性可能受環境噪音、口音或專業術語的影響，進而影響LLM對評論的理解和處理。
  • LLM在清理和標記評論時，仍可能存在誤解評審員意圖或引入偏見的風險，需要進一步的人工校驗。

Dynamic Surveys: Using LLMs to Blend Qualitative Depth,Quantitative Structure, and Collaborative Interaction
cs.HCcs.CLcs.AI
問卷調查是收集數據和獲取社會現象洞察力的強大工具，在產品設計、市場行銷和科學研究中至關重要。然而，傳統的開放式和封閉式問題格式限制了研究人員捕捉兼具質性深度和量化嚴謹性數據的能力。為解決這些問題，本研究提出Dynamic Surveys，一個利用大型語言模型(LLMs)即時動態聚類質性回覆並提取量化洞察的問卷平台。該平台還支持協作互動，讓研究人員能共同探索數據。這項創新方法旨在彌合質性與量化研究之間的鴻溝，提供更豐富、更具分析性的數據收集體驗。
如何利用LLM融合質性深度與量化結構來革新問卷調查？
深度點評
  • Dynamic Surveys創新性地將LLM應用於問卷調查的實時數據分析，特別是將質性回覆動態聚類並轉化為量化洞察，這在研究方法學上是質性與量化研究融合的重大突破。
  • 相較於傳統問卷需要大量人工編碼和分析質性數據，該平台透過LLM實現自動化處理，大幅提升了數據分析的效率和即時性，同時保留了質性數據的豐富性。
  • 這項研究對社會科學、市場研究和使用者體驗設計等領域具有深遠影響，它不僅能加速數據收集和分析過程，還能幫助研究人員從複雜的質性數據中發現更深層次的模式和趨勢。
研究貢獻
  • 提出Dynamic Surveys平台，利用LLM即時動態聚類質性回覆並提取量化洞察。
  • 彌合了傳統問卷中質性深度與量化結構之間的鴻溝，提供更豐富的數據收集體驗。
  • 支援協作互動功能，使研究人員能共同探索和分析數據。
研究限制
  • LLM在理解和聚類質性回覆時，可能存在語義誤解或引入模型偏見的風險，影響數據分析的客觀性。
  • 對於高度專業化或敏感的質性數據，LLM的處理能力可能仍需進一步驗證和微調，以確保結果的準確性和可靠性。

Role Steering of Language Models for Social Simulations
cs.AIcs.CLcs.CY
建立於語言模型代理人的社會模擬需要角色條件化的行為，這些行為在代理人被放入模擬群體之前需要經過檢查。本研究引入了一種針對角色條件化代理人的激活引導篩選工作流：定義角色檔案、提取角色特定方向、掃描四個引導係數、評估角色檔案對齊度，並通過或標記每個候選配置。在OLMo-3-7B-Instruct模型上，我們將此工作流應用於包含275個混合角色和228個角色無關問題的庫存，並透過GPT-4.1-mini提示的角色重新評估。結果顯示，此方法能有效控制代理人的角色行為，為大規模社會模擬提供了可靠基礎。
如何精確控制LLM代理人在社會模擬中的角色行為？
深度點評
  • 本研究提出激活引導篩選工作流，透過精確定義角色檔案和引導係數來控制LLM代理人的行為，這在AI代理人行為控制和社會模擬領域是方法論上的重要創新。
  • 相較於傳統的提示工程，此方法提供了更細粒度且可量化的行為控制機制，確保代理人在複雜社會情境中能保持角色一致性，顯著提升了社會模擬的真實性和可靠性。
  • 這項工作為構建大規模、高保真度的社會模擬提供了堅實的技術基礎，對於研究人類行為、政策評估和社會動態等領域具有巨大的潛在價值。
研究貢獻
  • 引入激活引導篩選工作流，用於檢查和控制LLM代理人的角色條件化行為。
  • 設計了定義角色檔案、提取角色方向、掃描引導係數和評估對齊度的系統化流程。
  • 在OLMo-3-7B-Instruct模型上驗證了該工作流的有效性，實現了對代理人角色行為的精確控制。
研究限制
  • 角色檔案的定義和引導係數的調優可能需要專業知識和大量實驗，過程較為複雜。
  • 模型在面對極端或未預期的社會情境時，其角色行為的穩定性和一致性仍需進一步驗證。

04 / Prompt Engineering × 心理學 精選 TOP 3 PROMPT ENG × PSYCHOLOGY
Prompt × 心理學 No.01
MemoryForge: Synthesize Lifelong Memory for Human-Like LLM Agents
cs.AIcs.CL
Prompt 技術
記憶導向條件化 (Memory-based Conditioning)：這是一種進階的提示工程技術，它不依賴於靜態的文本描述來定義代理人的人格，而是透過構建和動態檢索一個「自傳式記憶庫」來為LLM提供豐富的上下文。當LLM需要生成回應時，它會從記憶庫中檢索相關的過去經驗和資訊，將其作為動態提示的一部分，從而影響其輸出。
心理學概念
自傳式記憶 (Autobiographical Memory) 與 人格塑造 (Persona Shaping)：自傳式記憶是認知心理學中的一個核心概念，指個人對自身經歷和事件的記憶，它對於個體身份認同和行為連貫性至關重要。MemoryForge透過模擬這種記憶機制來塑造LLM代理人的「人格」，使其行為更具一致性和真實感，這與人類透過自身經驗形成穩定人格的過程相呼應。
應用場景
當前應用於角色扮演、虛擬伴侶和使用者模擬等場景，使AI代理人能展現更具深度和連貫性的行為。未來潛力在於開發用於教育領域創建具有豐富背景知識的歷史人物模擬器，或用於心理健康輔助AI，提供更具同理心和長期互動能力的支援。這對心理學實務的啟發是，可以利用這種記憶機制來模擬特定人格特徵，用於行為實驗或治療模擬，深入理解人類記憶與人格的交互作用。
記憶不再是提示的附庸，而是塑造AI人格的基石。

Role Steering of Language Models for Social Simulations
cs.AIcs.CLcs.CY
Prompt 技術
激活引導篩選工作流 (Activation-steering Screening Workflow)：這是一種用於精確控制LLM代理人角色行為的提示工程方法。它首先定義一個詳細的「角色檔案」，然後從模型內部提取與該角色相關的「角色特定方向」（可能是潛在空間中的向量）。接著，透過調整四個「引導係數」來微調模型在生成回應時對該方向的激活程度，並評估其與角色檔案的對齊度，最終篩選出符合預期角色行為的配置。
心理學概念
社會角色 (Social Roles) 與 行為控制 (Behavioral Control)：社會角色是社會心理學的核心概念，指個體在特定社會情境中應表現出的行為模式和期望。本研究透過激活引導來精確控制LLM代理人的「社會角色」行為，這與人類在不同社會情境下調整自身行為以符合角色期望的心理過程高度相關。它探討了如何透過外部干預來實現對複雜行為模式的精確控制。
應用場景
當前主要應用於構建大規模社會模擬，用於研究群體行為、政策影響和社會動態。未來潛力在於開發用於訓練人際溝通技能的虛擬情境，或用於模擬不同文化背景下的人類互動模式。這對心理學實務的啟發是，可以利用這種精確的角色控制來設計行為實驗，探究特定社會角色對個體決策和互動的影響，甚至用於治療社交焦慮症患者的虛擬暴露療法。
角色不再是簡單的描述，而是透過激活引導精準塑造的行為藍圖。

Prompt × 心理學 No.03
RubricReviewer: From Direct Critique to Objective and Comprehensive Rubric-Driven Peer Review
cs.AIcs.CL
Prompt 技術
評審標準驅動提示 (Rubric-Driven Prompting)：這是一種結構化的提示工程方法，旨在引導LLM根據預設的評審標準（rubric）來生成客觀且全面的評審意見。不同於直接要求LLM生成評論，此方法將評審標準作為核心輸入，促使LLM在分析稿件時，系統性地針對每個評審維度提供證據和判斷。這可以透過多階段提示實現，例如先要求LLM識別稿件中與某個評審標準相關的內容，再要求其根據該內容進行評分和評論。
心理學概念
認知偏見 (Cognitive Bias) 與 客觀判斷 (Objective Judgment)：在社會心理學和認知心理學中，人類的判斷容易受到各種認知偏見的影響，導致評審結果不一致或不客觀。RubricReviewer透過強制LLM遵循明確的評審標準，旨在減少這種偏見，提升評審的客觀性和透明度。這與人類在進行複雜判斷時，透過結構化工具（如評分量表）來減少主觀性、提高決策品質的心理策略相符。
應用場景
當前主要應用於學術論文的同行評審，旨在提升評審效率和質量。未來潛力在於擴展到其他需要客觀評估的領域，如專案提案審核、員工績效評估或學生作業批改。這對心理學實務的啟發是，可以利用這種評審標準驅動的AI系統來分析人類評審的行為模式，識別潛在的偏見來源，並設計更有效的培訓方案來提升人類評審的客觀性。
評審不再是主觀的藝術，而是透過標準化提示實現的客觀科學。
