AI Evaluation Should Work With Humans

傳統AI評估過度強調超越人類的自主表現，導致AI發展方向偏離，未能充分發揮其與人類協作的潛力。本研究提出應轉向評估「人機團隊」的協作表現，以期引導AI系統成為人類能力的真正補充。作者認為，這種典範轉移將促使AI系統更好地服務社會，帶來更積極的社會成果。這篇立場文件呼籲AI社群重新思考其評估策略，從根本上改變AI的發展軌跡。
AI評估應如何轉變以促進人機協作？
深度點評
  • 此文並非技術創新，而是對AI發展方向的深刻反思，挑戰了主流的「超人AI」範式，提出以「人機協作」為核心的評估框架，具備重要的哲學與倫理意義。
  • 相較於現有側重單一AI性能指標的研究，本文將評估重心從AI本身轉移到人機系統的整體效能，為AI倫理與社會影響研究提供了新的視角。
  • 若此觀點被廣泛採納，將可能重塑AI研究的優先順序，鼓勵開發更具輔助性、協作性的AI技術，而非僅追求自主取代人類的系統。
研究貢獻
  • 提出「人機團隊」作為AI評估的新範式
  • 強調AI應作為人類能力的補充而非取代者

No. 02
Modular Cognitive Architecture Emerges in Large Language Models
cs.AIcs.CLcs.NE 2026-08-17
人腦展現出顯著的功能專業化，不同網絡支持語言、推理等認知功能，但這種模組化組織是否為智能系統的普遍原則仍是未解之謎。本研究旨在探討大型語言模型（LLM）是否也會在不同的優化過程中，自然地發展出類似的模組化認知架構。研究透過電路分析方法，深入探究LLM內部處理語言、推理等任務時的激活模式，發現LLM中確實存在與人腦功能區相似的專業化模組。這些模組在處理特定認知任務時會被激活，顯示出LLM內部結構的複雜性與功能分化。這項發現不僅加深了我們對LLM內部運作機制的理解，也為探討智能系統的通用設計原則提供了新的視角。
LLM是否會像人腦一樣發展出模組化認知架構？
深度點評
  • 研究透過新穎的電路分析方法，直接探究LLM的內部結構與功能分化，而非僅限於外部行為觀察，這在方法論上是一大創新。
  • 此研究將LLM與生物大腦進行類比，發現了LLM中類似的模組化組織，這與傳統認知科學對人腦的研究形成了有趣的對話，推動了對智能本質的跨領域理解。
  • 這項發現可能為未來設計更高效、更具解釋性的AI系統提供啟示，例如透過模組化設計來提升模型的可控性與泛化能力。
研究貢獻
  • 首次在LLM中觀察到類似人腦的模組化認知架構
  • 採用電路分析方法揭示LLM內部功能專業化
  • 為理解智能系統的通用設計原則提供實證依據
研究限制
  • 研究結果可能受限於特定LLM模型架構與訓練數據
  • 模組化程度的量化與其對模型性能的影響仍需進一步探討

Cross-Disciplinary Taxonomy and Modeling of Misunderstanding Generation, Amplification, and Detection, from Pragmatics to AI Agents
cs.CLcs.AIcs.HC 2026-08-17
隨著溝通日益透過AI媒介進行，即時、面對面的互動減少，導致誤解偵測成為一個亟待解決的問題。現有溝通模式缺乏修復誤解所需的資源，而新的偵測方法尚未跟上。本研究將誤解分析為一個分層過程：首先產生分歧，隨後可能被放大，最終被偵測並修復，或持續存在而未被察覺。作者整合了九個研究領域的觀點，提出一個跨學科的誤解生成、放大與偵測分類法與模型。此模型不僅涵蓋了從語用學到AI代理的廣泛範疇，也為未來開發更有效的人機溝通系統提供了理論基礎。
如何系統性地理解並偵測AI媒介溝通中的誤解？
深度點評
  • 本研究的創新之處在於其跨學科整合能力，將語用學、認知科學、社會心理學等領域對誤解的理解融會貫通，形成一套全面的理論框架，而非僅限於單一技術視角。
  • 相較於現有僅關注單一誤解類型或偵測方法的技術研究，本文提供了一個宏觀的誤解生命週期模型，有助於更全面地設計AI溝通系統中的誤解預防與修復機制。
  • 此分類法與模型將對AI代理的設計產生深遠影響，促使開發者在設計對話式AI時，更注重其理解與表達的精確性，並內建誤解偵測與澄清機制，提升人機互動的品質。
研究貢獻
  • 提出跨學科的誤解生成、放大與偵測分類法
  • 建立從語用學到AI代理的誤解分層模型
  • 為AI媒介溝通中的誤解問題提供理論基礎
研究限制
  • 作為理論性研究，缺乏具體的AI系統實作與實驗驗證
  • 模型中的各階段量化指標與偵測技術仍需進一步開發

Beyond Simplification: DFT-GEN for Fidelity-Preserving Visual Accessibility in Dyslexia-Friendly Educational Texts

對於閱讀障礙者而言，密集的教育文本會造成不必要的閱讀困難，但過度簡化又可能刪除必要的術語、任務限制或原始證據，損害資訊的準確性。本研究透過與閱讀障礙成人及專家訪談，揭示了核心矛盾：減輕閱讀負擔的同時，必須確保資訊的忠實度。為此，我們提出DFT-GEN，一個以利害關係人為導向的文本轉換框架，專為內容密集的教育材料設計。其核心貢獻在於提供一個針對閱讀障礙的特定輔助功能，而非通用的LLM精煉循環，確保文本在提升可讀性的同時，維持資訊的完整性與準確性。
如何為閱讀障礙者提供忠實度高的教育文本輔助功能？
深度點評
  • 本研究的創新在於其以「資訊忠實度」為核心的設計理念，區別於傳統的文本簡化方法，並透過利害關係人訪談確保解決方案的實用性與針對性，體現了以人為本的設計原則。
  • 相較於通用LLM文本處理，DFT-GEN專注於閱讀障礙者的特定需求，避免了過度簡化導致的資訊損失，為特殊教育領域提供了更精準的AI輔助工具。
  • 此框架的應用將顯著改善閱讀障礙學生的學習體驗，降低認知負荷，並確保他們能獲取完整且準確的教育內容，對教育公平性具有積極影響。
研究貢獻
  • 提出以「資訊忠實度」為核心的閱讀障礙文本轉換框架DFT-GEN
  • 透過利害關係人訪談明確閱讀障礙者的核心需求
  • 提供針對閱讀障礙的特定輔助功能，而非通用簡化
研究限制
  • 框架的實施細節與LLM的具體整合方式未完全闡明
  • 對不同語言和文化背景下閱讀障礙者的適用性仍需驗證

LLM代理如何實現個人化餐級別血糖動態調節？
深度點評
  • 本研究的創新點在於將LLM代理的推理與迭代優化能力應用於複雜的個人化生理調節問題，特別是血糖管理，這超越了傳統的靜態飲食建議，實現了動態干預。
  • 相較於現有基於升糖指數或簡單預測模型的血糖管理方法，LLM代理能夠整合更豐富的上下文資訊和個人生理回饋，提供更精準、更具適應性的餐點建議。
  • 此LLM代理系統有望革新糖尿病管理和精準營養領域，為患者提供高度個人化的飲食干預方案，顯著改善生活品質，並降低相關健康風險。
研究貢獻
  • 提出基於LLM代理的個人化餐級別血糖調節系統
  • 實現情境感知推理和迭代優化以動態調整飲食
  • 為精準營養和糖尿病管理提供創新解決方案
研究限制
  • 系統的安全性與可靠性在實際醫療應用中需嚴格驗證

Prompt × 心理學 No.01
Inducing Reward-Free Judging Rubrics that Reduce Over-Crediting in Agent Evaluation
cs.AIcs.CL
Prompt 技術
誘導式評分標準生成 (Inductive Rubric Generation)：透過從特定任務的成功與失敗案例中，自動學習並生成用於評估LLM代理表現的文字化評分標準，而非手動編寫或微調模型權重。
心理學概念
認知偏誤 (Cognitive Bias) 與 歸因錯誤 (Attribution Error)：傳統LLM評估者傾向於過度信任流暢但實質失敗的代理軌跡，這類似於人類在判斷時可能受到表面流暢性或「光環效應」的影響。誘導式評分標準旨在減少這種偏誤，促使評估更客觀地關注實際成果。
應用場景
在AI代理的開發與部署中，此技術能自動生成更客觀、減少偏誤的評估標準，大幅降低人工評估成本。對於心理學實務而言，這啟發我們思考如何設計更公正的評估工具，無論是評估人類行為、治療效果，或是AI輔助診斷系統，都能透過結構化的、從數據中學習的標準來減少評估者的主觀偏誤，提升評估的信效度。
讓AI學會「公正」評估，從源頭減少偏誤。

Prompt × 心理學 No.02
IterCOMP: Reasoning-aware Adaptive Prompt Compression for Multi-hop Question Answering
cs.CLcs.AI
Prompt 技術
推理感知自適應提示壓縮 (Reasoning-aware Adaptive Prompt Compression)：IterCOMP框架透過迭代壓縮，在多跳問答任務中，根據推理步驟的相互依賴性，動態地從冗長且嘈雜的上下文資訊中提取最相關的證據，以優化提示長度。
心理學概念
認知負荷 (Cognitive Load) 與 工作記憶 (Working Memory)：過長的提示和冗餘資訊會增加LLM的認知負荷，類似於人類在處理複雜任務時工作記憶的限制。提示壓縮技術旨在降低這種負荷，使模型能更有效地聚焦於核心推理，提升處理效率和準確性。
應用場景
此技術能顯著提升RAG系統在處理複雜、多跳問題時的效率與準確性，尤其適用於知識密集型應用。在心理學領域，這啟發我們思考如何優化資訊呈現方式，以降低個體的認知負荷，例如在教育材料設計、心理健康資訊傳播或複雜決策支援系統中，透過精煉和結構化資訊，幫助人們更有效地理解和處理訊息。

TeachMateGPT: A Multi-Agent Knowledge-Grounded Framework for Pedagogical Assessment Generation from Science Curriculum Materials
cs.AIcs.CLcs.CY
Prompt 技術
多代理知識接地提示 (Multi-Agent Knowledge-Grounded Prompting)：TeachMateGPT採用多代理系統，結合階層式知識庫（COPE）和非同步證據權威（AEA）機制，透過協作與驗證，從科學課程材料中生成高品質的教學評估項目。每個代理負責特定任務，並透過提示進行協調。
心理學概念
認知建構主義 (Cognitive Constructivism) 與 學習評估 (Learning Assessment)：此框架旨在生成符合課程目標、能有效評估學生理解程度的題目，這與認知建構主義強調學生主動建構知識的學習理論相符。多代理協作過程也模擬了人類專家在設計評估時的協商與驗證過程，提升了評估的有效性與可靠性。
應用場景
TeachMateGPT能自動化生成符合特定課程結構的科學評估題目，大幅減輕教師工作量，並提升評估品質。對於教育心理學而言，這提供了一個強大的工具，用於開發自適應學習系統中的即時評估、診斷性測驗，甚至個性化學習路徑的設計。它也啟發我們思考AI如何更好地理解學習目標與認知層次，以生成更具教育意義的評估內容，促進學生的深度學習。
AI化身教學助理，精準出題，解放教師，優化學習評估。
