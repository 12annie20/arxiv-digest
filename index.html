XAI忠實度指標如何未能有效提升人類信任與理解？
深度點評
  • 論文批判性地指出XAI忠實度指標的結構性缺陷，特別是其未能與人類對解釋的認知需求對齊，這對XAI領域的未來發展方向提出了根本性挑戰。
  • 相較於傳統XAI研究側重於開發新解釋方法，本文更著重於評估現有方法的有效性與其對人類行為的實際影響，為領域提供了重要的反思視角。
  • 本文的觀點可能促使XAI研究從單純追求「可解釋性」轉向更注重「有效性」與「人本設計」，強調解釋應服務於人類的特定任務與認知需求，而非僅是技術上的忠實呈現。
研究貢獻
  • 揭示XAI忠實度指標與人類理解需求之間的結構性錯位。
  • 提出XAI應重新定位為主要用於模型除錯的工具。

研究限制

單一對話式AI介面如何對用戶認知、信念及信任造成危害？

From Observation to Intervention: Identifiability of Latent User Bias in Human-AI Interaction
cs.AIcs.HCcs.CY 2026-10-13
對齊方法通常將用戶行為視為潛在偏好的可靠代理，然而當用戶持有信念依賴的認知偏見時，此假設便會失效，可能導致不可逆轉的「確認陷阱」和有害的迴饋循環。本論文形式化了AI系統何時能區分真實用戶偏好與受認知偏見影響的行為。研究將這種互動建模為多臂老虎機問題，首先證明了一個不可識別性定理：在被動觀察下，靜態二元偏見用戶會產生與無偏見用戶相同的行為軌跡。接著，論文提出了一種干預策略，透過引入隨機探索來打破這種不可識別性，從而使AI能夠推斷並緩解潛在的用戶偏見。
AI系統如何區分用戶真實偏好與受認知偏見影響的行為？
深度點評
  • 本文透過形式化建模和數學證明，揭示了在被動觀察下識別用戶潛在認知偏見的根本性挑戰，這對人機互動中的偏見緩解策略提供了重要的理論基礎。
  • 相較於多數偏見研究側重於AI模型的內在偏見，本研究將焦點轉向用戶自身的認知偏見及其在人機互動中的傳播與強化，並提出了創新的干預策略。
  • 該研究對於設計能夠主動識別並緩解用戶認知偏見的AI系統具有深遠影響，有助於避免「確認陷阱」和有害迴饋循環，進而提升AI對齊的魯棒性和倫理性。
研究貢獻
  • 形式化建模人機互動中用戶認知偏見的識別問題。
  • 證明了在被動觀察下，用戶偏見的不可識別性定理。
  • 提出一種基於隨機探索的干預策略來識別並緩解用戶偏見。
研究限制
  • 研究主要基於理論模型和簡化的多臂老虎機設定，實際應用中的複雜性可能更高。
  • 提出的干預策略可能需要用戶接受一定程度的「探索性」互動，這在實際應用中可能面臨挑戰。

如何透過無障礙說明和AI輔助提升盲人和低視力人士的家具組裝自主性？
深度點評
  • 本研究透過技術探針AssemblyLens，將複雜的視覺組裝說明轉化為BLV人士可理解的無障礙格式，展現了AI在提升特定群體生活自主性方面的具體創新應用。
  • 相較於一般輔助技術僅提供單純的資訊轉換，本研究更深入探討了「結構化路線圖」和「策略性指導」對BLV人士認知負荷和組裝效率的影響，具有更強的心理學洞察。
  • 這項工作為無障礙設計領域提供了實證基礎，鼓勵開發者在設計AI輔助系統時，不僅要考慮資訊的可訪問性，更要關注如何透過認知友好的方式呈現資訊，以最大化用戶的自主性和效率。
研究貢獻
  • 探索BLV人士組裝家具的策略與挑戰。
  • 設計並評估了提供高層次路線圖和逐步指導的無障礙說明。
  • 開發了技術探針AssemblyLens，將視覺說明轉換為可訪問格式。
研究限制
  • 研究參與者數量較少（八位BLV人士），結果的普遍性可能受限。
  • 實驗僅限於家具組裝任務，其他複雜任務的適用性有待進一步驗證。

Prompt × 心理學 No.01
Reflective Prompt Optimization of a Deep-Research Agent: A Topic-Disjoint, Multi-Seed Protocol for Measuring Transferable Gains and Prompt-Level Overfitting
cs.CLcs.AI
Prompt 技術
反射式提示優化 (Reflective Prompt Optimization)。這種技術讓AI代理透過自我反思和演化來改進其提示，以提升在特定任務上的表現。它類似於人類的試錯學習，但發生在提示層面，旨在生成更有效、更具泛化能力的指令。
心理學概念
學習與泛化 (Learning and Generalization) 及 過度擬合 (Overfitting)。論文探討了提示優化過程中，AI代理是否真正學會了可遷移的行為，還是僅僅記住了訓練範例的答案（過度擬合）。這與人類學習中知識的遷移能力和避免死記硬背的心理機制高度相關。
應用場景
當前應用於提升語言模型代理在事實性任務上的表現，使其能更有效地進行深度研究。未來潛力在於開發能自我改進、適應新情境的AI助手，例如在複雜問題解決、創意寫作或科學發現中。對心理學實務的啟發是，可以借鑒這種「反射式學習」機制，設計更有效的認知訓練或輔導策略，幫助人類提升自我反思和學習遷移能力。

Prompt × 心理學 No.02
CLEAT: Learning Value-Guided Clarification for Interactive Agents
cs.AIcs.CLcs.HC
Prompt 技術
價值引導式澄清 (Value-Guided Clarification)。這是一種互動式提示策略，AI代理會根據其對用戶目標和未明確限制的理解，主動提出澄清問題。其運作方式是透過學習哪些澄清能帶來更好的決策，從而優化提問的時機和內容，以有效對齊用戶意圖。
心理學概念
意圖對齊 (Intent Alignment) 和 決策制定 (Decision-Making)。論文的核心是讓AI代理更好地理解用戶的隱性意圖，這涉及人類溝通中的「心智理論」和「共同基礎」概念。AI的澄清行為旨在減少資訊不確定性，從而優化其後續決策，這與人類在不確定情境下的決策心理學密切相關。
應用場景
當前應用於提升LLM代理在複雜任務中的協作能力，使其能更精準地執行用戶指令。未來潛力在於開發更具「同理心」和「主動性」的AI助手，例如在個人助理、客服或教育輔導中，能主動預測用戶需求並提供有價值的互動。對心理學實務的啟發是，可以將這種價值引導式澄清機制應用於人際溝通訓練，提升溝通效率和理解深度。
AI學會「問對問題」，人機協作更上一層樓。

Prompt × 心理學 No.03
Incremental Retrieval-Augmented Generation for Human-in-the-Loop Decision Support
cs.AIcs.HC
Prompt 技術
增量式檢索增強生成 (Incremental Retrieval-Augmented Generation, iRAG)。這是一種結合RAG與人機協作的提示技術。傳統RAG從靜態知識庫檢索資訊，而iRAG則在知識庫初始為空的情況下，透過人類的決策逐步填充知識庫。AI系統從「靜默觀察」到「基於證據的質疑」，最終實現「自主處理」，並將人類決策作為可檢索的先例來增強生成。
心理學概念
決策支持 (Decision Support) 和 信任 (Trust)。iRAG系統旨在透過提供基於歷史決策的證據來支持人類決策，這直接關聯到人類在複雜情境下的認知決策過程。隨著AI系統從觀察到質疑再到自主，人類對AI的信任程度會動態變化，這涉及社會心理學中的信任建立與維護機制。
應用場景
當前應用於需要人類專家逐步建立知識庫並進行決策的場景，例如醫療診斷、法律諮詢或複雜工程決策。未來潛力在於開發能與人類共同成長、共同學習的智慧決策系統，尤其適用於知識不斷演進的領域。對心理學實務的啟發是，這種增量式學習和協作模式，可以應用於臨床決策支持，幫助心理諮詢師或醫生在面對新案例時，逐步建立和完善決策依據。
RAG結合人機協作，決策支持從零開始，逐步建立信任。
