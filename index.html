No. 01
Cross-Lingual Persona Effects in LLM Negotiation
cs.CLcs.AI 2026-11-05
本研究旨在探討大型語言模型（LLM）在不同語言環境下，其人格指令（persona instruction）對談判行為的影響是否能保持一致。研究發現，即使給予LLM相同的「強硬」指令，其在英文和韓文環境下的談判策略與結果可能存在顯著差異。這項研究透過對Gemini 3.6 Flash模型進行2x2x3的實驗設計，模擬了12種CraigslistBargain情境，共進行432次談判。結果顯示，LLM的跨語言社會政策忠實度（cross-lingual social-policy fidelity）並非理所當然，語言本身會影響指令的行為表現。這對開發全球化AI應用，特別是涉及人機互動與跨文化溝通的場景，具有重要的指導意義。
LLM的人格指令在不同語言中行為表現是否一致？
深度點評
  • 方法創新：首次系統性地探討LLM人格指令的跨語言忠實度，採用嚴謹的實驗設計來量化語言、賣家急迫性與買家角色對談判結果的影響。
  • 與既有研究比較：相較於多數僅關注單一語言或文化背景的LLM行為研究，本研究引入了跨語言維度，揭示了語言本身作為一個重要變量對AI行為的潛在影響，超越了單純的翻譯問題。
  • 對領域的潛在影響：對開發全球化、多語言AI系統，特別是需要精準控制AI行為（如客服、談判、教育）的應用，提供了關鍵的設計考量，強調了在地化與文化適應的重要性。
研究貢獻
  • 首次提出並量化「跨語言社會政策忠實度」概念。
  • 透過實驗證明LLM人格指令在不同語言間存在行為差異。
  • 為跨文化AI設計與評估提供了新視角。
研究限制
  • 僅限於英文和韓文兩種語言，結果推廣性有限。
  • 實驗情境為模擬談判，與真實世界複雜度仍有差距。

No. 02
Queering the Audits: Community-Based Auditing of AI Harms to Queer Communities
cs.CYcs.HC 2026-11-05
AI系統因訓練數據、評估指標和類別定義中嵌入多數群體預設，對酷兒社群造成了抹除、錯誤分類和歧視等危害。傳統技術審計往往依賴聚合測量，難以發現只有透過受影響社群親身經歷才能顯現的危害。本研究在EurIPS 2025舉辦了一場參與式審計工作坊，邀請16位酷兒社群成員使用4Cs危害分類法（內容、行為、接觸、後果）審計四個案例研究。結果顯示，社群成員能夠識別出傳統審計難以捕捉的細微危害，並提供了具體的改進建議。這項研究強調了社群參與在AI倫理審計中的關鍵作用，為開發更具包容性和公平性的AI系統提供了實踐框架。
如何透過社群參與式審計揭露AI對酷兒社群的危害？
深度點評
  • 方法創新：引入「社群參與式審計」模式，將受影響社群成員納入AI危害評估流程，彌補了傳統技術審計的盲點，提供了一種更具包容性和實用性的審計框架。
  • 與既有研究比較：相較於主流的AI倫理研究多聚焦於技術層面的偏見檢測與緩解，本研究將焦點轉向了社會層面的危害感知與經驗，強調了「由下而上」的審計視角，與人機互動（HCI）領域的參與式設計理念高度契合。
  • 對領域的潛在影響：為AI倫理與公平性研究提供了重要的實踐範例，鼓勵AI開發者與受影響社群建立更緊密的合作關係，有助於推動AI系統的設計從「以技術為中心」轉向「以人為中心」。
研究貢獻
  • 提出並實踐了社群參與式AI危害審計框架。
  • 揭示了AI對酷兒社群的具體且細微的危害。
  • 強調了社群視角在AI倫理評估中的不可或缺性。
研究限制
  • 工作坊規模較小（16位參與者），結果推廣性需進一步驗證。
  • 4Cs分類法仍需在更多情境中進行驗證與完善。

No. 03
GAVAGAI: Referential Alignment for Infant-Scale Vision-Language Models via Balanced Optimal Transport
cs.AI 2026-11-05
兒童透過約一億個詞彙輸入學習詞彙與其指涉物，而現有視覺語言模型（VLM）在類似規模的訓練下，其詞彙與指涉物的綁定可靠性遠低於人類。本研究認為，部分差距源於結構性問題：傳統的下一個詞元（next-token）字幕生成目標缺乏「這個詞指涉那個區域」的變量，導致訓練未能直接促使詞彙接地。為解決此問題，研究將每個場景視為一個小型分配問題，將聽到的內容詞彙與看到的區域進行匹配，並透過平衡最佳傳輸（Balanced Optimal Transport）方法求解。這種方法為VLM提供了直接的詞彙接地壓力，有望提升其對現實世界的理解能力。
如何提升視覺語言模型在嬰兒級數據量下的詞彙指涉對齊可靠性？
深度點評
  • 方法創新：將詞彙接地問題轉化為內容詞彙與視覺區域之間的「分配問題」，並利用平衡最佳傳輸進行求解，為VLM的訓練目標引入了明確的指涉壓力，這是一個新穎且具潛力的方向。
  • 與既有研究比較：相較於主流的VLM訓練方法，本研究從認知科學的「嬰兒學習」角度出發，指出傳統目標的結構性缺陷，並提出了一種更符合人類學習機制的接地策略，有望彌補VLM在語義理解上的差距。
  • 對領域的潛在影響：這項研究不僅有助於開發更具人類學習特性的VLM，也為理解人類語言習得的認知機制提供了計算模型，對認知科學和人工智慧領域都具有重要的理論與實踐意義。
研究貢獻
  • 提出VLM詞彙接地問題的結構性缺陷。
  • 引入平衡最佳傳輸方法實現詞彙與區域的指涉對齊。
  • 為嬰兒級VLM學習提供了新的訓練範式。
研究限制
  • 實驗規模和數據集可能仍需擴展以驗證其泛化能力。
  • 「嬰兒級」的定義與人類實際學習過程仍有簡化。

No. 04
Humanized but Still True? Auditing Facts and Detection in AI-Text Humanizers
cs.AIcs.CY 2026-11-05
AI「人化工具」（humanizers）旨在重寫機器生成文本，使其被檢測器判斷為人類撰寫。現有公開排行榜主要評估其規避檢測的能力和嵌入相似度，卻忽略了文本中可查證細節的存活率。本研究透過一個基於規則的檢查器，並由兩位AI註釋者驗證（精準度0.84-1.00，召回率0.93-0.95），檢查數字、日期、人名、組織名和引用文本等關鍵事實性細節在重寫後是否被更改或刪除。結果顯示，在2026年10月的公開人化工具排行榜中，所有11款商業工具都至少更改或刪除了其中一項細節。這項研究揭示了AI人化工具在追求「人味」的同時，可能犧牲文本真實性的問題，對AI內容的信任度構成挑戰。
AI「人化工具」在重寫文本時能否保持事實性細節的真實性？
深度點評
  • 方法創新：提出了一種新穎且實用的事實性細節審計框架，透過規則基檢查器結合AI註釋者，有效量化了AI人化工具對文本真實性的影響，填補了現有評估體系的空白。
  • 與既有研究比較：相較於主流的AI文本檢測與生成研究，本研究將焦點從「是否像人寫的」轉向「像人寫的同時是否仍是真的」，揭示了AI生成內容在追求流暢性與自然度時可能帶來的潛在風險，對AI倫理與內容信任度研究具有重要意義。
  • 對領域的潛在影響：這項研究對AI內容的生產、審核與消費產生深遠影響。它提醒使用者和開發者，AI人化工具可能在無意中引入錯誤信息，促使業界重新思考AI文本生成與編輯的倫理標準和質量控制機制。
研究貢獻
  • 開發了評估AI人化工具事實性真實性的審計框架。
  • 揭示了商業AI人化工具普遍存在的事實性細節修改或丟失問題。
  • 強調了AI內容生成中「真實性」與「人味」之間的權衡。
研究限制
  • 規則基檢查器可能無法捕捉所有類型的細節修改。
  • AI註釋者的驗證仍可能存在偏見或錯誤。

No. 05
From Lookups to Lessons: Turning Retrieved Knowledge into Parametric Memory
cs.AIcs.CL 2026-11-05
檢索增強生成（RAG）技術幫助大型語言模型（LLM）回答超出其訓練數據範圍的事實性問題，但同時增加了儲存和推理成本。將先前檢索到的信息蒸餾成參數記憶（parametric memories）可以實現重複利用，而無需在線檢索。然而，訓練記憶模型以模仿檢索器通常獎勵獨立的準確預測，這在與LLM現有預測結合時，不一定能提高最終輸出質量。為解決此問題，本研究引入了ResMem，其中LLM透過讀取檢索到的文本來學習，並將其轉化為參數記憶。這種方法旨在讓LLM更有效地整合外部知識，提升其在事實性問答任務中的表現。
如何將檢索到的知識有效轉化為LLM的參數記憶以提升問答性能？
深度點評
  • 方法創新：ResMem模型透過讓LLM直接讀取檢索文本並學習轉化為參數記憶，解決了傳統知識蒸餾方法中獨立預測獎勵與最終輸出質量不一致的問題，提供了一種更整合的知識學習與記憶機制。
  • 與既有研究比較：相較於單純的RAG或傳統知識蒸餾，ResMem強調了LLM在學習過程中對檢索知識的「理解」與「內化」，而非僅僅是「複製」，這更接近人類學習新知識並將其整合到現有認知結構中的過程。
  • 對領域的潛在影響：這項研究對提升LLM的長期記憶能力、減少推理成本以及實現更高效的知識管理具有重要意義。它為開發能夠持續學習和適應新信息的AI系統提供了新的思路，對教育、資訊檢索等領域有廣泛應用潛力。
研究貢獻
  • 提出ResMem模型，實現檢索知識向參數記憶的有效轉化。
  • 解決了傳統知識蒸餾在RAG中存在的局限性。
  • 提升了LLM在事實性問答任務中的表現。
研究限制
  • 參數記憶的容量與長期穩定性仍需進一步研究。
  • 模型訓練的複雜度與資源消耗可能較高。

LLM × 心理學 No.01
MEMENTO: Learning Context Management for Long Context Processing Agents
cs.AIcs.CL
核心問題
LLM代理如何有效管理長文本上下文以提升任務表現？
方法亮點
本研究提出MEMENTO，一個基於Qwen3-8B的長上下文代理，透過壓縮（compaction）策略管理上下文。研究首先引導模型學習筆記摘要行為，然後利用強化學習（RL）進行微調，使其能生成更有效的筆記，從而提升在長文本任務中的表現。
心理學意涵
這項研究對人類認知中的「工作記憶」與「長期記憶」機制提供了啟示。LLM代理的上下文管理類似於人類在處理複雜任務時的記憶策略，如筆記、摘要和回顧，以避免認知負荷過重。這有助於我們理解AI如何模擬或超越人類的認知限制，並為開發能有效處理大量資訊的認知輔助工具提供基礎。同時，也引發了關於AI記憶與遺忘的倫理考量。
讓LLM學會「做筆記」，是提升其長程記憶與推理效率的關鍵一步。

Prompt × 心理學 No.01
Cross-Lingual Persona Effects in LLM Negotiation
cs.CL
Prompt 技術
Persona Prompting (人格提示)。透過在提示中明確指定LLM應扮演的角色或具備的特質（如「headstrong」強硬），來引導其在特定情境（如談判）中展現預期的行為模式。
心理學概念
社會角色理論 (Social Role Theory) 與跨文化溝通 (Cross-cultural Communication)。研究發現，即使是相同的人格指令，在不同語言（文化）背景下，LLM的行為表現會有所差異，這反映了人類社會中角色行為受文化規範影響的現象。這也與社會心理學中對「說服」和「談判策略」的研究相關。
應用場景
在跨國客服、國際商務談判模擬、多語言教育輔導等場景中，可以利用人格提示來訓練LLM扮演特定角色。然而，必須注意不同語言文化對同一人格指令的解讀差異，進行在地化調整，以確保AI行為的適當性與有效性，避免因文化差異導致的誤解或衝突。這對心理諮詢輔助工具的跨文化應用也提供了警示。
人格提示雖強大，但跨語言的文化濾鏡讓AI行為充滿變數。

Prompt × 心理學 No.02
Cross-Prompt Reuse of Entity-Replacement Responses
cs.CLcs.AI
Prompt 技術
Prompt Reuse (提示重用) 與隱藏狀態注入 (Hidden-state Injection)。研究測量在固定模型權重下，實體替換響應在不同英文事實性問題之間的可轉移性。透過將兩個源問題的隱藏狀態變化注入到目標問題的特定深度，並比較預測與實際的對數機率偏移，來探究提示重用對模型行為的影響。
心理學概念
記憶遷移 (Memory Transfer) 與認知泛化 (Cognitive Generalization)。這項技術探討了AI模型如何將從一個任務或提示中學到的「知識」或「行為模式」應用到另一個相關任務中，類似於人類在學習新技能時的經驗遷移。隱藏狀態的注入可以被視為對模型「潛意識」或「深層認知」的干預，以影響其後續的推理過程。
應用場景
在需要快速適應新任務或情境的AI應用中，如智能客服、內容創作或程式碼生成，可以利用提示重用技術來提高效率。例如，當用戶提出一系列關於同一實體但不同關係的問題時，可以重用先前的提示或其隱藏狀態，以加速模型的響應並保持一致性。這對提升AI學習效率和減少重複訓練的認知負荷具有潛力。
提示重用揭示了LLM深層的知識遷移能力，是提升效率的聰明捷徑。

Prompt × 心理學 No.03
MEMENTO: Learning Context Management for Long Context Processing Agents
cs.CLcs.AI
Prompt 技術
Context Management (上下文管理) 與筆記摘要 (Note-taking/Summarization)。MEMENTO代理透過「壓縮」（compaction）策略來管理固定大小的上下文窗口，即模型會將其歷史對話生成一個自我摘要的「筆記」來替換，以保留關鍵資訊並騰出空間處理新的輸入。
心理學概念
工作記憶 (Working Memory) 與認知負荷 (Cognitive Load)。LLM的上下文窗口限制類似於人類工作記憶的有限容量。當資訊過多時，人類會透過摘要、筆記等方式來減少認知負荷，保留核心資訊。MEMENTO的筆記摘要行為正是對這種人類認知策略的模擬，旨在優化AI在處理長文本時的資訊處理效率和記憶保持能力。
應用場景
在需要處理大量歷史對話或長篇文檔的智能助理、客服機器人、法律文件分析、學術研究輔助等場景中，MEMENTO的上下文管理技術能顯著提升LLM的效率和準確性。它有助於AI在長時間互動中保持連貫性，減少「遺忘」重要資訊的風險，從而提供更流暢、更智能的用戶體驗，並降低用戶的認知負擔。
讓LLM學會「聰明地遺忘」，是其在長對話中保持「清醒」的秘訣。
