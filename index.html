Designing Needs- and Attention-Aware AI Learning Tools for Engineering Education: Insights from Psychological Outcomes
cs.HCcs.AI 2026-07-31
隨著人工智慧在高等教育中的應用日益普及，其對學習成效的影響因使用情境而異。本研究超越傳統的認知與學術成果評估，深入探討AI聊天機器人如何影響工程學生的心理需求與學習動機狀態。透過對206名大學工程系學生的問卷調查，研究檢視了AI聊天機器人對學生自主性、歸屬感以及減輕能力挫折感的感知影響。利用潛在交互作用效應的結構方程模型分析，結果揭示了AI工具在滿足學生心理需求方面的複雜作用。這項研究為設計更符合學生需求、提升學習動機的AI學習工具提供了寶貴的心理學洞見。
AI學習工具如何影響工程學生的心理需求與學習動機？
深度點評
  • 方法創新：本研究採用結構方程模型分析AI聊天機器人對學生心理需求的影響，並納入潛在交互作用效應，能更精確地捕捉複雜的心理機制。
  • 與既有研究比較：相較於多數關注學術表現的AI教育研究，本研究獨特地聚焦於心理學成果，如自主性、歸屬感及挫折感緩解，填補了該領域的空白。
  • 潛在影響：為未來AI學習工具的設計提供了以使用者心理需求為核心的指導原則，有助於開發更具人性化、更能激發學習動機的AI輔助系統。
研究貢獻
  • 首次系統性地探討AI聊天機器人對工程學生心理需求的影響。
  • 提出並驗證了AI工具在提升學生自主性、歸屬感及減輕挫折感方面的潛在作用。
  • 為AI學習工具的設計提供了基於心理學洞見的實證建議。
研究限制
  • 研究主要依賴學生自我報告的感知數據，可能存在主觀偏差。
  • 樣本僅限於工程系學生，結果的普適性可能受限於特定學科背景。

How Wrangling Tools Shape Wrangling: A Technical Dimensions Analysis
cs.HC 2026-07-31
資料整理在任何資料專案中都佔據了不成比例的時間與精力，儘管市面上有各式各樣的工具，但對於不同介面形式如何影響人們實際整理資料的方式，我們知之甚少。本研究透過一項針對40名參與者的觀察性研究，比較了在Jupyter（筆記本）、Excel（試算表）、ChatGPT（對話式AI）和OpenRefine（視覺化整理工具）等不同介面範式工具中執行資料清理任務的表現。我們將觀察結果置於程式設計技術維度框架內進行分析，發現工具的介面設計顯著影響了使用者的操作策略、錯誤類型及整體效率。這項研究揭示了工具設計對資料整理行為的深層影響，為未來資料整理工具的開發提供了關鍵見解。
不同資料整理工具的介面形式如何影響使用者的資料整理行為？
深度點評
  • 方法創新：採用跨工具的對照觀察性研究，並結合「程式設計技術維度」框架進行分析，提供了一個系統性比較不同介面範式影響的視角。
  • 與既有研究比較：過往研究多聚焦於單一工具的效率或功能，本研究則透過比較多種主流工具，揭示了介面設計對使用者行為的普遍性影響，而非僅限於特定工具。
  • 潛在影響：為HCI領域的工具設計者提供了實證依據，強調在開發資料整理工具時需考量介面形式對使用者認知負荷與操作策略的潛在影響。
研究貢獻
  • 首次對比分析了Jupyter、Excel、ChatGPT和OpenRefine等主流資料整理工具的介面形式如何塑造使用者行為。
  • 揭示了不同介面範式在資料清理任務中對使用者操作策略、錯誤模式及效率的影響。
  • 將觀察結果與「程式設計技術維度」框架結合，提供了理論與實踐相結合的分析視角。
研究限制
  • 研究樣本量相對較小（N=40），可能影響結果的普適性。
  • 研究任務集中於資料清理，對於其他複雜的資料整理任務的適用性有待進一步驗證。

No. 03
Pragmatic Reasoning in Design
cs.HCcs.AI 2026-07-31
人們通常在幾次互動後就能理解並使用新穎的產品，這表明設計選擇傳達了潛在的可用性與因果結構。本研究提出了一個形式化的解釋，將以使用者為中心的協同設計視為一場合作博弈，其中使用者是主導者，設計師是協助者。受語用溝通（如RSA模型）先前工作的啟發，我們的模型將設計師的設計決策視為溝通訊號，並透過遞歸心智化來預測使用者的判斷：設計師會預測使用者如何解釋設計，而使用者則會推斷設計師的意圖。這項研究為理解人機互動中的設計溝通提供了一個新穎的認知科學框架，強調了設計師與使用者之間隱含的協作推理過程。
如何形式化解釋設計師與使用者之間在設計理解上的語用推理過程？
深度點評
  • 方法創新：將使用者中心設計框架為合作博弈，並引入語用溝通（RSA）模型中的遞歸心智化概念，為設計溝通提供了一個新穎的計算認知模型。
  • 與既有研究比較：傳統設計研究多聚焦於設計原則或使用者測試，本研究則從認知科學角度，深入探討設計師與使用者之間隱含的「心智讀取」過程，填補了理論空白。
  • 潛在影響：有助於開發能更好地理解使用者意圖、生成更具「語用」意義的AI設計工具，提升人機協作設計的效率與品質。
研究貢獻
  • 提出一個將使用者中心設計視為合作博弈的形式化模型。
  • 引入遞歸心智化概念來解釋設計師與使用者之間的語用推理。
  • 為理解設計選擇如何傳達可用性與因果結構提供了理論框架。
研究限制
  • 模型主要為理論性建構，需要更多實證研究來驗證其在真實設計情境中的預測能力。
  • 遞歸心智化的計算複雜性可能限制其在大規模設計系統中的直接應用。

Large-Scale ChatBot Validation Through Customer Digital Twin Simulations
cs.AIcs.CL 2026-07-31
大型語言模型（LLM）驅動的聊天機器人正在金融等受監管領域革新客戶服務，但大規模且具成本效益的驗證仍是安全部署的關鍵障礙。本研究提出了一項兩部分的貢獻，用於大規模聊天機器人驗證。首先，我們介紹了一種創建高擬真度合成客戶代理（SCA）作為數位雙生的方法，這些代理基於真實交易和對話數據，能夠自動生成並進行行為條件化，以模擬多樣的客戶檔案和互動風格。透過評估，我們證明了這些數位雙生能有效捕捉真實客戶行為的複雜性，為聊天機器人提供了一個安全且可控的測試環境。
如何大規模且經濟高效地驗證LLM聊天機器人在客戶服務中的安全性與有效性？
深度點評
  • 方法創新：提出「合成客戶代理」（SCA）作為數位雙生，並基於真實數據進行行為條件化，這是一種新穎且高效的聊天機器人驗證方法，超越了傳統的人工測試或簡單模擬。
  • 與既有研究比較：現有聊天機器人驗證方法多側重於技術指標或小規模使用者測試，本研究則透過大規模數位雙生模擬，解決了在受監管領域進行安全部署的擴展性與成本問題。
  • 潛在影響：為金融、醫療等高風險領域的AI應用提供了可靠的驗證框架，有助於提升AI系統的安全性、可靠性與使用者信任度，並加速其商業化落地。
研究貢獻
  • 開發了一種創建高擬真度合成客戶代理（SCA）的方法，用於大規模聊天機器人驗證。
  • 提出了基於真實交易與對話數據的行為條件化策略，以模擬多樣的客戶互動風格。
  • 為受監管領域的LLM聊天機器人安全部署提供了可擴展且成本效益高的驗證解決方案。
研究限制
  • 合成客戶代理的行為擬真度仍需持續校準與驗證，以確保其能完全代表真實客戶的複雜性。
  • 數位雙生模擬可能無法完全捕捉所有真實世界中不可預測的邊緣案例或新興行為模式。

No. 05
AgentGUI: An Interface for Observing and Steering Long-Running AI Agents
cs.HCcs.AI 2026-07-31
隨著AI代理在處理複雜、長期任務方面的能力日益增強，人類的監督能力因缺乏以人為中心的介面而逐漸落後。為了解決這個問題，我們引入了AgentGUI，一個使用者友善的本地託管圖形使用者介面，用於在多個並行、長期運行的會話中無縫觀察和引導AI代理。AgentGUI具有1)豐富的代理軌跡視覺化功能，2)有效的自動與手動引導機制，以及3)與開源工具的整合與協調。透過AgentGUI，人類操作者可以更有效地理解代理的決策過程、及時介入修正，並在複雜任務中保持對AI系統的控制，從而提升人機協作的效率與安全性。
如何設計一個介面以有效觀察並引導長期運行的AI代理，以提升人機協作？
深度點評
  • 方法創新：AgentGUI結合了豐富的軌跡視覺化、手動與自動引導機制，並強調與開源工具的整合，提供了一個全面且實用的AI代理監督與控制解決方案。
  • 與既有研究比較：現有AI代理介面多側重於單一任務或有限的互動，AgentGUI則專注於「長期運行」與「多個並行會話」的複雜情境，解決了大規模AI代理部署中的關鍵挑戰。
  • 潛在影響：為人機協作領域提供了重要的工具支援，特別是在需要高可靠性與透明度的應用場景（如自動駕駛、複雜系統管理），有助於建立更安全、更可信賴的AI系統。
研究貢獻
  • 開發了AgentGUI，一個用於觀察和引導長期運行AI代理的本地託管GUI。
  • 提供了豐富的代理軌跡視覺化功能，增強了人類對代理決策過程的理解。
  • 設計了有效的自動與手動引導機制，實現了對AI代理的精確控制。
研究限制
  • AgentGUI的有效性可能高度依賴於代理本身的透明度與可解釋性。
  • 在極端複雜或高速變化的情境下，人類透過GUI進行即時引導的認知負荷仍可能較高。

cs.CLcs.AI
核心問題
如何生成能適應不同情境且符合人類偏好的AI對話輪替行為？

DuplexGen框架透過結合人類對話語料庫的自然時序現象與基於人類偏好的合成方法，生成具有適應性輪替行為的對話。它克服了傳統模型單一規範的限制，能根據具體情境和角色設定，動態調整AI的輪替時機與方式。
心理學意涵

AI對話輪替更自然，人機互動更流暢，但真實性界線值得深思。

情境化提示 (Contextualized Prompting)。透過在提示中整合目標使用者的特徵（如歷史言論、情緒狀態）和對話情境資訊，引導LLM生成更具針對性、更符合接收者心理狀態的反駁言論。
心理學概念
說服 (Persuasion) 與 社會影響 (Social Influence)。研究利用情境化提示來提升反駁言論的說服力，這與社會心理學中「訊息來源可信度」、「訊息相關性」和「受眾特徵匹配」等影響說服效果的因素高度相關。當AI生成的反駁言論能更好地適應接收者的心理背景時，其改變觀點或行為的潛力也隨之增強。
應用場景
當前應用於線上內容審核，透過AI自動生成針對性反駁言論以減輕網路毒性。未來潛力包括心理諮詢輔助，AI可根據個案的語氣、情緒和背景生成更具同理心和說服力的引導語；公共衛生宣傳，針對不同社群的心理特徵生成更有效的健康訊息。這對心理學實務的啟發是，AI能大規模應用個性化說服策略，但需警惕其倫理邊界，確保用於正向引導而非操縱。
AI情境化提示，讓反駁言論更具說服力，網路毒性有望緩解。

Prompt × 心理學 No.02
Steering Instruction Hierarchies at Inference Time
cs.AIcs.CL
Prompt 技術
價值向量編輯 (Value Vector Editing)。這是一種在推論時（inference time）修改LLM內部狀態的技術，透過識別並編輯特定提示位置的快取價值向量，來恢復或強化高優先級指令（如系統提示）對低優先級指令（如使用者輸入）的控制權。
心理學概念
認知控制 (Cognitive Control) 與 人機信任 (Human-AI Trust)。在人類認知中，我們需要區分不同層級的指令並優先執行重要任務。本研究透過技術手段讓LLM也能實現類似的「指令層級控制」，這關乎AI的「心智」如何處理衝突資訊。當AI能可靠地遵循高優先級指令時，人類對其行為的可預測性和安全性會產生更高的信任，這對於建立穩固的人機協作關係至關重要。
應用場景
當前應用於提升LLM的安全性與可靠性，確保系統提示（如「作為一個有幫助的AI助手」）能有效覆蓋使用者可能提出的惡意或不當指令。未來潛力包括AI代理的精確行為引導，確保AI在複雜任務中始終遵循核心目標；AI倫理對齊，透過技術手段強化AI對倫理原則的遵守。這對心理學實務的啟發是，理解並控制AI的「認知」層級，是建立安全、可信賴人機互動的基礎。
編輯價值向量，AI指令層級分明，人機信任與安全再升級。

Prompt × 心理學 No.03
Evaluating Prompt Scope and Demonstration Similarity in Local LLM Machine Translation
cs.CL
Prompt 技術
提示範圍 (Prompt Scope) 與 少樣本學習 (Few-shot Learning)。提示範圍指在單一提示中要求LLM翻譯的語言數量或句子數量。少樣本學習則透過提供少量範例（demonstrations）來引導LLM的行為，本研究探討了這些範例與目標任務的相似性如何影響翻譯品質。
心理學概念
認知負荷 (Cognitive Load) 與 學習效率 (Learning Efficiency)。雖然研究對象是LLM，但其探討的提示設計原則與人類學習和認知過程有共通之處。例如，過大的提示範圍可能增加LLM的「認知負荷」，導致性能下降；而提供高相似度的少樣本範例，則類似於人類在學習新任務時，透過具體案例來降低理解難度、提升學習效率。這反映了人類在設計與AI互動時，潛意識地應用了對自身認知過程的理解。
應用場景
當前應用於優化LLM機器翻譯的提示策略，以提高翻譯的準確性和效率。未來潛力包括設計更高效的AI學習介面，透過調整提示的複雜度和範例的相關性，來引導AI在不同任務中達到最佳表現；AI輔助語言學習，根據學習者的認知特點設計個性化的提示，提升語言學習效果。這對心理學實務的啟發是，人類設計AI提示的過程，本身就是一種對AI「認知」的建模與優化，可反思人類自身的學習與認知策略。
提示範圍與範例相似度，影響LLM翻譯效能，啟示人機學習效率新思維。
