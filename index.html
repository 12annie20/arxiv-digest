No. 01
From ML Predictions to Informed Diagnostic Assistance Using the Toulmin Model of Argumentation
cs.AIcs.HC 2026-07-14
機器學習模型在視網膜診斷等領域生成預測時，其結果往往缺乏透明度與可解釋性。為解決此問題，本研究提出一個基於圖爾敏論證模型（Toulmin model of argumentation）的框架，將圖像診斷分解為主張、依據、保證、限定詞、反駁與支持等組件。該框架旨在提供結構化且可解釋的評估，而非僅接受ML模型的表面預測。研究利用專門的生物標誌物提取模型作為論證的依據，並結合可解釋AI方法，以提升診斷輔助的可靠性。透過這種論證式方法，使用者能更深入理解AI診斷背後的邏輯，從而做出更明智的決策。這對於提升臨床決策的信任度與安全性具有重要意義。
如何將ML診斷預測轉化為可解釋的輔助資訊？
深度點評
  • 方法創新：將圖爾敏論證模型引入ML診斷解釋，提供了一套系統性的框架來分解與呈現AI的推理過程，超越了傳統XAI方法的單點解釋。
  • 與既有研究比較：相較於僅提供特徵重要性或注意力圖的XAI，本研究更進一步將解釋結構化為論證，使其更貼近人類的認知與決策模式，提升了可理解性。
  • 潛在影響：此框架有望大幅提升醫療AI的可信賴度與臨床接受度，特別是在高風險診斷場景中，能幫助醫生理解AI的「思考」過程。
研究貢獻
  • 提出基於圖爾敏模型的AI診斷解釋框架
  • 將圖像診斷分解為可解釋的論證組件
  • 提升ML預測在臨床應用中的透明度與可靠性
研究限制
  • 模型對生物標誌物提取的準確性仍是關鍵限制
  • 論證組件的自動生成與評估可能存在挑戰

YUKTI: From Natural-Language Situations to Robust, Verifiable Decisions An Uncertainty-Typed Proposition IR, Assumption-Robust Pareto Frontiers, and a Regret Certificate
cs.AIcs.CY 2026-07-14
語言模型在將文字情境轉化為數值計畫時，常過度自信地依賴單一目標與點值係數，導致決策在假設不完全正確時變得脆弱。本研究指出，這種「計算的模仿」在實際預算、努力或臨床關注分配等高風險決策中是潛在的失敗模式。為此，YUKTI系統改變了自動公式化的目標，其核心是一個帶有不確定性類型命題的圖形表示。該系統結合了假設穩健的帕累托前沿分析與後悔證明，旨在從自然語言情境中生成穩健且可驗證的決策。YUKTI的目標是提供一個更具彈性與可靠性的決策框架，以應對現實世界中固有的不確定性。
如何從自然語言情境生成穩健且可驗證的決策？
深度點評
  • 方法創新：YUKTI引入了不確定性類型命題圖、假設穩健的帕累托前沿和後悔證明，這些機制共同構建了一個更為全面的決策框架，超越了傳統LLM直接生成單一計畫的模式。
  • 與既有研究比較：與現有NL4Opt、OptiMUS等依賴點值係數的管道不同，YUKTI強調對不確定性的顯式建模和穩健性分析，更能應對現實世界中假設偏差帶來的風險。
  • 潛在影響：該研究為AI輔助決策系統在高風險領域（如醫療、金融）的應用提供了更可靠的基礎，有助於減少因模型過度自信而導致的決策失誤。
研究貢獻
  • 提出不確定性類型命題圖表示
  • 整合假設穩健的帕累托前沿分析
  • 引入後悔證明以提升決策可驗證性
研究限制
  • 命題圖的構建與不確定性建模的複雜性
  • 系統在處理極端複雜情境時的擴展性挑戰

學生學習行為如何影響AI輔助教育的效益？

  • 潛在影響：這項研究為開發更具適應性和個性化的AI教育系統提供了實證基礎，有助於實現「因材施教」，確保AI技術能公平且有效地服務於所有學生。

數據敘事中的錯誤如何產生、傳播與複合？
深度點評
  • 方法創新：提出TIC分類法，提供了一個統一且全面的框架來分析數據敘事在「意義建構過程」中可能出現的各種問題，這比單純指出圖表錯誤更具深度。
  • 與既有研究比較：不同於分散在各領域（統計、視覺化、事實查核）的零碎研究，本論文提供了一個跨領域的整合視角，解釋了數據溝事失敗的系統性原因。
  • 潛在影響：該分類法可作為數據科學家、記者和政策制定者在溝通數據時的檢查清單，有助於提升數據敘事的品質、減少誤導，並增強公眾對數據的批判性理解。
研究貢獻
  • 提出數據敘事失敗的TIC分類法
  • 提供數據溝通問題的整體分析視角
  • 有助於提升數據敘事的透明度與可靠性
研究限制
  • 分類法的普適性需更多跨文化驗證
  • 對複雜數據敘事中多重錯誤的互動分析仍需深化

如何評估模型在不規則臨床時序數據上的問答能力？
深度點評
  • 方法創新：CLIR-Bench專注於「不規則」臨床時間序列數據，這是一個在現有基準中被忽視但極具挑戰性的現實問題，為該領域的研究提供了急需的評估工具。
  • 與既有研究比較：相較於現有針對規則時間序列或靜態醫學數據的基準，CLIR-Bench更真實地反映了臨床數據的複雜性，能更精確地衡量模型在實際臨床場景中的表現。
  • 潛在影響：該基準的建立將加速AI在臨床決策支援領域的進步，特別是在需要精確理解病患動態變化的場景，有助於開發更安全、更有效的醫療AI系統。
研究貢獻
  • 提出CLIR-Bench多模態臨床問答基準
  • 專注於不規則臨床時間序列數據
  • 推動AI在複雜臨床數據推理能力的發展
研究限制
  • 基準數據集的規模與多樣性可能仍需擴展

Prompt × 心理學 No.01
Format Sensitivity Index: Token-Controlled Prompt Wrapper Robustness and Schema Compliance in LLM Benchmarking
cs.CLcs.HC
Prompt 技術
Prompt Wrapper (提示詞包裝器): 透過改變提示詞的格式（如加入特定標籤、分隔符號或指令結構）來引導LLM行為，即使內容相同，格式微調也能顯著影響模型表現。
心理學概念
認知負荷 (Cognitive Load): 不同的提示詞格式可能影響LLM處理資訊的「認知負荷」，導致其在理解指令、提取關鍵資訊或生成符合預期格式的輸出時的效率差異。格式越清晰、結構越符合模型內部偏好，其處理負荷可能越低，表現越好。
應用場景
本研究揭示了提示詞格式對LLM性能的巨大影響，這對於開發者在設計LLM應用時至關重要。在實際應用中，例如聊天機器人、內容生成或數據提取任務，優化提示詞格式能顯著提升模型的準確性和輸出品質。對於心理學實務而言，這意味著在利用LLM進行心理評估、輔導對話或研究數據分析時，精心設計的提示詞格式能更有效地引導LLM產生符合心理學專業要求的回應，減少誤解和偏差，提升人機互動的效率與滿意度。
提示詞格式微調，足以顛覆LLM排行榜，細節決定成敗。

Structured Messages (結構化訊息): 在多跳代理中，將訊息以特定結構（如JSON、XML或預定義的模板）進行編碼，而非自由文本，以確保資訊傳遞的準確性和一致性。
心理學概念
資訊傳遞與失真 (Information Transmission and Distortion): 訊息格式會影響資訊在多個代理之間傳遞時的保真度。非結構化訊息在傳遞過程中更容易因代理的「解釋」或「重構」而產生偏差，類似於人類在口耳相傳中資訊失真的現象。結構化訊息則能減少這種認知上的「噪音」和「重構」，確保資訊的忠實傳遞。
應用場景
本研究對於設計多代理系統（如AI助理團隊、自動化工作流）中的溝通協議具有重要指導意義。在需要高保真資訊傳遞的場景，例如醫療診斷、法律諮詢或複雜專案管理，採用結構化訊息格式能顯著降低錯誤率。對心理學實務而言，這啟發我們思考在人機協作中，如何透過優化溝通介面和訊息格式，來減少人類與AI之間因資訊理解差異而產生的誤解和衝突，提升團隊協作效率和信任感。
代理間溝通，格式是忠實傳遞的關鍵，而非修正錯誤的萬靈丹。

"Code Is Cheap. Show Me the Talk.": Lessons from Teaching and Managing AI Coding Tool Usage in a Visualization Course
cs.HCcs.CY
Prompt 技術
Prompt Injections (提示詞注入): 在教學情境中，教師透過在學生提交的作業或與AI工具的互動中，策略性地插入特定提示詞或問題，以引導學生反思、解釋AI生成的內容，而非僅僅複製貼上。
心理學概念
學習動機與自我效能 (Learning Motivation and Self-Efficacy): 當學生過度依賴AI工具時，可能導致學習動機降低，並影響其解決問題的自我效能感。提示詞注入等干預措施，旨在促使學生從被動接受AI結果轉變為主動思考和解釋，從而提升內在學習動機和對自身能力的信心。
應用場景
本研究為AI時代的教育者提供了寶貴的經驗，特別是在程式設計和視覺化等實作課程中。透過「提示詞注入」和口頭提問等策略，教師可以有效引導學生將AI工具作為學習輔助，而非替代品，從而深化學習效果。對教育心理學實務而言，這啟發我們設計更多以學生為中心的AI學習活動，鼓勵批判性思維和問題解決能力，同時關注AI對學生學習習慣和心理發展的長期影響，確保技術能真正促進而非阻礙學習。
AI寫碼易，但引導學生思考才是教育的真諦。
