Alignment Plausibility: A New Standard for Assuring AI in Healthcare
cs.AIcs.HCcs.CY
大型語言模型（LLMs）已成為心理健康支援的重要工具，但其設計常受限於注意力經濟，優先考量用戶參與而非有效的心理支持。開發者對安全問題的回應多為被動式，僅處理顯性危害，卻忽略了長期風險，如依賴性、界線模糊或扭曲信念的放大。本研究提出「對齊合理性」作為AI在醫療領域的新標準，旨在確保LLMs的運作目標與心理健康支援的臨床目標一致。此標準要求LLMs的設計應主動預防潛在危害，並促進用戶的自主性與福祉。研究強調，AI在醫療領域的應用需超越表面安全考量，深入探討其對人類心理健康的長期影響。這項工作為AI在敏感領域的倫理設計與評估提供了更全面的視角。
如何確保AI在心理健康支援中，其運作目標與臨床效益而非商業參與度對齊？
深度點評
  • 方法創新在於提出「對齊合理性」這一新標準，超越傳統的反應式安全措施，強調AI設計應主動與心理健康支援的臨床目標深度整合，而非僅修補顯性問題。
  • 相較於現有研究多關注LLM的即時危害檢測與緩解，本研究更進一步探討了AI在心理健康領域可能引發的長期、微妙的風險模式（如依賴性、界線侵蝕），並呼籲從根本上重新思考AI的設計目標。
  • 這項工作對AI在醫療、特別是心理健康領域的發展具有深遠影響，它促使開發者和政策制定者重新審視AI的倫理框架，強調以人為本的設計原則，並可能引導未來AI產品的認證與監管方向。
研究貢獻
  • 提出「對齊合理性」作為AI在醫療領域的新評估標準。
  • 揭示了LLM在心理健康支援中，注意力經濟導向設計的潛在長期風險。
  • 呼籲AI設計應從根本上與臨床目標對齊，而非僅處理表面危害。
研究限制
  • 「對齊合理性」的具體量化指標和實施細則仍需進一步研究與驗證。
  • 將此標準推廣至不同文化背景和醫療體系可能面臨挑戰。

HeadRoom: Lightweight, Edge-deployable Pipeline for Adaptive Notification Routing
cs.HCcs.AI
新興穿戴裝置如智慧眼鏡能透過多種感官通道傳遞通知，但如何選擇最佳通道仍是未解之題。本研究提出HeadRoom，一個輕量級、可邊緣部署的管道，能即時從第一人稱視角影像和音訊估計視覺與聽覺通道的可用性。我們進行了一項受控用戶研究（N=25），結果顯示在高感知負荷下，將通知路由至較可用的通道，能顯著縮短反應時間。這項技術有助於優化穿戴裝置的通知系統，減少用戶的認知負擔。HeadRoom的設計強調輕量化與即時性，使其適用於資源受限的邊緣設備。這項研究為未來智慧穿戴裝置的設計提供了實用的指導。
如何即時判斷穿戴裝置用戶的感官通道可用性，以實現適應性通知路由？
深度點評
  • 方法創新在於開發了一個輕量級且可邊緣部署的管道HeadRoom，能即時分析用戶的視聽環境，並據此動態調整通知路由，有效解決了穿戴裝置通知過載的問題。
  • 相較於傳統通知系統的靜態或基於用戶偏好的設定，本研究提出的適應性路由機制能更精準地響應用戶當前的感知狀態，在高負荷情境下表現出顯著的性能提升。
  • 這項技術對提升穿戴裝置的使用者體驗、減少認知中斷具有重要意義，特別是在需要高度專注的場景（如駕駛、手術），其應用潛力巨大，並為未來智慧助理的環境感知能力奠定基礎。
研究貢獻
  • 提出HeadRoom，一個輕量級、邊緣部署的適應性通知路由管道。
  • 開發了即時估計視覺與聽覺通道可用性的方法。
  • 實驗證明在高感知負荷下，適應性路由能縮短用戶反應時間。
研究限制
  • 研究僅在受控環境下進行，真實世界複雜情境的泛化能力需進一步驗證。
  • 目前僅考慮視覺與聽覺通道，未來可擴展至觸覺等其他感官通道。

Adversarial Social Epistemology for Assemblies of Humans and Large Language Models
cs.CLcs.CYcs.AI
本研究為人類與大型語言模型（LLMs）密集互動的溝通環境，勾勒出對抗性社會認識論（ASE）框架。在這種環境中，公開主張透過證詞、推論、機構認證和默契信任鏈條來支撐。然而，代理人有動機和機會為私利、聲譽、修辭或物質收益而扭曲、渲染、省略、捏造或策略性地不明確資訊。我們認為，這些現象無法被現有的「知識泡沫」、「迴聲室」或「錯誤資訊」等概念充分捕捉。ASE框架旨在更全面地理解在AI時代，資訊如何被策略性地操縱，以及這對集體知識建構的影響。這項工作為理解AI對社會認識論的深遠影響提供了新的視角。
在人類與LLM共存的溝通環境中，如何理解資訊被策略性操縱的社會認識論現象？
深度點評
  • 方法創新在於提出「對抗性社會認識論」（ASE）框架，超越了傳統的資訊失真概念，更深入地分析了在AI時代，代理人（包括LLM）如何策略性地利用溝通結構來操縱資訊，這為理解AI時代的信任與知識建構提供了新工具。
  • 相較於現有研究多將AI視為資訊傳播的工具或來源，本研究將LLM納入社會認識論的代理人範疇，探討其在複雜溝通景觀中可能扮演的策略性角色，這擴展了對AI社會影響的理解深度。
  • 這項工作對社會心理學、傳播學和AI倫理領域具有重要影響，它促使我們重新思考在AI參與的溝通環境中，如何評估資訊的真實性、建立信任，並設計更具韌性的知識系統，以應對潛在的惡意操縱。
研究貢獻
  • 提出對抗性社會認識論（ASE）框架，以理解人類與LLM互動中的資訊操縱。
  • 指出現有概念（如知識泡沫）不足以捕捉AI時代的資訊扭曲現象。
  • 分析了代理人為私利扭曲資訊的動機與機會。
研究限制
  • ASE框架仍處於概念性階段，需要更多實證研究來驗證其預測能力和應用範圍。
  • 如何具體識別和量化LLM在社會認識論中的「策略性」行為，仍是一個挑戰。

ImputeViz: A Visual Analytics Dashboard for Diagnosing Missing Data and Comparing Imputation Methods
cs.HCcs.AI
缺失資料是科學、社會科學和公共衛生研究中普遍存在的障礙，常導致分析偏誤，並將處理缺失值的責任歸咎於分析師。本研究介紹ImputeViz，一個整合的視覺分析儀表板，支援診斷缺失模式、配置插補模型和評估結果。該系統將MICE、隨機森林、XGBoost和kNN等廣泛使用的插補方法整合到一個互動式環境中，使缺失模式變得明確。為支援地理空間推理，ImputeViz還提供了地圖視圖，以視覺化地理區域內的缺失資料分佈。這項工具旨在簡化缺失資料處理的複雜性，提高分析的透明度和可靠性。ImputeViz的設計強調用戶友好性，讓研究人員能更有效地處理資料。
如何透過視覺分析工具，有效診斷缺失資料模式並比較不同插補方法的效能？
深度點評
  • 方法創新在於將多種主流插補方法（MICE, Random Forest, XGBoost, kNN）整合到一個直觀的視覺分析儀表板ImputeViz中，並特別加入了地理空間視圖，這顯著提升了缺失資料診斷和插補策略選擇的效率與透明度。
  • 相較於現有工具多側重於單一插補方法的實施或僅提供基礎的缺失模式統計，ImputeViz提供了一個全面的互動式環境，讓分析師能從多維度（包括地理空間）理解缺失資料的特性，並直接比較不同插補方案的影響。
  • 這項工具對社會科學、公共衛生和任何處理複雜資料集的領域具有重要意義，它降低了缺失資料處理的技術門檻，有助於減少分析偏誤，提高研究結果的可靠性，並促進資料科學實踐的標準化。
研究貢獻
  • 開發ImputeViz，一個整合的視覺分析儀表板，用於缺失資料診斷與插補方法比較。
  • 整合了多種主流插補方法，並提供互動式視覺化介面。
  • 引入地理空間視圖，支援地理區域內的缺失資料模式分析。
研究限制
  • ImputeViz的效能可能受限於資料集的大小和複雜性，對於超大型資料集可能存在性能瓶頸。
  • 插補方法的選擇和參數配置仍需用戶具備一定的統計知識，工具的自動化程度有待提升。

No. 05
Feedback Manipulation Regularization: Enabling Offline Agent Alignment for Imitation Learning
cs.AI
強化學習（RL）研究日益關注對齊問題，旨在確保代理人學習符合人類價值的行為。儘管人類示範和回饋對於對齊至關重要，但現有方法主要使用多階段管道結合這些訊號，這些管道是為語言生成的上下文多臂賭博機框架設計的。然而，很少有研究探討這些互補輸入如何作為更豐富、相互關聯的訊號，用於完全序列決策環境中的單階段離線訓練。本研究提出回饋操縱正規化（Feedback Manipulation Regularization），一種新穎的離線學習方法，旨在透過結構化人類回饋來引導代理人的行為。該方法將人類示範和回饋整合到一個統一的框架中，以實現更有效的代理人對齊。這項工作為RL代理人的行為對齊提供了新的思路。
如何將人類示範與回饋整合至單階段離線訓練，以實現RL代理人的行為對齊？
深度點評
  • 方法創新在於提出「回饋操縱正規化」，將人類示範和回饋這兩種關鍵對齊訊號，整合到一個單階段的離線強化學習框架中，這克服了現有多階段管道的複雜性與局限性，為代理人對齊提供了更直接且高效的途徑。
  • 相較於現有研究多將人類回饋視為獨立的獎勵訊號或僅用於語言生成任務，本研究將其視為一種可操縱的正規化項，在完全序列決策環境中引導代理行為，這擴展了人類回饋在RL對齊中的應用範疇和深度。
  • 這項工作對AI倫理、AI安全和人機協作領域具有重要影響，它為開發更符合人類價值觀的AI代理提供了實用方法，特別是在需要精確行為控制和高可靠性的應用場景（如自動駕駛、機器人操作）中，其潛力巨大。
研究貢獻
  • 提出「回饋操縱正規化」方法，用於離線代理人對齊。
  • 將人類示範與回饋整合到單階段離線訓練框架中。
  • 為完全序列決策環境中的代理人對齊提供了新途徑。
研究限制
  • 回饋操縱正規化的有效性可能高度依賴於人類回饋的品質和一致性，低品質回饋可能導致次優對齊。
  • 該方法在複雜、高維度動作空間中的可擴展性仍需進一步驗證。

Aligning Clinical Needs and AI Capabilities: A Survey on LLMs for Medical Reasoning
cs.AIcs.HC
核心問題
大型語言模型如何能更好地滿足臨床醫療推理的需求？
方法亮點
本研究採用雙視角方法，將臨床實踐與計算方法相結合。在臨床方面，依據米勒金字塔建立五級能力框架，從知識回憶到動態病例管理。在計算方面，將演繹、歸納和溯因推理與LLM的特定能力連結，並探討了多模態整合、知識增強和可解釋性等技術，以提升LLM在醫療推理中的效能。

一份全面且具前瞻性的醫療LLM應用指南，為臨床與AI的深度融合指明方向。

LLM × 心理學 No.02
How YouTube Frames ChatGPT Use in Education: An Epistemic Network Analysis with Supporting Multimodal Metadata
cs.CYcs.CL
核心問題
YouTube影片如何呈現ChatGPT在教育中的應用，以及這些呈現方式如何影響觀眾反應？
方法亮點
本研究採用PRISMA指南篩選了52部教育類YouTube影片，透過多模態元數據（如文字稿、標題、縮圖和觀眾評論）進行認識論網絡分析。研究識別出三種結構不同的論述群體：將ChatGPT定位為概念支架、作為效率工具，以及作為批判性思維的挑戰者，並分析這些框架與觀眾參與度及平台傳播的關係。
心理學意涵
這項研究揭示了公眾對AI工具（如ChatGPT）在教育領域的認知框架，對教育心理學和社會心理學具有重要意義。它說明了不同呈現方式如何影響學習者對AI的接受度、使用態度及學習成果，有助於教育者設計更有效的AI整合策略。同時，研究也觸及了資訊傳播中的「框架效應」和「社會影響」，提醒我們在推廣AI教育時需注意其潛在的社會心理影響，並引導學生發展批判性思維，以應對AI時代的資訊挑戰。這對於理解AI時代的學習行為與知識建構至關重要。

LLM × 心理學 No.03
Scalable and Culturally Specific Stereotype Dataset Construction via Human-LLM Collaboration
cs.CLcs.CY
核心問題
如何以可擴展且具成本效益的方式，建構跨文化、特定語言的LLM刻板印象資料集？
方法亮點
本研究提出一種成本效益高的人類-LLM協作註釋框架，並將其應用於建構EspanStereo，一個涵蓋歐洲和拉丁美洲多個西班牙語國家的西班牙語刻板印象資料集。該框架結合了人類專家對文化細微差別的理解與LLM的生成能力，以克服其他語言資料集稀缺和手動註釋成本高的問題。
心理學意涵
這項研究對社會心理學中關於偏見和刻板印象的跨文化研究具有重大貢獻，特別是在AI時代。它提供了一種有效方法來識別和量化LLM中存在的文化特定偏見，這對於理解AI如何反映或放大社會刻板印象至關重要。心理學家可以利用此類資料集來研究偏見的形成機制、文化差異對偏見的影響，以及如何設計更具文化敏感性的AI系統。同時，這也引發了關於AI倫理、公平性和文化適應性的重要討論，促使我們思考如何在AI開發中納入多元文化視角，避免全球化AI產品加劇特定文化群體的偏見。這對於構建公平、包容的AI系統至關重要。
透過人機協作，為LLM偏見研究開闢跨文化新徑，意義深遠。

Prompt × 心理學 No.01
When Implausible Tokens Get Reinforced: Tail-Aware Credit Calibration for LLM Reinforcement Learning
cs.AIcs.CL
Prompt 技術
RLHF (Reinforcement Learning from Human Feedback) 的改進。傳統RLHF在獎勵分配時可能對所有token一視同仁，導致低機率的錯誤token也被強化。本研究提出「尾部感知信用校準」，透過區分不同token的合理性，更精確地分配獎勵，避免「正向信用污染」。
心理學概念
認知偏誤 (Cognitive Bias) 與學習理論。論文探討不合理token被強化，導致模型學習到錯誤的偏誤，這與人類認知中的確認偏誤或過度概化有相似之處。傳統RLHF的均勻信用分配機制，在某種程度上反映了學習過程中未能有效區分資訊品質的偏誤，而尾部感知信用校準則試圖糾正這種偏誤，使其學習過程更接近人類的批判性思維。
應用場景
此技術能顯著提升LLM的推理能力和事實準確性，減少幻覺現象。在心理諮詢、教育輔導等需要高可靠性資訊的AI應用中，能確保AI提供更精準、無偏的建議，避免誤導用戶。未來潛力在於開發更具「批判性」和「自我糾正」能力的AI，使其在複雜情境下能做出更明智的判斷，對心理學實務的啟發是，AI的學習機制應更精細地模擬人類的認知過程，特別是在處理不確定性和錯誤資訊時的判斷力。
精準校準RL獎勵，讓LLM學習更明智，告別「正向污染」的幻覺。

Prompt × 心理學 No.02
When Debiasing Backfires: Counterintuitive Side Effects of Preprocessing-Based Stereotype Mitigation
cs.CLcs.CY
Prompt 技術
Preprocessing-Based Stereotype Mitigation (基於預處理的刻板印象緩解)。這類技術透過在模型訓練前或訓練後，對資料集進行去偏處理（如移除或修改帶有刻板印象的詞語），以影響模型生成行為，使其輸出更符合公平性原則。
心理學概念
社會偏見 (Social Bias) 與刻板印象 (Stereotypes)。論文直接探討去偏處理如何影響LLM的刻板印象，及其可能引發的意想不到的副作用。這與社會心理學中關於偏見的形成、傳播和消除機制高度相關，特別是「反彈效應」或「補償效應」，即試圖壓制某種偏見可能導致其以其他形式或在其他群體中顯現。
應用場景
此研究揭示了AI去偏處理的複雜性，提醒開發者在追求公平性時需謹慎。在心理健康、教育、招聘等領域，AI應用若未能有效處理偏見，可能加劇社會不公。理解這些「反彈效應」有助於設計更精細的去偏策略，例如結合多維度偏見檢測和情境感知調整。對心理學實務的啟發是，AI的偏見緩解不僅是技術問題，更是深刻的社會心理學問題，需要跨學科合作來開發真正公平、無害的AI系統，並教育用戶認識AI偏見的潛在風險。
去偏反噬，AI倫理的複雜性遠超想像，需警惕「好心辦壞事」。

Prompt × 心理學 No.03
Feedback Manipulation Regularization: Enabling Offline Agent Alignment for Imitation Learning
cs.AI
Prompt 技術
Feedback Manipulation Regularization (回饋操縱正規化)。這是一種離線強化學習方法，透過結構化人類回饋與示範，在單階段訓練中引導代理行為，使其與人類價值觀對齊。它將人類回饋視為一種正規化項，用於塑造代理人的決策策略。
心理學概念
行為塑造 (Behavioral Shaping) 與價值對齊 (Value Alignment)。論文旨在透過人類回饋來塑造AI代理的行為，使其與人類價值觀對齊，這與行為心理學中透過獎勵和懲罰來逐步塑造複雜行為的原理相似。同時，它也觸及了AI倫理中如何將抽象的人類價值觀轉化為可操作的AI行為準則的核心問題。
應用場景
此技術對於開發安全、可靠且符合倫理規範的AI代理至關重要，尤其是在高風險領域如自動駕駛、醫療機器人或個人助理。透過精確的人類回饋，AI能學習更細緻的行為模式，避免潛在的倫理衝突。未來潛力在於實現更自然、直觀的人機協作，讓AI能更好地理解人類意圖和偏好。對心理學實務的啟發是，人類回饋的設計和應用本身就是一門心理學藝術，如何有效提取和編碼人類的價值觀，將是提升AI對齊能力的關鍵，這也為人機互動設計提供了新的研究方向。
精準回饋塑造AI行為，讓機器更懂人類價值，實現深度對齊。
