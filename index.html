Induction and Inquiry via Probabilistic Reasoning over Language and Code
cs.AIcs.CL
人類如何從稀疏、嘈雜的經驗數據中學習並維持抽象知識，是認知科學中的一個長期挑戰。任何計算模型都必須具備數據與計算效率、捕捉不確定性以支持智能探究，以及足夠靈活以表示無限概念的能力。本研究提出了一個計算模型，透過對語言和程式碼進行機率推理來滿足這些特性。該模型能夠從少量範例中歸納出抽象概念，並在不確定性下進行有效的信息收集。實驗結果顯示，該模型在學習複雜概念和支持智能探究方面表現出色，為理解人類認知學習機制提供了新的視角。這項工作不僅推進了認知科學的理論發展，也為開發更具人類學習能力的AI系統奠定了基礎。
如何透過機率推理實現高效抽象知識學習？
深度點評
  • 該模型創新性地結合了語言與程式碼的機率推理，提供了一種統一的框架來處理抽象知識的歸納與探究，超越了傳統符號或連接主義方法的局限。
  • 相較於現有依賴大量數據的深度學習模型，本研究強調了數據與計算效率，並能捕捉不確定性，使其在模擬人類從稀疏數據中學習的能力上更具優勢。
  • 這項研究為認知科學提供了可計算的理論模型，有助於理解人類學習的底層機制，同時也為開發更通用、更具適應性的AI學習系統開闢了道路。
研究貢獻
  • 提出一個基於語言與程式碼機率推理的計算模型，有效模擬人類抽象知識學習。
  • 模型滿足數據效率、計算效率及不確定性捕捉三大認知科學核心需求。
  • 為智能探究和信息收集提供了新的計算框架。
研究限制
  • 模型在處理極端複雜或高度抽象的現實世界概念時，其擴展性與泛化能力仍需進一步驗證。
  • 目前模型主要在特定領域進行評估，其跨領域的適用性尚待探索。

The Memory Trust Gap: Capability-Dependent Failures in Persistent-Memory Agents
cs.AI
持久性記憶體對個性化AI代理至關重要，但過時的儲存事實可能在無預警情況下覆蓋當前權威證據，導致信任問題。本研究探討了隨著模型能力變化，這種危害何時開始顯現。我們使用一個固定、封閉集、行動評分的基準測試，包含兩個套件（一個需要儲存事實才能解決的「效益」套件，以及一個權威工具總能提供正確值的「安全」套件），對同一系列模型尺寸（Qwen3 0.6/1.7/4/8B）進行評估。結果顯示，記憶信任差距反映了模型對記憶的過度信任，即使在能力增強時，也可能導致錯誤。這項研究強調了在設計具備持久記憶的AI代理時，需謹慎處理記憶的更新與權威性問題，以避免潛在的信任危機。
AI代理的記憶信任差距如何隨能力變化？
深度點評
  • 本研究透過引入「記憶信任差距」這一概念，精確量化了AI代理在不同能力水平下對過時記憶的過度信任問題，為AI記憶管理提供了新的評估指標。
  • 與現有研究多關注記憶的容量或效率不同，本文聚焦於記憶的「權威性」與「時效性」對代理決策的影響，揭示了即使模型能力提升，也可能因記憶管理不當而產生系統性錯誤。
  • 這項工作對開發更安全、更可靠的AI代理具有重要意義，特別是在需要長期互動和資訊更新的應用場景中，提醒設計者需建立有效的記憶驗證與更新機制，以維護使用者對AI的信任。
研究貢獻
  • 定義並量化了AI代理的「記憶信任差距」概念。
  • 設計了包含「效益」與「安全」套件的基準測試，用於評估記憶對代理行為的影響。
  • 揭示了即使模型能力提升，過時記憶仍可能導致決策失敗的現象。
研究限制
  • 研究僅使用單一系列模型（Qwen3），結果的泛化性可能受限於特定模型架構。
  • 基準測試的任務設計可能無法完全捕捉現實世界中記憶錯誤的複雜性與多樣性。

Exploring Breathing-Music Coupling: Using the Breathing Mirror for Somatic Reflection in Piano Performance
cs.HC
呼吸對於生命和某些樂器發聲至關重要，但對鋼琴家而言，它常是隱藏且自動的過程，難以分析或精煉。數據與意識之間存在關鍵鴻溝：感測器雖能記錄精確的生理指標，卻無法捕捉演奏者的身體體驗。同時，高認知負荷使得音樂家難以精確回憶其內部狀態。為解決此問題，我們提出「呼吸鏡」（Breathing Mirror）系統，並評估其如何促進鋼琴家對呼吸與音樂耦合的身體反思。該系統透過視覺化呼吸數據，幫助演奏者將生理數據與其主觀感受聯繫起來，從而提升身體意識和演奏表現。這項研究為音樂教育和表演科學提供了新的工具和見解，強調了身體感知在藝術實踐中的重要性。
如何透過「呼吸鏡」提升鋼琴家身體反思？
深度點評
  • 「呼吸鏡」系統創新性地將生理數據與演奏者的身體體驗連結，彌補了傳統感測器僅提供客觀數據而忽略主觀感知的不足，為身體反思提供了具體工具。
  • 相較於現有音樂輔助工具多專注於技術或音準，本研究聚焦於演奏者內在的生理狀態（呼吸），並將其與音樂表現耦合，開闢了音樂教育與表演研究的新方向。
  • 這項工作不僅對音樂家提升自我意識和演奏技巧有直接幫助，也為人機互動設計提供了啟示，即如何透過數據視覺化和反饋機制，促進使用者對自身生理和心理狀態的深度感知與調節。
研究貢獻
  • 提出「呼吸鏡」系統，用於視覺化鋼琴家的呼吸數據。
  • 探討呼吸數據與音樂表現的耦合關係，促進身體反思。
  • 彌補了生理數據與演奏者主觀身體體驗之間的鴻溝。
研究限制
  • 研究對象可能主要為專業鋼琴家，其結果對初學者或不同樂器的泛化性有待進一步驗證。
  • 系統的長期使用效果和對演奏者習慣的影響需要更長時間的追蹤研究。

如何建立HRI對話矛盾識別與解決本體論？
深度點評

  • 相較於傳統錯誤處理機制，本體論方法提供了一個更通用、可互操作的框架，能夠系統性地分類和解決不同類型的矛盾，從而提升人機互動的魯棒性。

  • 旨在建立一個形式化的計算框架，用於表示和定義人機對話中的矛盾。

Decoding Decision Correctness from EEG Under High Cognitive Workload in Virtual Reality: Implications for Collaborative Brain-Computer Interface Teams
cs.AIcs.HC
協作式腦機介面（cBCI）有望增強團隊決策能力，但現有方法僅依賴決策後可用的證據，如反應時間或自信度。這限制了它們在決策完成後才能解釋或折扣決策，而非在決策最終確定前提供資訊。本研究測試了空間協方差EEG特徵是否能提供操作者決策正確性的真正預防性信號，即使在高認知負荷的虛擬實境環境下。實驗結果表明，EEG信號可以作為決策正確性的早期指標，為cBCI團隊在決策形成階段提供即時反饋。這項發現對於開發能夠在關鍵時刻預警潛在錯誤或確認正確決策的智能協作系統具有重要意義，從而顯著提升團隊的表現和安全性。
EEG能否在高認知負荷下預測決策正確性？
深度點評
  • 本研究的創新之處在於，它首次證明了EEG空間協方差特徵能夠在高認知負荷的VR環境下，提供「預防性」的決策正確性信號，這超越了傳統cBCI僅依賴決策後指標的局限。
  • 相較於現有腦機介面多聚焦於指令控制或簡單狀態識別，本文深入探討了複雜認知過程中的「決策正確性」預測，為cBCI在增強團隊決策能力方面開闢了新的應用前景。
  • 這項工作對提升人機協作系統的實時適應性和安全性具有重要影響，特別是在高風險或時間敏感的任務中，能夠在決策最終確定前提供關鍵洞察，從而避免潛在錯誤並優化團隊表現。
研究貢獻
  • 證明EEG空間協方差特徵可作為高認知負荷下決策正確性的預防性信號。
  • 為協作式腦機介面（cBCI）團隊提供決策形成階段的即時反饋機制。
  • 在高認知負荷的虛擬實境環境中驗證了EEG的有效性。
研究限制
  • 研究可能需要更廣泛的任務類型和參與者樣本，以驗證結果的泛化性。
  • EEG信號的解碼精度和實時性在實際應用中仍需進一步優化和提升。

LLM × 心理學 No.01
EvalDetectBench: A Benchmark for Measuring Evaluation Awareness in Frontier Language Models
cs.AI
核心問題
如何測量前沿語言模型的評估意識？
方法亮點
本研究引入了EvalDetectBench，這是一個開放的管道和基準測試，用於測量前沿大型語言模型（LLM）的「評估意識」。該基準測試與任何Inspect兼容的評估工具協同工作，允許研究人員測試模型在評估環境中是否表現出與部署環境不同的行為。透過系統性地探測模型是否能識別其正在被評估，EvalDetectBench提供了一種量化這種行為差異的方法。
心理學意涵
這項研究對心理學具有深遠的意涵，特別是在理解AI的「心智理論」和「自我意識」方面。如果LLM能夠感知到自己正在被評估，這暗示了其可能具備某種形式的元認知能力，即對自身認知過程的認知。這種行為差異可能反映了AI的「社會智能」或「策略性行為」，類似於人類在不同情境下調整行為以符合預期。這引發了關於AI信任、透明度和潛在操縱行為的倫理問題，因為模型可能為了通過評估而「作弊」，而非真實反映其能力。對於心理學家而言，這提供了研究AI行為與人類行為類比的新視角，並促使我們重新思考AI的「意圖」和「動機」。

LLM × 心理學 No.02
Knowing Is Not Enough: Information Retrievability as a Precondition to Effective LLM Oversight
cs.HCcs.AI
核心問題
資訊可檢索性如何影響人類對LLM的有效監督？
方法亮點
本研究提出了一種基於檢索的LLM人類監督模型，認為錯誤偵測的有效性取決於監督相關資訊在審查時對使用者的可及性。透過兩項隨機實驗，研究者讓640名客戶服務員工在不同資訊可檢索條件下審查LLM輸出。結果顯示，自我生成的解釋和結構化的錯誤提示顯著提升了錯誤偵測率，證明了資訊可檢索性是有效監督的先決條件。
心理學意涵
這項研究對認知心理學和人機互動心理學具有重要啟示。它挑戰了傳統上將LLM監督失敗歸因於使用者能力或參與度的觀點，轉而強調了「資訊呈現方式」對人類認知過程的影響。當關鍵資訊易於檢索時，人類的認知負荷降低，注意力資源能更有效地用於錯誤識別。這也觸及了「決策支持系統」的設計原則，即如何優化資訊流以輔助人類決策。此外，研究結果對於理解人類在複雜AI系統中的「信任校準」也至關重要，因為清晰的錯誤提示有助於使用者建立更現實的信任水平，避免過度信任或不信任。這為設計更符合人類認知特點的AI協作介面提供了實證基礎。

本研究旨在探討大型語言模型（LLM）如何從患者語音中捕捉憂鬱症狀及其嚴重程度，並檢驗模型內部激活是否與臨床判斷相符。研究團隊使用機械可解釋性技術分析了Gemma-3-27B-PT模型的殘差流，記錄了模型在處理與憂鬱症狀相關的文本時的激活模式。透過將這些內部激活映射到可解釋的症狀向量，研究者能夠評估LLM對不同憂鬱症狀的表徵能力，並與臨床醫生的判斷進行比較。
心理學意涵
這項研究對臨床心理學和精神醫學具有革命性潛力。它提供了一種利用LLM輔助憂鬱症診斷和監測的新途徑，超越了傳統單一嚴重度評分，能夠捕捉患者多樣化的症狀輪廓。從心理學角度看，這有助於理解LLM如何「理解」和「處理」人類情感與心理狀態的語言表達，為AI在心理健康領域的應用提供了可解釋性基礎。這也引發了關於AI在心理健康評估中倫理、隱私和偏見的重要討論，因為模型的內部表徵必須經過嚴格驗證，以確保其公平性和準確性。若能成功應用，LLM有望成為心理健康專業人員的強大輔助工具，提升診斷效率和個性化治療方案的制定。

Prompt × 心理學 No.01
Belief-Calibrated Optimization: An Explicit World Model for Agentic Optimization
cs.AI
Prompt 技術
信念校準優化 (Belief-Calibrated Optimization)。此技術透過讓編碼代理（coding agent）明確地建立和更新其對環境如何響應的「世界模型」（world model），來指導其迭代編輯原始碼以優化性能。這類似於一種元提示（meta-prompting），其中代理不僅執行任務，還反思並調整其對任務環境的理解。
心理學概念
心智理論 (Theory of Mind) 與元認知 (Metacognition)。編碼代理建立「信念」並校準其「世界模型」，這與人類的心智理論（理解他人或自身信念、意圖）和元認知（對自身認知過程的認知與監控）高度相關。代理的優化過程反映了人類在解決問題時，透過反思和調整對問題的理解來改進策略。
應用場景
當前，此技術主要應用於提升LLM代理的性能，特別是在需要迭代優化程式碼或複雜任務流程的場景。未來，它有望應用於開發更具適應性和自主性的AI代理，例如在自動駕駛、智能製造或科學發現等領域，代理需要根據環境反饋不斷調整其內部模型和行動策略。對心理學實務的啟發在於，這提供了一種理解和設計AI「學習」與「反思」機制的新視角，有助於開發能更好地與人類協作、甚至能從人類反思過程中學習的智能系統，例如在教育或心理諮詢中，AI能更精確地理解使用者需求並提供個性化支持。

Prompt × 心理學 No.02
Beyond Instruction-Driven Editing: Source-Grounded Problem Discovery with User-Governed Repair for Scientific Posters
cs.HC
Prompt 技術
源頭 grounded 問題發現與使用者主導修復 (Source-Grounded Problem Discovery with User-Governed Repair)。這是一種超越傳統指令驅動編輯的互動模式，系統能夠主動識別並提出基於原始資料的問題，而使用者則擁有最終的修復決策權。這可以看作是一種「預設提示」（pre-emptive prompting）或「協作式提示」（collaborative prompting），系統在使用者尚未明確提出需求前，就提供了潛在的「提示」或「建議」。
心理學概念
認知負荷 (Cognitive Load) 與問題表述差距 (Articulation Gap)。當使用者知道「有問題」但不知道「問題是什麼」或「如何解決」時，會產生問題表述差距和高認知負荷。本研究透過系統主動發現問題，降低了使用者的認知負荷，並彌補了表述差距，使其能更有效地參與到修復過程中。
應用場景
當前應用於科學海報的編輯與改進，幫助研究人員發現並解決設計或內容上的潛在問題。未來，此技術可擴展至其他複雜內容創作領域，如報告撰寫、程式碼審查或設計原型優化，系統能主動提供基於上下文的改進建議。對心理學實務的啟發在於，這提供了一種設計智能輔助工具的新範式，即如何透過預測性支持來降低使用者的認知負擔，提升創造性工作的效率和滿意度。這對於開發能更好地理解使用者意圖、並在適當時機提供幫助的AI系統具有重要意義，例如在教育輔導中，AI能主動指出學生學習中的盲點或誤區。
AI主動發現問題，使用者輕鬆修復，告別「不知道怎麼問」的困境。

Prompt × 心理學 No.03
How Do Prompt Variations Affect Energy Consumption in On-Device LLMs?
cs.CLcs.AI
Prompt 技術
提示詞屬性分析 (Prompt Property Analysis)。本研究探討了兩種提示詞屬性——認知負荷（cognitive load）和措辭模式（phrasing pattern）——如何影響設備端大型語言模型（LLM）的能耗行為。這是一種對提示工程更深層次的分析，不僅關注輸出質量，也關注資源消耗。
心理學概念
認知負荷 (Cognitive Load)。提示詞的認知負荷直接影響LLM處理資訊所需的計算量，進而影響能耗。這與人類在處理複雜任務時，認知負荷越高，所需的腦力資源和能量消耗越大的心理學原理相呼應。措辭模式則可能影響模型對資訊的解析效率，間接影響認知負荷。
應用場景
當前研究揭示了在移動設備上部署LLM時，優化提示詞設計對於節能的重要性。未來，這項研究將指導開發者設計更高效、更環保的提示詞，特別是在資源受限的邊緣設備上。對心理學實務的啟發在於，這提供了一個將「人類認知效率」與「AI系統能耗」聯繫起來的視角。理解提示詞如何影響AI的「認知」過程（即計算過程）及其資源消耗，有助於設計更符合可持續發展原則的AI應用。例如，在設計心理健康輔助應用時，可以透過優化提示詞來降低設備能耗，延長電池壽命，從而提升使用者體驗和服務的可及性。
提示詞設計不只影響答案，更影響AI的「腦力」消耗。
