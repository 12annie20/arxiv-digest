Socioduality: A Relational Process Framework for Human-AI Interaction
cs.HCcs.AI 2026-08-13
人機互動研究常側重於個體能力、組合表現或最終產出，卻忽略了互動過程中一方的回應如何形塑另一方後續貢獻的條件。本文提出了「社會二元性」(socioduality) 概念，這是一個序列性、互惠且具歷史承載的關係過程，描述了兩方之間的回應如何成為對方下一個貢獻、判斷、決策或行動的觀察條件。此框架強調了互動的動態性和相互依賴性，超越了單純的輸入輸出分析。研究旨在提供一個更細緻的視角來理解人類與AI之間複雜的協作與共同演化。透過此框架，研究人員可以更深入地分析互動的微觀機制，並設計出更具適應性和響應性的人機系統。這對於提升人機協作的品質和效率具有重要的理論與實踐意義。
如何建立一個能捕捉人機互動動態、互惠與歷史承載特性的關係過程框架？
深度點評
  • 此框架創新地將人機互動視為一個「社會二元性」過程，強調了互動的序列性、互惠性和歷史承載性，超越了傳統的單向或靜態評估。
  • 相較於現有僅評估最終結果或單一能力的HCI研究，Socioduality框架提供了一個更細緻的分析工具，能深入探討互動的微觀機制和共同演化。
  • 此框架為設計更具適應性、響應性和「社會智能」的AI系統提供了理論基礎，有助於提升人機協作的品質和使用者體驗。
研究貢獻
  • 提出「社會二元性」作為人機互動的關係過程框架
  • 強調互動的序列性、互惠性與歷史承載特徵
  • 為分析人機協作的動態機制提供新視角
研究限制
  • 框架的實證驗證可能需要複雜的實驗設計
  • 量化「歷史承載」的影響可能存在挑戰

The Role of Variability in Human-Machine Interaction Experience
cs.HCcs.AI 2026-08-13
人機互動 (HMI) 需要考慮人類運動行為本質的控制策略。傳統的共享控制和觸覺輔助方法通常忽略人類行為的隨機性，這可能限制了性能和人類互動體驗。本研究設計了一個實驗環境，並評估了一種新穎的「人類變異性感知最佳控制器」。參與者在三種條件下執行物理耦合的觸覺互動任務：一種旨在傳統上最小化人類輸入變異性的控制器模式，一種考慮人類變異性的控制器模式，以及一種無輔助的基線模式。研究發現，考慮人類變異性的控制器不僅能提升任務表現，還能顯著改善使用者的互動體驗。這表明將人類行為的隨機性納入HMI設計，對於創造更自然、更高效的人機系統至關重要。
在人機互動中，考慮人類運動行為變異性對性能和使用者體驗有何影響？
深度點評
  • 本研究創新地將人類運動行為的隨機性納入HMI控制策略，設計了「人類變異性感知最佳控制器」，突破了傳統方法忽略此特性的局限。
  • 相較於傳統最小化變異性的控制器，此研究證明了擁抱並利用人類變異性，能同時提升任務表現和使用者體驗，為HMI設計提供了新方向。
  • 這項研究對機器人輔助、虛擬實境互動及其他需要精細人機協作的領域具有潛在影響，有助於開發更符合人類直覺和舒適度的智能系統。
研究貢獻
  • 設計並評估「人類變異性感知最佳控制器」
  • 證明考慮人類變異性可提升HMI性能與體驗
  • 為HMI控制策略提供新設計原則
研究限制
  • 實驗環境的模擬性可能與真實世界存在差異
  • 參與者樣本量可能影響結果的普適性

如何準確測量瀏覽器網路攝影機凝視追蹤器的真實延遲，以確保數據可靠性？
深度點評
  • 本研究提出了一種創新的「捕獲時鐘」方法，透過利用瀏覽器API來準確測量網路攝影機凝視追蹤器的真實延遲，解決了現有測量方法的根本性缺陷。
  • 相較於傳統的發射時間戳記方法，此方法提供了更誠實和可靠的延遲數據，對於依賴精確時間同步的認知心理學實驗和HCI研究具有顯著優勢。
  • 這項研究為基於網路攝影機的凝視追蹤技術樹立了新的評估標準，將極大提升其在學術研究、臨床診斷和使用者體驗分析中的數據可靠性和應用價值。
研究貢獻
  • 提出「捕獲時鐘」方法以準確測量凝視追蹤延遲
  • 揭示現有凝視追蹤延遲測量方法的缺陷
  • 提供開源參考實作以促進研究社群應用
研究限制
  • 方法依賴於特定的瀏覽器API，可能存在兼容性問題

LLM × 心理學 No.01
Dynamic Governance of Multi-LLM Agent Systems for Collaborative Conversational Outcomes
cs.AI
核心問題
如何透過控制理論治理層解決多LLM代理系統在缺乏共享目標函數時的協作崩潰問題？
方法亮點
提出「體驗協調器」(Experience Orchestrator, EO) 作為控制理論治理層，在模擬金融服務環境中引導具有結構性對立目標的LLM代理進行多輪互動。EO旨在替代缺失的共享目標函數，確保代理間的對話能達成預期結果，避免因目標衝突導致的對話終止或單方屈服。
心理學意涵
這項研究對於理解和設計更有效的人機協作系統具有重要意義。在心理學上，它觸及了群體動力學、談判策略和衝突解決的議題，特別是在多智能體環境中。如果AI代理能夠在沒有明確共享目標的情況下，透過治理層實現協作，這將為人類社會中複雜協作的建模和優化提供新的視角。同時，這也引發了關於AI系統自主性與控制權的倫理討論，以及如何確保AI協作符合人類價值觀的問題。
透過治理層讓LLM代理從「衝突崩潰」走向「協作共贏」，為複雜智能體系統設計開闢新徑。

cs.CLcs.AI
核心問題
如何建立一個任務驅動的代理檢查表評估框架，以更細緻地評估LLM代理的角色扮演能力？

告別單一分數，TRACE Bench讓LLM角色扮演評估更透明、更具診斷性，直指對話核心。

04 / Prompt Engineering × 心理學 精選 TOP 3 PROMPT ENG × PSYCHOLOGY
Prompt × 心理學 No.01
From Monolithic to Modular: Segment-level Automatic Prompt Optimization
cs.CL
Prompt 技術
Segment-level Automatic Prompt Optimization (SAPO)。該技術將提示分解為角色、上下文、任務和輸出格式等獨立區塊，然後根據正負範例對每個區塊進行針對性改進。優化循環使用一個LLM，透過靜態元提示和結構化輸出進行分割、弱點分析和候選生成。
心理學概念
認知負荷 (Cognitive Load) 與注意力 (Attention)。傳統整體提示優化可能導致LLM在處理複雜指令時認知負荷過高，難以同時優化多個行為。SAPO透過模組化分解，降低了LLM在單次優化中需要處理的資訊量，使其能更有效地「專注」於特定提示段落的改進，類似於人類在處理複雜任務時將其分解為子任務以降低認知負荷。
應用場景
當前應用於提升LLM在特定任務上的表現和穩定性，例如客服對話、內容生成或程式碼編寫。未來潛力在於開發更精準、更可控的LLM應用，尤其是在需要多方面行為協調的複雜情境中。對心理學實務的啟發是，這種模組化思維可以應用於設計更有效的心理干預或教育材料，將複雜的指令或概念分解為易於理解和處理的小單元，以優化學習或行為改變的效果。
模組化提示優化，讓LLM學習更精準，就像人類分段記憶，效率倍增。

Prompt × 心理學 No.02
Lost in Compaction: Evaluating Side-Constraint Loss under Context Compaction
cs.CLcs.AI
Prompt 技術
語境壓縮 (Context Compaction) 下的提示損失評估。這項研究並非提出新的提示工程技術，而是評估現有LLM系統在上下文窗口壓力下，如何「壓縮」或「丟失」用戶發出的「會話約束」(Session Constraints, SCs) 提示。它透過COMPINT評估套件，量化了多輪對話、代理軌跡和長程研究等場景中SCs的損失。
心理學概念
記憶與注意力 (Memory and Attention)、意圖保留 (Intention Retention)。會話約束類似於人類在長期任務中需要記住的「規則」或「原則」。當LLM系統進行語境壓縮時，如果這些關鍵約束被「遺忘」，就如同人類在執行任務時注意力分散或記憶力下降，導致行為偏離預期。這揭示了LLM在維持長期「意圖」或「規則」方面存在的挑戰，與人類在認知負荷下保持任務目標的心理機制有相似之處。
應用場景
當前應用於評估LLM系統在處理長上下文和多輪互動時的魯棒性與可靠性，特別是對於需要遵守特定規則或安全指令的應用。未來潛力在於開發更智能的語境管理策略，確保關鍵提示不會在壓縮過程中丟失，提升LLM在複雜、長期任務中的表現。對心理學實務的啟發是，在設計人機互動系統時，應考慮用戶「意圖」的持久性，並設計機制來確保AI能持續「記住」關鍵指令，尤其是在心理諮詢或輔助治療等需要高度一致性的場景。
LLM語境壓縮如人類健忘，關鍵指令「失憶」恐釀大錯，警示設計者應深思。

Prompt × 心理學 No.03
Better, Faster, Stronger: Programmatic Skill Learning Best Reduces Agent Cost
cs.AIcs.CL
Prompt 技術
程式化技能學習 (Programmatic Skill Learning)。這項技術透過讓LLM代理學習並執行一系列確定性動作的「程式」，來增強其能力並降低運行成本。與其他技能學習方法相比，程式化技能學習被認為能實現最佳的成本效益，因為它將複雜任務分解為可重複執行的程式模組。
心理學概念
認知效率 (Cognitive Efficiency)、習慣形成 (Habit Formation) 與自動化 (Automation)。程式化技能學習類似於人類將重複性任務轉化為自動化習慣或程序性知識，從而降低執行時的認知負荷和資源消耗。當一個代理學會將複雜任務分解為一系列明確的「程式」步驟時，它就能更高效、更穩定地執行任務，這與人類透過練習和經驗形成專業技能的過程相似。
應用場景
當前應用於提升LLM代理在特定領域（如自動化程式碼生成、數據分析或複雜決策）的性能和成本效益。未來潛力在於開發能夠自主學習和優化「技能程式」的智能代理，使其能適應更廣泛的任務和環境。對心理學實務的啟發是，這種技能學習模式可以應用於設計智能輔助系統，幫助用戶學習新技能或養成良好習慣，例如透過提供結構化的「行為程式」來引導用戶完成複雜的心理治療練習或自我提升任務。
程式化技能學習讓LLM代理更「聰明」也更「省錢」，如同人類將經驗轉化為高效習慣。
