No. 01
User-Side Contextual Phenomena in Long-Term Human-AI Interaction
cs.HCcs.CY 2026-09-16
當前對對話式AI的評估主要集中在模型輸出，如幻覺或事實錯誤，但本研究旨在探討長期且重複的人機互動中，使用者端可能形成的風險。研究追蹤了一位使用者在20個月內與同一系統進行近四千次對話的歷程。結果顯示，使用者逐漸將系統解讀為具有記憶、關懷、判斷力與權威，並圍繞其重塑了部分思維模式。單一回應可能無明顯問題，但長期互動卻可能導致使用者對AI產生過度依賴或誤解。這項研究強調了在評估AI時，需超越單次互動，考量長期使用對使用者心理與行為的深遠影響。研究結果對AI系統的設計者、政策制定者及使用者教育具有重要啟示，呼籲更全面地理解人機互動的複雜性。
長期人機互動如何影響使用者心理與行為？
深度點評
  • 研究方法創新，透過單一使用者長期互動的深度案例分析，揭示了傳統量化評估難以捕捉的複雜心理現象，但其個案性質限制了結果的普遍性。
  • 相較於既有研究多關注AI的技術缺陷，本研究將焦點轉向使用者端，強調了AI對人類認知與社會心理的潛在重塑作用，為人機互動研究開闢了新視角。
  • 對AI倫理與負責任AI設計具有深遠影響，提醒開發者需警惕AI在長期使用中可能引發的依賴、誤解及認知偏誤，促使設計更具韌性與透明度的AI系統。
研究貢獻
  • 首次透過長期個案研究，揭示了使用者在與AI系統長期互動中，對AI產生擬人化、權威化等複雜心理投射的現象。
  • 強調了AI評估應超越單次互動的輸出表現，納入長期使用者行為與心理變化的考量。
  • 為AI系統的倫理設計、使用者教育及政策制定提供了實證基礎，以應對AI對人類認知與社會關係的潛在影響。
研究限制
  • 研究基於單一使用者案例，其結果的普遍性可能受限，需要更多跨文化、跨情境的實證研究來驗證。
  • 研究主要透過對話記錄進行分析，可能無法完全捕捉使用者內在的認知過程與情感體驗，需要結合其他心理測量方法。

No. 02
PAUSE: A Privacy-Preserving Self-Reflection Tool for AI-Associated Cognitive Offloading
cs.AIcs.HC 2026-09-16
認知卸載是指利用外部輔助工具來減少心智努力，而大型語言模型（LLM）將此延伸至思維本身。本研究將「AI相關認知卸載」定義為個人習慣性地用LLM輸出取代自身推理、構思、學習或溝通的模式。近期實證研究指出，某些LLM使用模式與批判性思維努力、輔助任務期間的神經參與、創意多樣性及學習成果的變化有關聯。為應對這些挑戰，本研究提出PAUSE，一個保護隱私的自我反思工具，旨在幫助使用者意識並管理其AI相關認知卸載行為。PAUSE透過匿名化數據分析使用模式，並提供個人化反饋，鼓勵使用者在利用AI便利性的同時，維持自身的認知參與。此工具旨在促進更健康、更具意識的AI使用習慣，避免過度依賴導致認知能力退化。
如何平衡AI效率與人類認知參與，避免過度認知卸載？
深度點評
  • 方法創新在於提出一個具體的隱私保護工具PAUSE，將抽象的認知卸載概念轉化為可操作的干預方案，但其有效性仍需大規模實證驗證。
  • 與現有研究多聚焦於AI技術本身不同，本研究將焦點轉向AI對人類認知行為的長期影響，並嘗試提供解決方案，而非僅僅提出問題。
  • 對教育心理學、認知心理學及人機互動設計具有重要啟示，鼓勵開發者在設計AI工具時，融入促進使用者自我反思與認知參與的機制，以維護人類的批判性思維能力。
研究貢獻
  • 明確定義並探討了「AI相關認知卸載」這一新興心理現象及其對人類認知能力的潛在影響。
  • 提出並設計了PAUSE，一個保護隱私的自我反思工具，旨在幫助使用者管理其AI使用習慣，促進認知參與。
  • 為AI倫理設計提供了實用框架，強調在AI工具中融入促進使用者自我意識與認知健康的機制。
研究限制
  • PAUSE工具的長期有效性及對不同使用者群體的適用性仍需進一步的實證研究來驗證。
  • 隱私保護機制可能限制數據的深度分析，影響對認知卸載模式的全面理解。

Token Merging for Multilingual Speech Recognition: A Systematic Study Across Model Scale and Fine-Tuning
cs.CLcs.AI 2026-09-16
像Whisper這類領先的多語言語音識別模型，無需特定語言訓練即可轉錄多樣化的低資源語言，但其部署成本高昂。Token合併技術透過動態結合冗餘特徵來緩解這種低效率，在不需重新訓練的情況下縮短推論時的序列長度。本研究系統性地評估了Token合併技術在Whisper模型家族中的表現，涵蓋了十六種不同語言及三種不同模型尺寸。研究還測試了Token合併與微調策略之間的交互作用，以了解其對模型性能和效率的綜合影響。結果顯示，Token合併能顯著提升多語言語音識別模型的推論效率，同時保持較高的準確性，尤其在資源受限的環境中更具應用潛力。這項研究為優化多語言語音識別模型的部署提供了寶貴的見解。
Token合併如何提升多語言語音識別模型的效率與性能？
深度點評
  • 研究方法嚴謹，系統性地評估了Token合併在不同模型規模和微調策略下的表現，提供了全面的性能分析，但未深入探討其對語音識別錯誤模式的影響。
  • 相較於傳統的剪枝或量化方法，Token合併在不需重新訓練的情況下實現效率提升，為多語言語音識別的部署提供了更靈活且通用的優化途徑。
  • 對計算語言學、語音處理及低資源語言技術發展具有重要意義，有助於推動高效、普惠的多語言語音識別技術在更廣泛的應用場景中落地，例如跨文化溝通輔助工具。
研究貢獻
  • 首次對Token合併技術在Whisper模型家族中的多語言語音識別性能進行了系統性評估。
  • 探討了Token合併與模型規模、微調策略之間的交互作用，提供了詳細的實驗數據和分析。
  • 證明了Token合併在提升多語言語音識別模型推論效率方面的有效性，為資源受限環境下的部署提供了實用方案。
研究限制
  • 研究主要關注效率提升，對Token合併可能導致的語音識別錯誤類型或語義理解偏差未進行深入分析。
  • 實驗僅限於Whisper模型家族，其結果是否能推廣至其他語音識別模型仍需進一步驗證。

LVLM如何在科學考試的冗餘上下文下進行文檔級推理？
深度點評
  • TestHallVQA基準測試的設計創新，特別關注了冗餘上下文對LVLM推理能力的影響，彌補了現有基準測試的不足，但其數據集規模和多樣性仍有提升空間。
  • 相較於傳統VQA任務，本研究更貼近真實世界的複雜文檔理解場景，強調模型在信息過載環境下的篩選與推理能力，推動了LVLM在專業領域的應用。
  • 對認知科學中的注意力機制與信息處理具有啟示，可藉由分析LVLM在冗餘信息下的表現，反思人類在類似情境下的認知策略，並指導AI模型設計以更好地模擬人類的選擇性注意力。
研究貢獻
  • 引入了TestHallVQA，一個新的基準測試，專門用於評估LVLM在科學考試中，面對冗餘上下文下的文檔級推理能力。

  • 為LVLM在複雜文檔理解和專業領域應用（如教育、醫療）的發展提供了更具挑戰性和實用性的評估工具。
研究限制
  • TestHallVQA數據集主要來源於科學考試，其領域特異性可能限制了模型在其他類型複雜文檔上的泛化能力。
  • 研究主要關注性能評估，對LVLM在處理冗餘信息時的內部機制或錯誤歸因分析較少。

No. 05
Hindsight Bias in Clinical Temporal Reasoning: How Future Data Exposure Affects Large Language Model Judgment
cs.CLcs.AI 2026-09-16
臨床決策本質上是前瞻性的，但臨床語言模型卻常在回溯性記錄上進行評估，這些記錄已揭示最終診斷、治療反應和結果。這種評估方式可能獎勵模型利用未來信息，而非在決策點的不確定性下進行推理。為此，我們引入了一個配對基準測試，用於衡量與後見之明偏誤一致的、由結果條件導致的臨床時間推理轉變。該基準測試包含來自PubMed Central開放存取子集的171份病例報告，涵蓋40例敗血症和131例GLP-1/糖尿病案例。研究結果顯示，當模型接觸到未來信息時，其判斷會顯著受到影響，表現出類似人類的後見之明偏誤。這項研究強調了在開發和評估臨床AI時，必須嚴格控制時間信息暴露，以確保模型的判斷是基於決策時可用的信息，而非事後諸葛。
LLM在臨床推理中是否會因未來數據暴露而產生後見之明偏誤？
深度點評
  • 研究設計巧妙，透過配對基準測試量化了LLM在臨床推理中的後見之明偏誤，為AI醫療領域的評估提供了新的視角，但數據集規模相對有限。
  • 與傳統的AI性能評估不同，本研究將認知心理學中的「後見之明偏誤」引入AI領域，揭示了AI在處理時間序列信息時可能存在的深層次問題，具有重要的跨學科意義。
  • 對臨床心理學、醫療AI倫理及決策支持系統的發展具有關鍵影響，提醒開發者在設計AI輔助診斷工具時，必須嚴格模擬臨床決策的真實情境，避免因信息洩漏導致的誤判，確保AI的判斷符合臨床實踐的嚴謹性。
研究貢獻
  • 首次引入配對基準測試，量化了大型語言模型在臨床時間推理中因未來數據暴露而產生的後見之明偏誤。
  • 證明了LLM在臨床情境下，其判斷會受到事後結果信息的影響，表現出類似人類的認知偏誤。
  • 為醫療AI的開發和評估提供了新的指導原則，強調在訓練和測試中必須嚴格控制時間信息暴露，以確保模型的判斷公正性和可靠性。
研究限制
  • 研究使用的病例報告數量相對有限，可能無法完全捕捉所有臨床情境下的後見之明偏誤模式。
  • 主要關注LLM的判斷結果，對其內部推理過程如何受到偏誤影響的機制分析較少。

LLM × 心理學 No.01
When Can You Trust Your Synthetic Users? Diagnostics and Corrections for LLM Consumer Panels
cs.AIcs.CLcs.CY
核心問題
如何診斷並修正LLM生成合成消費者數據中的系統性偏差？
方法亮點
本研究提出一個形式化框架，將合成面板偏差分解為共變量偏移（covariate shift）和概念偏移（concept shift），並開發了相應的測試與校正方法。透過對LLM生成數據的聚合驗證指標進行深入分析，揭示了方差壓縮、係數符號翻轉、亞組誤差膨脹等系統性失敗。該框架旨在提供一套判斷何時信任、校正或放棄LLM生成消費者數據的準則。
心理學意涵
這項研究對社會心理學和行為經濟學具有重要意義，尤其是在消費者行為研究領域。它揭示了利用LLM作為合成使用者進行市場調查時，可能引入的系統性偏見，挑戰了AI在模擬人類群體行為方面的可靠性。研究結果提醒心理學家和市場研究者，在使用AI生成數據時需保持高度警惕，並提供了一套診斷和修正偏見的方法，有助於提升AI輔助研究的科學嚴謹性。同時，這也引發了關於AI在社會科學研究中角色與倫理的討論。
合成使用者雖省錢，但偏誤診斷與校正，才是信任AI模擬人性的關鍵。

LLM × 心理學 No.02
PhysMent: An Interactive Approach For LLM Reasoning In Physics Problems
cs.AIcs.CL
核心問題
LLM能否透過主動實驗與工具互動來推理物理世界？
方法亮點
本研究引入PhysMent基準測試，透過與MuJoCo物理模擬器進行迭代、工具媒介的互動，評估LLM的物理推理能力。與傳統靜態基準測試不同，PhysMent要求模型透過施加力、查詢物體狀態、推進時間和修改場景幾何等方式來發現信息，然後才能回答問題。這種互動式方法旨在更真實地模擬人類在解決物理問題時的探索與實驗過程。
心理學意涵
這項研究對認知科學，特別是關於人類物理直覺和問題解決策略的理解，提供了新的視角。它挑戰了LLM僅依賴靜態知識進行推理的局限性，展示了透過主動實驗和工具使用，LLM也能展現出類似人類的探索式學習能力。這對於開發更具通用智能的AI系統，以及理解人類如何透過與環境互動來建構知識具有啟發性。同時，也為教育心理學中基於探究式學習的AI輔助教學提供了潛在方向。

Prompt × 心理學 No.01
TimeThink: Eliciting Compositional Reasoning in Timeseries Large Language Models
cs.AIcs.CL
Prompt 技術
TimeThink採用了一種基於強化學習（RL）的提示策略，結合了時間序列多模態大型語言模型（TS-MLLM）的推理能力。它透過設計特定的提示結構和獎勵機制，引導模型進行「組合式推理」（compositional reasoning），使其能夠捕捉動態時間模式並提供明確的解釋，而非僅僅是隱式推理。
心理學概念
涉及的心理學概念是「組合式推理」（Compositional Reasoning）和「解釋性」（Explainability）。組合式推理是指將複雜問題分解為更小的、可管理的子問題，並逐步解決的能力，這與人類的認知策略高度相關。解釋性則關聯到人類對理解和信任AI決策的需求，尤其在高風險應用如醫療領域，透明的推理過程能增強使用者信任並降低認知負荷。
應用場景
TimeThink的應用場景廣泛，尤其在需要理解複雜時間動態的領域。例如，在醫療保健中，它可以幫助醫生分析患者的生理數據趨勢，提供疾病進展的解釋性預測；在金融領域，可用於分析市場趨勢並解釋其背後的原因。未來潛力在於將這種可解釋的組合式推理能力推廣到更多複雜的決策支持系統，提升AI的透明度和可信度。對心理學實務的啟發是，AI模型若能提供清晰的推理路徑，將有助於心理學家理解AI的「思維」模式，並在臨床診斷或行為預測中提供更具說服力的輔助信息。
時間序列LLM若能「思考」並「解釋」，複雜動態便能洞察，高風險決策更添信任。

Prompt × 心理學 No.02
Lexical Prompt Compression for Large Language Models: A Training-Free, Deterministic Pipeline with Empirical Pareto Analysis Across Eleven Task Categories
cs.CLcs.AI
Prompt 技術
本研究提出了一種「詞彙提示壓縮」（Lexical Prompt Compression）技術，這是一種無需訓練、確定性的管道，旨在減少大型語言模型（LLM）提示的長度。它透過詞彙層面的優化，例如移除冗餘詞彙、精簡表達或利用語義等效替換，來實現高壓縮比。與需要輔助語言模型的學習型壓縮方法不同，此方法不依賴額外模型，且能保證每次壓縮結果的一致性。
心理學概念
涉及的心理學概念主要是「認知負荷」（Cognitive Load）和「信息處理效率」（Information Processing Efficiency）。當提示過長或過於複雜時，會增加LLM的認知負荷，導致推理成本和延遲增加。透過提示壓縮，可以有效降低模型的處理負擔，提升其處理效率。這也與人類在處理信息時，傾向於簡化和提取關鍵信息的認知偏好相呼應，旨在讓AI以更「經濟」的方式進行認知活動。
應用場景
此技術在實際應用中具有巨大潛力，尤其是在需要處理長提示或對延遲敏感的場景。例如，在即時對話系統中，壓縮提示可以顯著降低推理成本和響應時間；在複雜的鏈式思維（CoT）推理任務中，可以減少上下文窗口的壓力。對心理學實務的啟發是，當AI作為輔助工具時，其輸入的簡潔性與效率會直接影響使用者體驗和AI的實用性。透過優化AI的「輸入認知」，可以間接提升人機互動的流暢度和效率，減少人類在使用AI時的認知摩擦。
提示壓縮不僅省錢省時，更是為LLM減輕認知負荷，讓AI思考更輕盈。
