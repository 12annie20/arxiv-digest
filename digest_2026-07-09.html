No. 01
Depression Symptoms and Relational Patterns in 187k ChatGPT Histories
cs.HCcs.CY 2026-07-09
隨著大型語言模型（LLMs）日益成為私密且隨時可用的對話系統，人們對憂鬱症狀患者如何使用這些系統知之甚少。本研究將ChatGPT視為一種新興的非正式支持基礎設施，其特點是私密、持久、反應迅速且全天候可用。研究分析了來自766名參與者的187,093條ChatGPT對話歷史，這些參與者完成了PHQ-8問卷，並將症狀程度低於或等於中度閾值（分數為10）的群體進行比較。結果發現，PHQ-8分數較高的使用者在與ChatGPT的互動中展現出特定的關係模式，例如更頻繁地表達負面情緒或尋求支持。這項研究為理解LLMs在心理健康支持中的潛力與挑戰提供了寶貴見解，並為未來設計更具同理心和有效性的AI輔助工具奠定基礎。
憂鬱症狀患者如何使用ChatGPT？
深度點評
  • 本研究透過大規模真實對話數據分析，揭示了LLM在心理健康支持領域的潛在應用，其數據量和真實性遠超傳統實驗室研究，為領域帶來突破性視角。
  • 相較於傳統的心理諮詢或同儕支持，ChatGPT作為一種非正式支持基礎設施，提供了前所未有的可及性和匿名性，其互動模式的分析有助於理解新型態的心理支持機制。
  • 這項研究對臨床心理學和人機互動領域具有深遠影響，不僅能指導開發更有效的AI心理健康工具，也引發了關於AI在敏感健康議題中倫理責任和隱私保護的討論。
研究貢獻
  • 首次大規模分析憂鬱症狀患者與ChatGPT的互動模式
  • 將ChatGPT視為新興的非正式心理支持基礎設施
  • 揭示了不同憂鬱程度使用者在LLM互動中的關係差異

  • 無法完全捕捉對話的深層情感語境和非語言線索

No. 02
Perceived System Predictability: Scale Development and Application
cs.HC 2026-07-09
使用者對互動系統可預測性的感知，會影響他們對系統的解釋、信任和依賴程度，然而人機互動（HCI）領域卻缺乏對此感知精確的概念化和經過驗證的測量工具。為彌補這一空白，本研究引入了「感知系統可預測性」（PSP）作為一個以使用者為中心的建構，其根植於不確定性理論，並區分了認知性、偶然性和有效性可預測性。研究貢獻包括：（i）一個將PSP與信任和理解等鄰近建構相關聯的理論框架；（ii）一個包含6個項目的PSP量表，該量表經過了多項研究的驗證，證明其具有良好的信效度；（iii）將PSP量表應用於多個互動系統的實證研究，展示了其在評估使用者體驗和系統設計中的實用價值。
如何精確測量使用者對系統可預測性的感知？
深度點評
  • 本研究創新性地將不確定性理論引入HCI領域，提出了「感知系統可預測性」這一新穎且具區分度的概念，並開發了經過嚴格驗證的量表，填補了該領域的測量空白。
  • 相較於現有對信任或理解的測量，PSP量表更聚焦於系統行為的預期性，能更細緻地捕捉使用者對AI系統不確定性的反應，為AI系統的設計提供了更精確的指導。
  • PSP量表的開發將對HCI、AI倫理和使用者體驗設計產生深遠影響，有助於設計者更好地理解和管理使用者對AI系統的期望，從而提升使用者信任和接受度。
研究貢獻
  • 提出並概念化「感知系統可預測性」(PSP)建構
  • 開發並驗證了6項PSP量表
  • 將PSP應用於多個互動系統以展示其價值
研究限制
  • 量表主要基於自評，可能存在主觀偏差
  • 跨文化或不同使用者群體的適用性需進一步驗證

如何有效評估小型語言模型作為程式設計導師的表現？
深度點評
  • 本研究透過CSTutorBench基準測試，為評估SLMs在特定教育領域（積木式程式設計）的表現提供了標準化框架，解決了現有評估缺乏針對性的問題，具有重要的實踐意義。

  • CSTutorBench的引入將加速SLMs在教育領域的發展和應用，特別是在程式設計教學方面，有助於開發更符合學生認知發展階段和學習需求的AI導師系統。
研究貢獻
  • 引入CSTutorBench，一個針對積木式程式設計的SLM導師基準測試
  • 評估SLMs在K-12程式設計教育中的潛力
  • 為AI導師的選擇和部署提供實證依據

如何用圖論架構來建模複雜的認知狀態及其動態轉化？
深度點評
  • NEST架構創新性地將圖論應用於認知建模，透過巢狀情節狀態拓撲來表徵認知的動態形成與轉化，這比傳統的靜態模型更能捕捉人類思維的複雜性和層次性。
  • 相較於現有的認知架構，NEST區分了持久性信念圖和容量有限的工作記憶圖，這與人類認知科學中的長期記憶和短期記憶概念高度契合，為AI系統的記憶管理提供了新的啟發。
  • 本研究為認知科學和人工智慧領域提供了一個強大的理論框架，有望推動開發出更具類人推理、學習和記憶能力的AI系統，並加深我們對人類自身認知的理解。
研究貢獻
  • 提出NEST，一個基於圖論的認知狀態表徵本體論
  • 區分持久性信念圖與容量有限的工作記憶圖
  • 定義六種關係類別來類型化圖的邊
研究限制
  • 理論框架的實證驗證仍需大量工作
  • 將抽象概念映射到具體計算模型可能存在挑戰

LLM × 心理學 No.01
Most LLM Conformity Needs No Speaker: Measuring the Speaker-Free Floor in Peer-Pressure Benchmarks
cs.AIcs.CL
核心問題
LLM的從眾行為是否真的需要「說話者」的存在？
方法亮點
研究引入了「無來源條件」（no-source condition），在標準從眾提示中移除明確的「說話者」存在，僅保留重複的錯誤答案本身，以區分LLM從眾行為中由「說話者」和「錯誤答案」本身引起的影響。透過比較有/無說話者情境下的模型反應，量化了「無說話者基礎從眾」（speaker-free floor）。
心理學意涵
本研究揭示了LLM在「從眾」行為中，很大一部分並非源於對「說話者」的社會壓力感知，而是對重複錯誤資訊的內在傾向。這對社會心理學中關於從眾行為的理論提出了新的思考，即資訊本身（而非其來源）可能足以引導行為。在AI倫理方面，這意味著LLM可能在無意中傳播或強化偏見，即使沒有明確的外部影響者。這也提醒我們在設計LLM應用時，需警惕其對資訊重複性的敏感，避免無意中引導使用者形成錯誤判斷。
LLM的從眾是資訊的奴隸，而非社會壓力的受害者。

Prompt × 心理學 No.01
How Personas Can Influence Agents to Play Split or Steal
cs.CLcs.AI
Prompt 技術
Persona Prompting (角色提示) - 透過在提示中賦予LLM代理特定的「人格」或「角色描述」，來引導其在社會困境遊戲（如Split or Steal）中展現出預設的策略行為，例如合作或背叛。
心理學概念
社會心理學中的「說服」（Persuasion）與「行為影響」（Behavioral Influence）、行為經濟學中的「決策偏誤」（Decision Bias）。Persona提示透過模擬社會情境中的角色設定，影響了LLM代理的「社會認知」和「決策策略」，使其行為更接近特定人格特質的人類。
應用場景
當前應用於模擬人類在社會互動中的決策行為，例如在遊戲理論實驗中測試不同人格特質的影響。未來潛力巨大，可用於開發更具說服力或同理心的AI助手，例如在談判、客戶服務或教育輔導中，AI能根據情境扮演不同角色以優化互動。對心理學實務的啟發是，透過精準的角色設定，AI可以成為研究人類社會行為的強大工具，同時也為設計更符合使用者心理預期的AI互動模式提供了新思路。

Prompt × 心理學 No.02
Prompt Robustness Is Task-Dependent: Comparing Objective and Belief-Style Questions in LLM Evaluation
cs.CLcs.AI
Prompt 技術
Prompt Robustness Testing (提示穩健性測試) - 透過系統性地改變提示的措辭、結構或上下文，來評估LLM在不同提示下回答的一致性。本研究特別區分了「客觀問題」和「信念風格問題」的穩健性。
心理學概念
認知心理學中的「框架效應」（Framing Effect）和「信念固著」（Belief Perseverance）。研究發現LLM對「信念風格問題」的提示穩健性較差，這反映了其在處理主觀、價值觀相關問題時，更容易受到提示細微變化的影響，類似於人類在面對模糊或情感性問題時的認知脆弱性。
應用場景
當前應用於評估LLM在不同任務類型下的可靠性，特別是在涉及價值觀、政治態度等敏感領域。未來潛力在於指導開發更具「提示魯棒性」的LLM，減少因提示微小變化而導致的行為不一致。對心理學實務的啟發是，在利用LLM進行心理測量或意見調查時，必須極度謹慎提示的設計，以避免引入測量偏差。同時，這也為研究人類在不同問題框架下信念的穩定性提供了對照組。
LLM的「信念」比「事實」更脆弱，提示一變，立場就動搖。

FirstResearch: Auditable Question Formation for LLM Scientific Discovery Agents
cs.CLcs.AI
Prompt 技術
Structured Prompting / Chain-of-Thought (CoT) with Auditable Certificates (結構化提示/可審計證書的思維鏈) - 透過設計一個「研究問題證書」的核心人工製品，要求LLM代理在提出研究問題時，明確記錄其原始定義、機制、可證偽性及假設，從而使LLM的科學發現過程可被審計。
心理學概念
認知心理學中的「批判性思維」（Critical Thinking）、「元認知」（Metacognition）和「推理」（Reasoning）。本技術旨在讓AI代理在「思考」科學問題時，能像人類科學家一樣進行自我反思和驗證，提升其推理過程的透明度和可信度，從而增強人類對AI科學發現的「信任」。
應用場景
當前應用於提升LLM在科學研究中的輔助能力，特別是協助生成可驗證和有意義的初步研究問題。未來潛力在於將AI代理深度整合到科學研究流程中，使其不僅能生成假設，還能提供其推理的「證據鏈」，從而加速科學發現。對心理學實務的啟發是，這提供了一個框架來研究人類科學家如何評估和信任AI生成的假設，以及如何透過提示設計來引導AI模仿人類的科學思維模式。
讓AI學會「問對問題」，並解釋「為何這樣問」，科學發現不再是黑箱。
